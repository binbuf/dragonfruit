# Cursor assets

`capitaine-cursors/` is the vendored Dragonfruit system cursor theme. See
[`capitaine-cursors/README.md`](capitaine-cursors/README.md) for provenance,
the license, and the modifications made for this repository.

The theme is installed to `share/icons/capitaine-cursors` by `make install`;
the compositor also discovers the in-repo copy directly during development.
