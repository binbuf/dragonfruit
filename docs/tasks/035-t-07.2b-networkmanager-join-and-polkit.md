## Goal

Join/activate a network, degrading to read-only if polkit blocks it.

## Scope

- Join/activate a network through NetworkManager.
- If polkit blocks join, degrade to read-only and record it.

## Explicitly deferred

- None.

## Acceptance (agent-completable)

- [x] Join works against a mock; polkit denial leaves a read-only item with a recorded note.

## Test plan

- Headless: mock join success and denial paths.

## Hand-off

- **Landed:** `dragonfruit-networkmanager` joined the write path. The transport
  seam `NetworkManagerSource::activate` + `ActivateRequest`/`ActivateOutcome`
  join the existing `read` (`src/source.rs`); `MockNetworkManager` gained
  `deny_joins`/`fail_joins`/`allow_joins`/`activations`. The adapter gained
  `join(JoinRequest) -> JoinResult`, `WifiAccess::{ReadWrite, ReadOnly{note}}`,
  `access()`/`is_read_only()`/`degradation_note()` (`src/adapter.rs`).
  `DbusNetworkManager::activate` calls `AddAndActivateConnection` and classifies
  a polkit refusal by D-Bus error name or message (`src/dbus.rs`).
- **Verified:** `cargo test -p dragonfruit-networkmanager` → 41 tests green
  (32 lib + 4 `tests/join_path.rs` + 5 `tests/read_path.rs`); `make e2e` → exit
  0; `make clippy`/`cargo clippy -p dragonfruit-networkmanager --all-targets --
  -D warnings` and `cargo fmt --all -- --check` clean.
- **Decision (ADR 0027):** a denied write is its own outcome, and the read-only
  degradation lives on the *adapter* (not in `WifiSnapshot`) so the network list
  stays live; the status slot stays visible **and enabled** — read-only means
  reads keep working, only joins are off. A degraded adapter refuses further
  joins locally (no re-poll of a doomed request). The note survives `refresh`.
- **T-07.3 must know:** audio extends the same crate-per-adapter layout; this
  task touched only `services/networkmanager`. There is still no host/bridge
  driving the Rust adapters for the C++ shell (T-07.5 decides it) and the live
  write path is compile-checked only (no bus in CI).
- **Not done here:** the real `DbusNetworkManager::activate` is compile-checked,
  not exercised (no system bus); no signal subscription thread yet; no QML
  surface. `--placeholders` stays until T-07.5b.
- **Live visual check:** launched the nested demo (`make demo`, host session
  `wayland-0`) and captured the compositor window with
  `spectacle -b -n -a` → `docs/captures/t07-networkmanager-join.png`
