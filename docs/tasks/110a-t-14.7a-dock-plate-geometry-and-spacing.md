## Goal

The Dock bar reads as a floating plate: visible breathing room between the
artwork and the plate edge on all four sides, and a real gap between the plate
and the screen edge. The reserved zone and auto-hide follow the new geometry,
so windows still never underlap the Dock and a hidden Dock leaves no strip.

## Current behavior (investigated, T101 era)

- `Theme.controls.dock.padding` and `gap` are both 6 px. The plate is
  `iconSize + indicatorSpace + 2 * padding` tall and exactly the baseline
  content plus 2 × padding wide.
- The Dock layer surface is anchored to the screen edge and its thickness is
  `barThickness + magnifyBand`, so the plate's bottom edge is flush with the
  screen edge. `edgeMargin` (4 px) exists but is used only by `hideOffset`; no
  visible gap exists.
- The exclusive zone is `barThickness`; there is no reserved gap, so a floating
  plate would leave windows underlapping it.
- Left/right Docks have the same problem on their edge.

## Scope

- [ ] `tokens.json`: split the single spacing value into cross-axis `padding`
      (artwork ↔ plate edge) and along-axis `paddingAlong` (plate ends); set
      `padding: 10`, `paddingAlong: 14`, `gap: 8`, `edgeMargin: 8` as starting
      values, then tune against captures and record the finals. Regenerate
      `Theme.qml` with `scripts/gen-tokens.py`.
- [ ] `Dock.qml`: consolidate the geometry into one `plateRect` property (the
      baseline for now) used by the plate drawing, the input region, and — in
      T-14.7b — the backdrop panel request. Keep `barThickness` as the plate
      height; use `paddingAlong` for the ends.
- [ ] Place the plate `edgeMargin` from the anchored screen edge: grow the
      surface by `edgeMargin` and make the exclusive zone
      `barThickness + edgeMargin` (bottom/left/right), so Zoom keeps clear of
      the floating plate.
- [ ] Keep auto-hide behavior exact: `hideOffset` still reaches the surface
      bottom (`barThickness + edgeMargin`), the hidden edge band stays on the
      screen edge, and re-reveal lands at the same plate rect.
- [ ] Mirror the margin/padding for `position: left|right`; bounce and drag
      translations must stay inside the surface.
- [ ] Update `tst_dock.qml` geometry expectations and add explicit cases:
      plate bottom = surface edge − `edgeMargin`; every entry inside the plate
      at `iconSizeMin`/`iconSizeMax`; hidden translation fully clears the
      surface; the vertical variants.
- [ ] Capture
      `docs/captures/t14-dock-spacing-{bottom,left,right}-{light,dark}.png`
      (crop to the Dock) and add the `PROGRESS.md` note.

## Design notes

- All values are design-system tokens; no literals in `shell/dock/*.qml`
  (`make check-design-tokens` scans only `design-system/`, but the rule holds).
- Keep the legacy geometry model: the reserved zone is the visible plate plus
  the edge margin; magnification reserves nothing extra (T-14.7b).
- The Dock **floats** (product direction; ADR
  [0091](../design/adr/0091-dock-tahoe-floating-glass-language.md)): tune the
  gap against the local Tahoe reference captures rather than removing it. There
  is no flush variant.
- One `plateRect` source of truth — do not re-derive the padding math in the
  shell or the compositor.
- The 44 px `trashSize` token is unrelated to this unit (T-14.7d).

## Hand-off

**Landed.** The Dock is a floating plate with token-driven spacing on all four
sides.

Final token values (`design-system/tokens/tokens.json` → `controls.dock`, then
`scripts/gen-tokens.py` ever writes `Theme.qml`/`design_tokens.rs`):
`padding: 10`, `paddingAlong: 14` (new), `gap: 8`, `edgeMargin: 8`. Captures
confirm the visual: plate is 75 px (icon 48 + indicator 7 + 2×10), gap 8 px on
every anchored edge, same 10 px cross-axis inset all around.

Geometry contract (T-14.7b must build on this):

- `shell/dock/Dock.qml` exposes one `plateRect` (baseline plate) and the derived
  `surfaceThickness` (= `barThickness + magnifyBand + edgeMargin`) and
  `reservedThickness` (= `barThickness + edgeMargin`). `barThickness` is still
  the plate's cross-axis size; `paddingAlong` now insets the plate's ends.
- The shell reads those properties (`shell/src/shellcontroller.cpp`) for the
  layer-surface extent and the exclusive zone; it no longer derives the padding
  math. `m_dockBarThickness` was removed as dead state.
- T-14.7b: send `plateRect` as the live panel rect on every commit; today the
  compositor's derived panel is already the plate because `panel_bounds`
  intersects the input region (the plate plus magnified icons) with the reserved
  strip, so the gap is not frosted.
- Auto-hide translation is still `barThickness + edgeMargin` and now fully
  clears the surface (hidden plate top/left/right lands on the screen edge;
  only the `edgeTrigger` sliver stays interactive).

**Deviations.** None from the scope. Rust is unchanged (`reserved_rect` follows
the shell's exclusive zone as the task predicted).
