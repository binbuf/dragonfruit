## Reference UI/UX (macOS screenshots)

Local art direction only: the pane mirrors macOS System Settings nearly
verbatim in style, order, labels, controls, and wording. Images in
`docs/reference/macos/` (never shipped; see
[14-risks.md](../design/14-risks.md)), distilled in
[System_Preferences.md](../reference/System_Preferences.md).

Sections and rows (observed order):

- **Display preview card**: display artwork labelled `Built-in Display`, with
  an `Arrange…` button for multi-display layouts (T-16).
- **Resolution/scale list**: `Larger Text`…`Default`…`More Space` icon tiles,
  accent border on the selected tile; footer "Using a scaled resolution may
  affect performance."
- **`Brightness`**: slider with sun glyphs at both ends, plus
  `Automatically adjust brightness` toggle.
- **`True Tone`**: toggle with description (Apple-only; see below).
- **`Preset`**: color profile popup (`Apple XDR Display (P3-1600 nits)` in the
  capture).
- **`Refresh rate`**: popup (`ProMotion` in the capture).
- **Night Shift / advanced buttons**: `Night Shift…` and `Advanced…` (cropped
  from the capture).

Wave 1 maps resolution, scale, and rotation to our compositor output API
([08-settings.md](../design/08-settings.md)); rotation is not visible in the
capture. All other rows are the pane's target UI, not deferred: providers —
brightness = compositor/kernel; color = TBD; Night Shift = our night light
(decide the label at implementation); `Advanced…` opens T-15/T-16 output
controls.

Adapt or omit (Apple-only): `True Tone`; Apple display names
(`Apple XDR Display (P3-1600 nits)` → a generic profile); the
`When connected to TV` (`Ask What to Show`) row is Apple TV/AirPlay.
