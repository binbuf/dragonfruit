### Deviation: a real presenter bug found and fixed

The verification surfaced that Qt's D-Bus `ay` decoding hands the shell's
`ChooserBridge` a NUL-terminated `current_folder`; `suggestedUri` fed the NUL
into `QUrl::fromLocalFile`, so the real Flatpak file-choose failed with
`Cannot open file:%00.` before listing anything. Minimal fix in
`shell/src/chooserbridge.cpp` (trim trailing NULs from `current_file` /
`current_folder`, matching the portal backend's `decode_path_bytes`), pinned by
`shell/tests/tst_chooser.cpp` (`theSelectionRoundTripsToThePortalPresenter` now
sends the real NUL-terminated option). This is the only product change in this
otherwise verification-only unit; the track rule that T-17 adds no features is
waived here because the acceptance cannot be met without it.
