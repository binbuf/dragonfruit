# T180 — T-20.2 Tahoe liquid-glass: refraction, specular rim, adaptive tint

## Goal
The blurred chrome panels gain the parts of macOS Tahoe's Liquid Glass that a
plain Gaussian blur lacks: an SDF edge lens that refracts the backdrop near the
rim, a bright specular inner rim, and an adaptive tint sampled from the backdrop
luminance. All parameters are semantic material tokens, per scheme.

## Scope
- [ ] Add semantic tokens for the liquid glass per role and scheme: refraction
      strength, specular intensity/width, adaptive-tint amount (and any blur
      downsample factor). No literals in the shader.
- [ ] In `window/blur.rs` (or a sibling `glass.rs`), implement the edge lens:
      displace the sampled backdrop near the rounded rim using the panel's signed
      distance field; add the specular inner rim and the adaptive tint from the
      blurred backdrop luminance.
- [ ] Wire the fields through `BackdropSpec`/`MaterialRole` and the builder; the
      QML surfaces keep their existing translucent fill/rim layers as the
      complement, not the source of the effect.
- [ ] `DegradeTier`: `Full` = blur + refraction + specular + tint; `Reduced` =
      blur + specular, no refraction, smaller radius; `Minimal` = the flat
      fallback (unchanged).
- [ ] Keep the one-pass-per-frame guard and the counters; no new pass.

## Design notes
- The lens is an SDF effect on the panel's rounded rect, not a normal map asset
  (original assets only). Parameterise it so a future curved-edge look can reuse
  it.
- The adaptive tint reads the blurred backdrop's mean luminance and blends toward
  the scheme's surface/chrome tone; it must stay legible in light and dark and
  never invert label contrast.
- Reduced motion does not disable the material (it is not motion); the tier, not
  reduced-motion, owns the fallback.
- Headless unit tests assert the spec mapping and the tier behaviour; the pixel
  effect is verified by capture.
