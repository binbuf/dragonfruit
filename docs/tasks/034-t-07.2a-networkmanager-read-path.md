## Goal

Read Wi-Fi state, access-point list, and signal strength from NetworkManager's D-Bus API (no libnm link).

## Scope

- Current Wi-Fi state, AP list, signal strength.
- Read-only; degrades to hidden when NetworkManager is absent.

## Explicitly deferred

- Join/activate and polkit degradation (T-07.2b).

## Acceptance (agent-completable)

- [ ] AP list and state render from a mocked NetworkManager; absence hides the item.

## Test plan

- Headless: adapter reads a fixture and emits the expected state.

## Hand-off

- T-07.2b adds the write path.
- **Landed:** `services/networkmanager/` (new crate
  `dragonfruit-networkmanager`, workspace member): `source.rs` (raw
  `NetworkManagerData` + `NetworkManagerSource` + `MockNetworkManager`),
  `model.rs` (`WifiSnapshot`, `WifiState`, `Connectivity`, `Security`,
  `AccessPoint`, `Band` + decoding), `adapter.rs`
  (`NetworkManagerAdapter<S>` over the shared `Adapter`/`Subscription`), and
  `dbus.rs` (`DbusNetworkManager`, zbus blocking proxies — no `libnm`).
  Fixture `tests/fixtures/nm-office.json`, acceptance `tests/read_path.rs`.
- **Verified:** `cargo test -p dragonfruit-networkmanager` → 21 tests green
  (16 lib + 5 integration); `make e2e` → exit 0; `make clippy` and
  `cargo fmt --all -- --check` clean.
- **Deviation / decision:** concrete adapters get their own crate so the
  dependency-free contract crate stays free of the D-Bus stack; recorded as
  ADR `0026`. `make e2e` now also runs `cargo test -p
  dragonfruit-networkmanager`.
- **T-07.2b must know:** extend `dragonfruit-networkmanager`; the transport
  seam is `NetworkManagerSource::read` (`Ok(Some)` data / `Ok(None)` absent /
  `Err` present-but-failed). Add the activate/join call there and classify a
  polkit denial as a recorded read-only condition — do **not** add a poll loop
  above the adapter. `DbusNetworkManager` currently reads only; the signal
  subscription (`PropertiesChanged`, `DeviceAdded/Removed`) and the host that
  drives `refresh()` are still unowned (T-07.5 decides the bridge).
- **Not done here:** the real D-Bus source is compile-checked but not
  exercised in CI (no bus/daemon); the shell/QML binding of the Wi-Fi slot is
  T-07.5. `refresh()` is explicit; no background subscription thread yet.
- **Live visual check:** launched the nested demo (`make demo`, host session
  `wayland-0`) and captured `docs/captures/t07-networkmanager.png` (3840×2160,
  matching the T32/T33 captures). This unit has no surface of its own, so the
  check is that the desktop rendered: the demo log shows the shell authenticated,
