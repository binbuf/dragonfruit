## Goal

Draw a functional SSD titlebar for Tier-2 windows from design tokens, with no interaction yet, so the decoration exists and its geometry/insets are assertable.

## Scope

- New compositor render element for the SSD titlebar sized from design-system tokens (height, padding, traffic-light size).
- Flat token fill; square corners (materials are T-04).
- Traffic-light close/minimize/zoom glyphs with hover and disabled *drawing*; left-side placement.
- Titlebar sits above the window surface in the element list; client input regions untouched (no behaviour yet).
- Titlebar insets offset the client area through the existing `configure_window_size` path only.

## Explicitly deferred

- Shadows/blur/rounded corners (T-04).
- All titlebar interaction (T-01.2).
- Third-party themes (T-14).

## Acceptance (agent-completable)

- [x] A mapped Wayland toplevel carries a titlebar element with the expected insets; a CSD client does not.
- [x] An X11 Tier-2 window carries the same titlebar.
- [x] Client area is configured below the titlebar.

## Test plan

- Headless: map a Wayland toplevel, assert the titlebar element and insets; assert a CSD client has none.
- Regression: `window_conformance` stays green.

## Hand-off

Landed (T-01.1):

- `compositor/src/window/decoration.rs`: `TitlebarElement`,
  `WindowInsets`, `TrafficLightKind`/`TrafficLightButton`, `ColorScheme`.
  `TITLEBAR_HEIGHT == 40` from `component.titlebar.height`. The titlebar is
  directly *above* the content (`y = content.y - 40`), full width; the three
  left-side lights are laid out with the `traffic_lights` tokens. Hover
  reveals axis-aligned glyph marks; disabled draws the muted fill with no
  glyph. `button_at`/`hit` are ready for T-01.2's hit-test.
- `DfState::titlebar_element(window)` and `DfState::insets_for(window)`;
  `zoom_window` insets its usable target by the titlebar, so the client is
  configured `usable - 40` tall through `configure_window_size` (the single
  geometry path). Fullscreen hides the titlebar and reserves nothing.
- Wayland tier: default `ServerSide`; only an explicit `xdg-decoration`
  `ClientSide` request gets no titlebar (`state.rs::toplevel_decoration_tier`,
  `apply_decoration_mode`). X11 Tier-2 unchanged.
- Rendering: `render::titlebar_render_elements` builds flat
  `SolidColorRenderElement`s; nested and DRM gained a
  `Decoration = SolidColorRenderElement` element variant.
- Test plumbing: `query decorations` on the T-03 synthetic-input socket
  (sender must bind a reply socket).

Deviations / notes:

- `window_conformance`'s maximize assertion now expects
  `OUTPUT_H - TITLEBAR_HEIGHT` (was `OUTPUT_H`).
- The glyphs are placeholder solid marks (no vector rasterizer yet); the
  scheme is hardcoded `Dark` until T-08. Both are T-04/T-08 follow-ups.
- `docs/PROGRESS.md` has the full T01 section.

Next tasks:

- T-04 replaces the flat fill with the material pass; keep
  `render_elements` pluggable.
- Fullscreen hover reveal (hide + reveal) is T-01.3.
