## Goal

Vendor the [Phosphor](https://phosphoricons.com/) icon set (MIT) into `assets/`,
expose it to QML at a stable resource path, and add one reusable `PhosphorIcon`
primitive that renders a named glyph tinted to a color at a size. This is the
foundation the three migration units (T-19.1b/c/d) consume; it renders no
Dragonfruit chrome on its own.

## Context (read first)

- `design-system/components/Icon.qml` — the inherited **original-geometry**
  glyph vocabulary. It stays; this unit adds an image-backed path beside it.
- `design-system/CMakeLists.txt` — `qt_add_qml_module(URI Dragonfruit …)` and
  `df_qml_lint`; the new resource set and component register here.
- `assets/fonts/Inter/` + `NOTICE` §Bundled assets — the precedent for a
  vendored third-party asset and its license/attribution bookkeeping.
- `docs/design/14-risks.md` §Intellectual property — the original-assets rule.
  Phosphor is MIT (not Apple artwork), so it is permitted, but the departure
  from "all geometry is ours" needs an ADR.

## Scope

- [ ] Vendor a **pinned** Phosphor release under `assets/icons/phosphor/` (the
      chosen weight's SVGs + the upstream license). Record the version/weight.
- [ ] Add Phosphor to `NOTICE` (Bundled assets) and `LICENSES/`; add an ADR
      recording the third-party-icon decision and the rule that a glyph is a
      *resource* while all styling stays in QML.
- [ ] Expose the SVGs through the design-system module resources with a stable
      prefix, referenced as `qrc:/icons/phosphor/<name>.svg`. A referenced glyph
      that does not exist must fail the build, never fall back silently.
- [ ] Add `design-system/components/PhosphorIcon.qml`: properties `name`,
      `color` (default `Theme.color.textPrimary`), `size`, and an optional
      `weight`. It resolves the name to the resource path, tints the monochrome
      glyph to `color`, and keeps the glyph's aspect. Confirm the Qt 6.11 tint
      mechanism (e.g. `MultiEffect` colorization); if tinting is unreliable,
      ship near-white fills and document the choice.
- [ ] Register it in `design-system/CMakeLists.txt` (`qt_add_qml_module` +
      `df_qml_lint`) and add a gallery section + snapshot.

## Out of scope

- Any Dragonfruit chrome that *uses* the glyphs (→ T-19.1b/c/d).
- Replacing `Icon.qml`; it remains for marks not migrated.
- A dark/light swap of the glyph files (one tinted set serves both schemes).

## Design notes

- Keep the glyph and its styling separate: never bake a color/container into an
  SVG that the component should own.
- The existence check is the guard that stops a typo shipping as a blank mark.
- Keep the primitive dumb: no category gradients, no container — those belong
  to `SettingsCategoryIcon` (T-19.1b).
