## Goal

Bound the chooser's visible rows (a token, default 7) and scroll the rest below
a pinned `Show All Windows` header, so an app with many windows never produces
an off-screen or output-clipped popover. The row action buttons from T-14.7m
stay reachable for every row.

## Context (read first)

- `shell/dock/DockWindowChooser.qml` — currently a `Column`/`Repeater` whose
  height is the full window list; no viewport, no scrollbar, no cap.
- `shell/dock/DockStackPopover.qml` — the existing pattern to mirror: a
  `maxItems` viewport with a `ScrollView` and a `“…N more…”` summary row
  (`~24`, `~239`, `~317`).
- `shell/src/shellcontroller.cpp` `renderDock` — the pre-sized popover buffer
  and headroom (ADR 0100); the chooser must stay inside it and must not resize
  the surface.
- `design-system/tokens/tokens.json` — `component.dock.*`; add a chooser group
  (max rows, row height already in `controls.contextMenu`, scrollbar width).
- `shell/tests/tst_dock.qml` — geometry/rows cases to extend.

## Current behavior (investigated, T110 era)

- A 15-window app produces a chooser taller than the output; the headroom path
  clamps the surface, but rows are not reachable by scroll and the header is not
  pinned.

## Scope

- [ ] Token `component.dock.chooser.maxRows` (default 7) plus any needed
      scrollbar/gutter values in `tokens.json`; regenerate `Theme.qml` (never
      edit it by hand).
- [ ] Convert the row list to a bounded viewport (a `ScrollView`/`Flickable`
      with `StopAtBounds`) whose height is `min(rows, maxRows) * rowHeight`; the
      `Show All Windows` header and separator stay pinned above it.
- [ ] Keep the existing behavior for short lists (no scrollbar, no reserved
      gutter) and clamp the popover to the output/headroom.
- [ ] Keyboard: arrow navigation keeps the focused row scrolled into the
      viewport; Home/End jump within the list.
- [ ] Tests: `tst_dock.qml` for the viewport cap, header pinning, scrollbar
      presence only when needed, keyboard scroll-into-view, and the unchanged
      short-list geometry.
- [ ] Capture `docs/captures/t14-dock-chooser-scroll.png` (a long list scrolled)
      and the `PROGRESS.md` note.

## Explicitly deferred

- Live thumbnails and rich rows (deferred preview protocol, ADR 0103).
- Grouping rows by Space or by minimized state; search/filter inside the
  chooser.
- A "N more…" summary row (the ScrollView viewport is the chosen form; the
  stack popover keeps its summary pattern).

## Design notes

- Reuse the stack popover's proven viewport math rather than inventing a second
  scroll idiom; keep the `maxItems`-style cap in tokens, not literals.
- The chooser's height is part of `popoverRect`; changing it must not force a
  window resize (ADR 0100) — the buffer already carries the headroom.
- The header is the `Show All Windows` action; it must never scroll away.
