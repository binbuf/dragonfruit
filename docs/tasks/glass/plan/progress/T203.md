# T203 — Control Center panel, module and expanded-list materials

## What landed

- `design-system/tokens/tokens.json` Control Center presets now carry the
  measured capsule optics and distinct calibrations:
  - `controlCenterOuter`: Light 0.265/0.373, Dark 0.489/0.677, blur 8,
    edge 0.30, edgeWidth 1, edgeTail 6, sharpFraction 0.10, corner lens
    6 pt / 24 pt / 50 pt.
  - `controlCenterModule`: Light 0.391/0.317 (the measured effective fit used
    as the opaque module's final composite), Dark adapted 0.65/0.44, same
    capsule optics.
  - `controlCenterExpanded`: Light adapted 0.94/0.96, Dark observed-luma
    0.96/0.13, softer inner rim 0.22 / 4 pt lens.
- `scripts/material_presets.py` validates the flat-band/lens fields for the
  Control Center presets as well as the Dock.
- `compositor/src/material_preset.rs` loads the optional lens fields for the
  Control Center family; `compositor/src/render.rs` resolves the same flat-band
  glass model for `controlCenterOuter/Module/Expanded` on the replacement rail
  and uses the preset blur instead of the generic popup blur.
- `compositor/src/shell/layer.rs` raises `MAX_PANEL_REGIONS` from 8 to 32
  (outer + 19 modules + up to two expanded lists). The conformance test mirrors
  the new bound.
- `shell/src/shellprotocol.{h,cpp}` gains
  `setControlCenterPanelRegions()` / `clearControlCenterPanelRegions()`
  (commit-latched with the panel image, same wire shape as the popup regions).
- `shell/src/shellcontroller.cpp` declares the regions before each panel
  commit, clears them on hide, re-renders when `materialRegions` changes,
  seeds expanded state from `DF_CONTROL_CENTER_FIXTURE`, and implements the
  capture-only `DF_CONTROL_CENTER_ABSENT` adapter mask.
- `shell/control-center/ControlCenter.qml`:
  - resolves `controlCenterOuter/Module/Expanded` through `Glass.resolve`;
  - hides QML fills on the sampled path, paints the resolved tint/alpha on
    solid/software/Reduce Transparency;
  - declares `outer`, `module-*`, `expanded-wifi`/`expanded-bluetooth` regions,
    clipped to the scroll viewport;
  - adds expandable Wi-Fi network and Bluetooth device lists with accessible
    disclosure links, and keeps the existing toggle/settings actions;
  - uses light-on-glass module foreground in sampled Light and scheme text in
    the expanded lists;
  - keeps `Flickable.StopAtBounds`, the existing focus order and the full-panel
    input region.
- `shell/tests/tst_controlcenter.qml` adds six T203 cases: distinct regions,
  solid/contrast fallback, expansion regions, scroll bounds, disclosure
  accessibility and light-on-glass foreground.
- `scripts/t203-control-center.py` is the fixture/check/scorer;
  `scripts/capture-t203-control-center.sh` runs 14 nested cases and
  `make control-center-materials-capture` records them.
- Docs: ADR 0222, `docs/design/10-design-system.md`,
  `docs/design/02-compositor.md`, `docs/private-protocols.md`,
  `docs/rendering.md`.

## Region / preset / adapter mapping

| Region key | Preset | Extent |
|---|---|---|
| `outer` | `controlCenterOuter` | whole 360×1164 panel, radius 28 |
| `module-wifi` … `module-clipboard` | `controlCenterModule` | each visible tile, radius 10, clipped to the scroll viewport |
| `expanded-wifi` | `controlCenterExpanded` | open Wi-Fi network list, radius 6 |
| `expanded-bluetooth` | `controlCenterExpanded` | open Bluetooth device list, radius 6 |

Adapters: Wi-Fi (`wifi.networks`), Bluetooth (`bluetooth.knownDevices`),
Storage, Focus (notification service), Sound (audio), Display (brightness),
Dark Mode (settingsd), Keyboard (input), Mission Control (shell projection),
Battery, Lock Screen (shell projection), Menu Bar (shell projection), Software
Update (updates), Users (accounts), Printers, Privacy, Accessibility, VPN and
Clipboard. `DF_CONTROL_CENTER_ABSENT=bluetooth,storage,...` replaces those
views with `state: unavailable` for the absent-adapter captures only.

## Reusable facts / gotchas

- `DF_CONTROL_CENTER_FIXTURE=expanded|wifi|bluetooth|hold`,
  `DF_CONTROL_CENTER_HOLD=1`, `DF_CONTROL_CENTER_ABSENT=<csv>`. The hold timer
  reopens the panel while a capture script cycles tiers.
- Nested capture needs `FORCE_TIER=full`; the host throttles `submit()` and the
  degrade controller otherwise reaches Minimal and paints the solid fallback.
- The compositor flat-band shader output is opaque. Do not decompose the
  measured effective alpha and stack it over the outer; use the effective fit
  directly for the module region. The outer remains visible around capsules.
- QML `mapToItem` does not register a binding dependency on `item.x/y`. The
  region binding reads those explicitly, otherwise every module region keeps
  the pre-Column-layout y=0. The shell also re-renders on
  `materialRegionsChanged`.
- `query scale` prints every `control-center` region with preset/logical rect;
  the scorer parses that instead of guessing geometry.
- The nested capture output was 2880×1800 in this host (kwin virtual), not
  1920×1200; the scorer uses the query rects so it is size-independent.
- Remove each `$SOCKET.session` after a full-session case or the runtime tmpfs
  fills; the T203 script does this.
- `cargo clippy` still reports pre-existing excessive-precision literals in
  the generated motion curve (`design_tokens.rs`); not part of `make gates`.

## Follow-ups

- Wi-Fi network rows are a read-only projection. If the Control Center should
  join networks, add a `wifiJoinRequested(ssid)` signal and route it through
  the existing `SystemStatusClient::join` path; keep the Settings link.
- The Light expanded-list and dark module values are adapted; recapture with a
  controlled light expanded-list backdrop and a dark module decomposition if
  the reference checkout gains them.
- If future modules push past 32 regions, group adjacent tiles or raise the
  bound with the same conformance-test update; do not silently drop regions.
- The T203 scorer's neutral/grid wallpapers are generated at capture time; add
  a committed fixture if the capture rail moves off the nested compositor.
