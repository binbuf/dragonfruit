# T198 — Dock optics fit and capture

## What landed

- Dock preset tokens (`design-system/tokens/tokens.json`, both schemes):
  `sharpFraction` 0.12, `edgeTail` 6 pt, `cornerLensPeak` 9.6,
  `cornerLensDistance` 15, `cornerLensTail` 50. `scripts/material_presets.py`
  validates them and the generated `Theme.glass`/`design_tokens::glass` carry
  them.
- `compositor/src/window/dock_optics.rs`:
  - `DockOptics::light()/dark()`, `checker_mtf`, `rim_profile`,
    `corner_displacement`, `flat_edge_displacement`.
  - `DOCK_SCALE_WEIGHTS = [0.12, 0.26, 0.40, 0, 0, 0.22]` for
    `[sharp, level1, level2, level3, level4, level5]`.
  - `DOCK_BLUR_ITERATIONS = 5`.
  - Tests pin the 2/4/8/16/32 pt targets within 0.05, rim peak/half/tail and
    corner peak/flat edge.
- `compositor/src/window/blur.rs`:
  - `BlurSpec::for_dock` (5 iterations + sharp weights), `BlurSpec::scaled`
    preserves them through degrade tiers.
  - `GlassSpec` gained `flat_band`, `flat_alpha`, `rim_peak`,
    `rim_half_width`, `rim_tail`, `corner_peak/distance/tail`; the shader
    reconstructs panel-relative UV from `panel_uv_offset/scale` and uses
    `uv_per_px` for clipped/fractional panels.
  - The flat-band shader path mixes toward the neutral tint, adds an
    exponential rim and a corner-only lens; the legacy adaptive tint path is
    unchanged for every other role.
  - `TextureRenderer::draw_texture_from_to` now takes an explicit alpha for
    the composite passes.
- `compositor/src/backend/nested.rs` + `drm.rs`:
  - The Dock composite uses a **panel-physical** Kawase chain, then draws the
    sharp scene and levels 1/2/5 into one panel-resolution texture with
    source-over weights. Other roles keep the full-output chain base.
  - Trace: `DFTRACE dock-optics composite weights=… panel=… scale=… composite=…`
    with `DRAGONFRUIT_FRAME_TRACE=1`.
- `compositor/src/render.rs`: the Dock preset builds `BlurSpec::for_dock` and
  `GlassSpec::for_dock`, then overrides alpha/tint/edge/edge-width from the
  resolved preset so Increase Contrast is visible.
- `shell/dock/Dock.qml`: `glassOptics = Glass.resolve("dock", …)`,
  `sampledPlate` hides the QML fill/gloss/rim/edge/border/shadow on the
  sampled path. Fallback/reduce-transparency paint the resolved neutral
  plate (legacy keeps the milky fallback). `shell/tests/tst_dock.qml` covers
  sampled, fallback and replacement-resolved cases.
- Capture/evidence: `make dock-optics-capture` →
  `scripts/capture-t198-dock-optics.sh` + `scripts/t198-dock-optics.py`.
  It starts `kwin_wayland --virtual` when the host has no mapped nested
  window, seeds a scratch settingsd with the checker wallpaper and scheme,
  captures the compositor's own render, dumps `query scale`/`query material`,
  scores the flat band/MTF/rim/flat edge, and runs a moving sweep with the
  material counters.

## Results

- 1x (1920x1200) light/dark/Reduce Transparency/Increase Contrast: pass.
  Light worst MTF delta +0.038, dark -0.023, rim 0.399 vs 0.397, half 0.75 pt,
  tail 5.5 pt, flat edge 0 pt. Reduce Transparency is solid and scored on the
  opaque plate. Increase Contrast resolves edge 0.747/width 1.5 and the
  captured rim is clipped on light.
- 1.5x/2x captures are recorded but MTF/rim are OPEN: the nested scene-texture
  scale path attenuates the backdrop more than the 1x calibration. See
  `docs/captures/t198-dock-optics.md`.
- Sweep: `material_allocations=41`, `material_region_px=2304000` flat across
  two snapshots; `blur_skips=1772`, `blur_miss_source=8`, `blur_miss_spec=1`,
  `blur_miss_scene=0`, `blur_miss_chain=0`.

## Reusable facts

- `python3 scripts/t198-dock-optics.py model` prints the fitted curve.
- `python3 scripts/t198-dock-optics.py wallpaper --out … --width … --height …
  --scale S` writes the vertical multi-sine checker; `--flat` writes mid-grey.
- `python3 scripts/t198-dock-optics.py score --capture … --query … --out …`
  reads `scale region dock …` and `material preset=dock …`.
- Periods are logical points; at 2x the reference capture pixels
  4/8/16/32/64 are 2/4/8/16/32 points. The scorer divides raw AC by
  `1 - alpha` to separate flat band from the filtered response.
- The capture script needs `/run/user/<uid>` space: full-session scratch XDG
  trees are ~150 MB each. `t21-live-capture.sh` now prefers the compositor's
  `$CAPTURE` over the shell's possibly-zero-length screenshot copy, and the
  T198 script removes each `$SOCKET.session` after the case.
- `kwin_wayland --virtual --fullscreen 1 --socket … --width 3840 --height 2446`
  gives a 3840x2400 client after the 46 px decoration; request the nested
  window with `DRAGONFRUIT_NESTED_SIZE=WxH` (new capture-only seam).
- `t21-live-capture.sh` gained optional `WALLPAPER_SOURCE`, `WALLPAPER_FIT`,
  `COLOR_SCHEME`, `REDUCE_TRANSPARENCY`, `INCREASE_CONTRAST`, `QUERY_OUT`.
