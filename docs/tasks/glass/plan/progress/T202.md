# T202 — menu-family glass

## What landed

- **Three presets, one mapping.** `menuAttached` (menu-bar dropdown),
  `menuDetached` (tray/Dock/app context menus), `statusMenu` (Wi-Fi,
  Bluetooth, volume, battery). Submenus are detached cards. QML resolves
  through `Material.menuResolution()`/`menuFill()`; the compositor resolves
  the same generated presets through `material_preset`.
- **Attached geometry.** `component.contextMenu.attachedRadius = 12.5` and
  `closeScale = 0.95`. `Popup` squares the attached top corners while keeping
  the bottom pair rounded; detached/status cards stay all-rounded. The
  menu-bar dropdown is flush to the bar (`popupAnchorOffset`).
- **Per-region shell metadata.** `ShellProtocol::setPopupPanelRegions()` and
  `setDockPopupPanelRegion()` declare the open panels with key/preset/corners/
  overscan on `menubar-popup`/`dock-popup`. `setPopupInputActive()` /
  `setDockPopupInputActive()` accept pointer input only while logically open.
- **Measured exit.** `motion.menuClose.duration = 183` and terminal scale
  0.95; `Popup`/`ContextMenu` translate/scale toward the anchor. The shell
  releases input and clears the decorative panel at close start, keeps the
  overlay mapped for a 210 ms tail, and cancels the unmap on reopen/retarget.
  Reduce Motion disables the Behaviors and sets the terminal scale to 1.
- **Light slider.** Light `menuAttached` keeps the measured anchors. Light
  `menuDetached`/`statusMenu` use `slider: "lightRelative"`: alpha scales by
  the attached alpha ratio, tint takes the attached tint delta; the default
  fit is unchanged. Dark presets do not follow the light slider.
- **Dark File calibration.** Dark attached is anchored to the valid dark
  mid/black context/status family (`0.66/0.26`) and mixed 25% toward a deeper
  adapted baseline (`0.6425/0.2775` resolved), distinct from dark detached.
  The contaminated white crop stays rejected/open.
- **Local fallback.** `ContextMenu` defaults to `materialBackdrop: "local"`,
  so Files/desktop/Select paint the opaque scheme plate under replacement.
  The tray and Dock set `trusted`.
- **Bluetooth status menu.** New `shell/menubar/BluetoothMenu.qml` reads the
  existing bridge-host view, honours `menu.control.bluetooth`, and raises the
  Control Center tile's power/device/settings actions. Absent hides; error or
  `readOnly` stays visible but inert.
- **SSD menu.** `compositor/src/window/menu.rs` resolves `menuDetached` and
  uses the opaque local fallback in replacement; geometry/hit-testing is
  unchanged.
- **Evidence/check.** `scripts/t202-menu-families.py` (`make
  menu-families-check`, in `make gates`) pins alpha/blur/shadow/corner/slider/
  dark/fallback/motion. `make menu-families-capture` writes nine nested
  stills plus `docs/captures/t202-capture.json`.

## Reusable facts / gotchas

- `Material.menuFill(preset, blurActive, tier, fallback, trusted)` is the one
  menu complement. `trusted=false` resolves `software` (opaque); the legacy
  rollout still returns `popupFill()`.
- `Popup` uses `motionPreset: "menu"` for menu timing; the generic popup keeps
  `popupOpen/popupClose`.
- `Popup`/`ContextMenu` Behaviors are `enabled: !Theme.reducedMotion` so the
  reduced-motion structural sweep sees them; do not replace with a bare
  duration property or the sweep fails.
- Shell close timers are 210 ms (183 ms motion + margin). Do not reduce below
  the token or the exit is clipped.
- `setPopupPanelRegions` is commit-latched: call it before `render()` commits
  the popup pixels. `clearPanelRegions` + empty input region is the close
  contract.
- The full-session capture rail leaves a large `$socket.session` under
  `XDG_RUNTIME_DIR`; `capture-t202-menus.sh` removes it after each case or the
  1.3 GB runtime tmpfs fills after a few runs.
- Capture seams: `DF_MENUBAR_MENU_FIXTURE=<index>`,
  `DF_STATUS_MENU_FIXTURE=<wifi|bluetooth|volume|battery>`,
  `DF_DOCK_MENU_FIXTURE=1`, `DF_DESKTOP_CONTEXT_FIXTURE=1`.
- The `query scale` dump in a capture is taken before the fixture menu opens
  in some runs; use the screenshot plus `query material` for optics, and a
  separate live query if region text is needed.
