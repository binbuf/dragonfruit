# T194 — reference evidence and baseline

## What landed

- `docs/captures/glass-reference-manifest.json` pins revision
  `063a473cf06d0dba5cb83bd56c40b6fc88df2931` and 15 source files, 33 JSON
  sections, 6 analysis scripts, 13 ICC-converted crops and 8 gaps. It records
  the Display P3 → sRGB assumption, crop rects in both capture pixels and
  logical points, and SHA-256 hashes.
- `scripts/t194-reference-manifest.py` writes/verifies the manifest. Root
  resolution is `--reference-root` → `DRAGONFRUIT_REFERENCE_ROOT` →
  `../macos-liquid-glass`. A requested run exits 2 with a clear message on a
  missing root, revision mismatch, missing source, or source/script/JSON/crop
  hash mismatch. `--check-manifest` is the no-checkout structural check.
- `scripts/glass_compare.py` and `scripts/t194-glass-compare.py` implement
  ICC-aware sRGB loading, bounded logical registration, per-metric masks, and
  independent colour / geometry / MTF / motion / timing scores. Missing or
  zero coverage is `missing`, never a pass.
- `tests/glass/` contains deterministic 160×120 neutral, checker, line-grid
  and saturated fixtures, a two-frame motion pair, per-case specs, derived
  `targets.json`, and `provenance.json`. `tests/glass/run_selftest.py`
  regenerates in a temp dir and proves detection of intentional colour, crop/
  geometry, MTF, motion, registration and timing regressions (120 checks).
- `docs/captures/t194-glass-baseline.json` / `.md` record twelve surface crops
  (Dock, bar, attached menu, detached menu, Control Center, banner; light and
  dark), stationary/moving backdrop evidence (including the native
  `t21-native-{dark,light}-live-under-dock-2x.png` moving test panel), and the
  T-21 stationary idle / moving Dock-sweep counters (frames, skipped frames,
  material allocations, region px, shm/dmabuf transport, p95 commit/callback).
  The environment row names backend nested, 1920×1200, scale 1, 144 Hz
  override, full material, `path=gpu`, `render-control+dmabuf`.
- `docs/captures/t194-glass-baseline.open.txt` is the explicit host-capture
  OPEN row. This session's host is a native Dragonfruit session whose
  `spectacle` probe exits non-zero and whose nested compositor never gets its
  window mapped (no Wayland socket within 10 s). The probe logs are committed
  next to the OPEN artifact.
- `docs/design/adr/0213-glass-reference-manifest-and-comparison.md` records the
  manifest/registration/mask decisions.
