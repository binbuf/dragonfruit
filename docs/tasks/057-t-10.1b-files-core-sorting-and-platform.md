## Hand-off

Landed T-10.1b in `services/files-core/` (`dragonfruit-files-core`): sorting
over the streaming model and the finalized fallback decision. See
[adr/0043](../../design/adr/0043-files-core-fallback-is-the-shipping-backend.md).

- **Sorting** — `sort.rs` (new) adds `SortKey` (name/kind/size/modified),
  `SortDirection` (ascending/descending), and `SortSpec` (key, direction,
  `folders_first`). Name collation is dependency-free natural/numeric
  (`file2` before `file10`), case-insensitive with a case-sensitive
  tie-break; locale-aware collation is deferred. `SortKey`/`SortDirection`
  round-trip through `as_str`/`parse` for the future bridge/persistence.
- **Incremental + stable** — `DirectoryModel` keeps arrival order in
  `nodes()` and a separate sorted projection (`ordered()`,
  `ordered_indices()`, `ordered_node`, `ordered_position_of`). Each batch is
  stable-sorted and merged into the projection in O(n); `set_sort` re-sorts
  what is loaded in place. Equal keys keep arrival order; node ids never
  change, so selection survives a re-sort. `check_consistent()` now also
  asserts the projection is a permutation and is stable-sorted.
- **Fallback finalized** — GIO headers are absent from the pinned toolchain
  (`pkg-config --exists gio-2.0` fails), so `StdFsSource` stays the shipping
  backend behind the unchanged `DirectorySource` seam.
  `SANCTIONED_FALLBACK_MARKER` now names GIO/GVfs, the seam, and ADR 0043;
  the fallback still resolves only `file://` and refuses foreign schemes.
- **Tests** — `cargo test -p dragonfruit-files-core`: 39 pass (27 unit + 5
  `tests/sorting.rs` + 6 `tests/streaming.rs` + 1 doctest). Sorting tests
  cover natural order, case handling, leading zeros, folders-first not
  reversing on descending, size/kind/modified keys, per-batch sorted
  projection over a 600-file stream, stability, and re-sort without
  renumbering. Existing T-10.1a streaming tests still pass unchanged.
- **Gate** — `make lint` 31/31; `make e2e` exit 0.
- **Live visual check** — files-core has no surface. Nested demo capture
  `/tmp/opencode/t57-desktop.png` (1920x1200): menu bar, Dock, and the
  Settings window render with no artifacts. The only oddity vision reported
  (an X11 demo-window title clipped at its right edge) is the pre-existing
  demo client, not Files. Vision is a supporting check only.

Deferred / next: T-10.2a adds operations on top of this model. Trash/Recents/
volumes still return `UnsupportedScheme` under the fallback, so T-10.3a must
add a GIO reader or explicitly degrade. Locale-aware collation and the
cross-locale matrix remain open.
