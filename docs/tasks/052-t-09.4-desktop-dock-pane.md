**Sections and rows (observed order):**

- **Dock**:
  - `Size` — slider, `Small`/`Large` captions → `dock.size`
  - `Magnification` — slider, `Off`/`Small`/`Large` → `dock.magnification`
  - `Dock position on screen` — popup (`Bottom`) → `dock.position`
  - `Minimized window animation` — popup (`Genie Effect`) →
    `dock.minimizedAnimation` (genie/scale/none)
  - `Window title bar double-click action` — popup (`Zoom`) →
    `dock.titlebarDoubleClick` (zoom/minimize/none)
  - `Minimize windows into application icon` — toggle →
    `dock.minimizeIntoTileIcon`
  - `Automatically hide and show the Dock` — toggle → `dock.autohide`
  - `Animate opening applications` — toggle → `dock.animateOpening`
  - `Show indicators for open applications` — toggle → `dock.showIndicators`
  - `Show suggested and recent apps in Dock` — toggle → `dock.showRecentApps`
- **Desktop & Stage Manager**:
  - `Show items` — segmented (`On Desktop`/`In Stage Manager`) → Desktop
    Reveal (T-05.5) layer; `In Stage Manager` omitted
  - `Click wallpaper to show desktop` — popup (`Always`) → Desktop Reveal
    (T-05.5)
  - `Stage Manager` — toggle; omitted (Apple-only)
  - `Show recent apps in Stage Manager` — toggle; omitted (Apple-only)

Grouped inset sections, right-aligned controls, popups with a trailing
chevron; `dock.pinned` has no reference row (macOS reorders by drag).

**Adapt or omit (Apple-only):**

- Stage Manager and `Show recent apps in Stage Manager`.
- `Show suggested and recent apps in Dock` if no backend (decide at
  implementation).
- Apple-account touchpoints (sidebar/header).

## Hand-off

**State: done.** The Desktop & Dock pane is real and live: the `Dock` group
ships all ten `dock.*` control rows bound through the `Settings` singleton, and
the shell re-lays-out the Dock from the settingsd `Changed` (its existing
T-08.2a applier) — no restart, one interaction beat.

What landed:

- **`apps/settings/DesktopDockPane.qml`** (new) — `SettingsGroup` "Dock" with
  `Slider` (Size `Small`/`Large`; Magnification `Off`/`Small`/`Large`),
  `Select` (position / minimized animation / titlebar double-click), and
  `Toggle` (minimize-into-icon, auto-hide, animate opening, indicators, recents)
  rows. Every control uses the T-09.1b two-way pattern.
  Registered in `SettingsShell.paneComponent("desktop-dock")`; the catalog row
  was already `shipped: true`.
- **`design-system/components/Slider.qml`** (new) — a continuous `[from,to]`
  slider with optional end/mid captions, drag/tap/arrow/Home/End, `moved` +
  `committed` intent signals, `FocusRing`, and AT-SPI `Slider`. Tokens
  `component.slider`.
- **`design-system/components/Select.qml`** (new) — a value-popup row (current
  label + chevron) over the existing `ContextMenu`; AT-SPI `ComboBox`. Tokens
  `component.select`.
- **Tests** — `apps/settings/tests/tst_settings_desktop_dock.{cpp,qml}`
  (10 cases, `DF_SETTINGS_FIXTURE=1`): pane wiring, each slider/select/toggle
  applies live, external changes converge, right-aligned controls.
  `design-system/tests/tst_design_system.qml` gained 5 Slider/Select cases;
  gallery pages `Slider`/`Select` and `scripts/check-gallery-snapshots.py`
  updated.
- **Docs** — ADR
  [0039](design/adr/0039-slider-and-select-design-system-components.md);
  track 09 "Desktop & Dock pane (T-09.4)"; `10-design-system.md` component list.

Commands that work (repo root; `make` sets the toolchain env):

- `ctest --test-dir build -R "tst_settings_desktop_dock|tst_design_system"`
  — both pass (10 + 40 cases).
- `make qml-test` 27/27; `make lint` green; `make visual-test` — 72 snapshots;
  `make e2e` exit 0.
- Live capture (`/tmp/opencode/t52-capture.sh`, stills
  `/tmp/opencode/t52-{before,scrolled,after}.png`): real `dragonfruit-settingsd`
  on the session bus, nested demo with `DF_SETTINGS_START_PANE=desktop-dock`,
  then `dock.size`/`dock.magnification`/`dock.showIndicators` changed
  mid-session. Raw observation: the pane slider knobs moved from ~0.5 to near
  "Large" and stayed in step. Vision on the maximized window read all ten rows —
  Size, Magnification, Dock position, Minimized window animation, Window title
  bar double-click action, the five toggles — with no clipping/overlap, and the
  header "Desktop & Dock"; the 900x620 window cuts the last row off until the
  window is zoomed, so the zoomed still is the complete one.

Deviations / scope notes:

- **Desktop & Stage Manager group omitted** (Show items, Click wallpaper to
  show desktop, Stage Manager): no schema keys exist for the Desktop Reveal /
  hot-corner layer, so per the no-half-panes rule the rows wait for T-15.5.
- `dock.pinned` deliberately has no row (macOS reorders by drag).
- Adding `Slider`/`Select` to the library was necessary (T-09.5 needs a
  Brightness slider); ADR 0039 records it. Gallery goldens were **not**
  regenerated (matching T-50/T-51): `make gallery-snapshot` rewrites all 72 due
  to host font differences, so the committed art-direction set is untouched and
  `make visual-test` (non-strict) is the gate.

Gotchas for later tasks:

- **`Select`'s menu is clipped by the pane's `ScrollView`** (like the existing
  `Popup`). Keep popup rows above the fold or host the menu in an overlay. The
  three Desktop & Dock popups are all near the top.
- A `Slider` writes via `moved` per drag step; bind `value` with a `Binding`
  element (the T-09.1b pattern), never a bare `value: Settings.values[...]`.
- `dock.*` keys are applied by `ShellController::applyDockSettings`; a pane only
  writes keys. `dock.minimizeIntoTileIcon` is Dock-entry visibility, not a
  compositor key.
