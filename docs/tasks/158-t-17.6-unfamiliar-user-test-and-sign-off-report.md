### The gate fix that unblocked `make check`

`make check` had been red since the T-14/T-03 work at
`check-desktop-names`: the gate matched third-party identifiers
(`org.kde.StatusNotifierItem`, `org.gnome.Calculator.desktop`) and comments
naming the host desktop. T-17.6 corrected it (`scripts/check-desktop-names.sh`
strips `org.<name>.<member>` namespaces before matching; the host-desktop
comments were reworded; the one real hardcode —
`scripts/zoo/zoo-run.sh`'s `XDG_CURRENT_DESKTOP=Dragonfruit` — is now
lowercase). A bare desktop-name literal still fails. [ADR 0180].
