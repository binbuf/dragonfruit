Gotchas for later tasks:

- The capture script trims the host window decoration by cropping to the
  bottom-centred 1920x1200 output. It assumes the nested output is exactly
  1920x1200, like the other capture drivers.
- It raises the nested window with a best-effort KWin D-Bus script before
  `spectacle -a`, so a host window covering the nested session cannot crop the
  bar out. On a non-KWin host the active-window capture still needs the window
  in front.
- The host no-poll test does not spawn a timer/thread (the host has none); it
  guards the read seam. If a poll loop is ever added above an adapter, assert
  the counters here.
