# T244 — Preview (Quick Look)

## Goal

Add the Preview panel: spacebar preview for images/PDFs/videos/multiple items, navigation, actions, fullscreen, and close.

## Context (read first)

- T215/T218 captures
- `docs/design/09-files.md` (file opening), `docs/design/22-total-experience.md`
- Design-system components, portal/file renderers

## Reference UI/UX (macOS screenshots)

- Host: **Linux**. Reference inventory: `macos-liquid-glass-review/docs/SURFACE-INVENTORY.md`; capture plan: `macos-liquid-glass-review/docs/CAPTURE-PLAN.md`.
- Local macOS captures are reference only and never ship. Record the build/axes for every artifact.

## Scope

- [ ] Open on Space for the current selection; close on Space/Escape.
- [ ] Render image/PDF/video/text via a safe renderer/delegate; no shell execution.
- [ ] Navigation for multiple items; fullscreen; actions (Open, Show in Files, Share/Copy).
- [ ] Loading/error/unsupported states; keyboard/AX; reduced motion.
- [ ] Tests and captures for each content type.

## Out of scope

- A new document renderer for every format; delegate to Evince/Okular/mpv or Qt.
- Markup/annotation in the first pass.

## Design notes

Preview is a shell overlay, not a new app. It must not block the file manager or leak a file handle. Unsupported formats show an explicit state with “Open with…”. The panel material follows the glass popover/overlay role. Space closes only if Preview has focus; otherwise it opens.

- [ ] Hand-off filled in below.
