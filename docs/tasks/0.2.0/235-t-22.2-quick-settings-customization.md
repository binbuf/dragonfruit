# T235 — Quick Settings customization and expanded modules

## Goal

Make Quick Settings a customizable, live panel with the full module set and expanded sheets.

## Context (read first)

- T232 extras; T227 settings
- `shell/control-center/ControlCenter.qml`, `shell/src/controlcenterpolicy.*`
- `docs/reference/macos-ui-inventory.md` Control Center

## Reference UI/UX (macOS screenshots)

- Host: **Linux**. Reference inventory: `macos-liquid-glass-review/docs/SURFACE-INVENTORY.md`; capture plan: `macos-liquid-glass-review/docs/CAPTURE-PLAN.md`.
- Local macOS captures are reference only and never ship. Record the build/axes for every artifact.

## Scope

- [ ] Module registry: add/remove/reorder, menu-bar-only vs panel, per-display.
- [ ] Expanded sheets: Wi-Fi, Bluetooth, Focus, Screen Casting, Now Playing, Sound, Display, Battery.
- [ ] Live service state and absence for every module.
- [ ] Keyboard navigation, AX names, reduced motion, material tiers.
- [ ] Persist customization through settingsd; the shell observes.
- [ ] Check the liquid-glass Control Center tasks (T203) first.

## Out of scope

- A second Control Center implementation.
- New modules without an owner.

## Design notes

A module without a service is hidden or shows an explicit unavailable state. The panel never scrolls if the reference does not; if it must, the scroll behavior is designed. Customization is a management surface, not a second settings app. The panel and module materials are distinct (outer vs module) and come from the glass path.

## Done when

- [ ] Customization persists and changes the live panel.
- [ ] Every module opens its sheet and reflects live state/absence.
- [ ] Keyboard/AX/reduced-motion tests pass.
- [ ] Docs touched: the design doc(s) this task implements and the relevant `docs/design/STATUS.md` row.
- [ ] Hand-off filled in below.
