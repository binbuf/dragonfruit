# T237 — Dock motion: launch, bounce, minimize/genie, auto-hide, multi-display

## Goal

Match the Dock’s motion language: launch bounce, minimize/restore, auto-hide, reorder settle, and per-display behavior.

## Context (read first)

- T213/T218 motion; T236 behavior
- ADR 0218; `docs/design/motion-and-feedback.md`
- `shell/dock/Dock.qml`, `compositor/src/window/motion.rs`, `compositor/src/animation.rs`

## Reference UI/UX (macOS screenshots)

- Host: **Linux**. Reference inventory: `macos-liquid-glass-review/docs/SURFACE-INVENTORY.md`; capture plan: `macos-liquid-glass-review/docs/CAPTURE-PLAN.md`.
- Local macOS captures are reference only and never ship. Record the build/axes for every artifact.

## Scope

- [ ] Use the measured launch lift/bounce; do not invent an unresolved multi-bounce.
- [ ] Minimize genie/scale and restore; target mapping per `dock.minimizeIntoTileIcon`/`dock.minimizedAnimation`.
- [ ] Auto-hide reveal/hide interactive slide with measured delay/curve; reserved zone updates.
- [ ] Reorder settle, chooser open/close, tooltip timing, Trash progress.
- [ ] Multi-display/fullscreen behavior; reduced motion for every path.
- [ ] Check the glass Dock motion task (T199) first; implement only missing work.

## Out of scope

- Re-tuning the measured magnification profile (T198/T199).
- A second animation clock.

## Design notes

All motion uses the shared clock and tokens. A reverse input retargets from the current state. Reduced motion preserves the destination/state without travel. The Dock plate/hit targets follow the animation. A hidden auto-hide Dock reserves nothing. Capture p95 frame times.
