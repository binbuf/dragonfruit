## Out of scope

## Design notes

Input settings are live through the compositor; the pane never writes xinput/xkb files directly. Users/groups use accountsservice + distro adapter. Printers use CUPS/SANE. Battery uses UPower/PPD. Every row has an absence path. Check the liquid-glass Settings chrome task before styling.
