# T252 — Accessibility integration and shell AT-SPI

## Goal

Make the shell accessible: export chrome to AT-SPI, integrate Orca/speech-dispatcher, complete the magnifier/contrast/reduced-motion paths, and pass a keyboard-only audit.

## Context (read first)

- T229 Accessibility pane; T220 naming
- ADR 0154; `compositor/src/magnifier.rs`, `services/accessibility-adapter/`
- `docs/design/08-settings.md` accessibility section

## Reference UI/UX (macOS screenshots)

- Host: **Linux**. Reference inventory: `macos-liquid-glass-review/docs/SURFACE-INVENTORY.md`; capture plan: `macos-liquid-glass-review/docs/CAPTURE-PLAN.md`.
- Local macOS captures are reference only and never ship. Record the build/axes for every artifact.

## Scope

- [ ] Export menu bar, Dock, Quick Settings, notifications, OSD, overview, switcher, Search, drawer, lock to AT-SPI.
- [ ] Integrate Orca start/stop and speech-dispatcher read/announce.
- [ ] Magnifier: focus/pointer follow, zoom level, contrast/reduced motion.
- [ ] Keyboard-only audit of every core surface; visible focus.
- [ ] High-contrast/reduce-transparency/reduce-motion live paths.
- [ ] Update the Accessibility pane rows for every implemented/delegated feature (VoiceOver/Orca, Zoom, Hover Text, Display, Motion, Read & Speak, Hearing, Keyboard, Pointer, Switch Control, Shortcuts) with absence states.
- [ ] Tests, audit report, and captures.

## Out of scope

- Writing a new screen reader.
- Apple-specific accessibility features.

## Design notes

The offscreen QPA currently has no accessibility backend (G-19); this task must either add a Wayland/AT-SPI bridge or change the shell transport. Do not claim accessibility until the chrome is on the bus. A delegated service that is absent is disabled with a note. The audit must include a screen-reader spot check.

## Done when

- [ ] Shell chrome appears on AT-SPI and Orca can inspect/activate it.
- [ ] Keyboard-only audit passes for every core surface.
- [ ] Magnifier/contrast/reduced motion work; report/captures committed.
- [ ] Docs touched: the design doc(s) this task implements and the relevant `docs/design/STATUS.md` row.
- [ ] Hand-off filled in below.

## Live visual check (required)

- [ ] Run Orca and a keyboard-only pass over the Dock/menu/Quick Settings/Search; capture the focus and announcements.
