## Scope

- [ ] Stage: off/on, stage strip, recent apps, stage groups, drag to stage, fullscreen behavior.

## Out of scope

- A second window model.
- Full macOS Stage Manager parity if the capture is incomplete; implement the measured subset and mark the rest `OPEN`.

## Design notes

Stage is a window-management mode, not a second workspace model. Tiling uses compositor geometry and the same snap targets as drag-to-edge. A tiled window restores its previous frame. The stage strip is per-display. If the macOS capture is only onboarding, state the evidence gap and implement a conservative subset.
