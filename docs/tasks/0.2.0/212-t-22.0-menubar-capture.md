# T212 — Capture: menu bar and menu extras

## Goal

Capture the menu bar, system menu, application menus, status items, and their popovers in every important state.

## Context (read first)

- T209/T210 inventory and harness
- `docs/reference/macos-ui-inventory.md`
- `docs/design/04-shell.md`

## Reference UI/UX (macOS screenshots)

- Host: **macOS**. Reference inventory: `macos-liquid-glass-review/docs/SURFACE-INVENTORY.md`; capture plan: `macos-liquid-glass-review/docs/CAPTURE-PLAN.md`.
- Local macOS captures are reference only and never ship. Record the build/axes for every artifact.

## Scope

- [ ] Capture `S-MB-*`, `S-SYS-*`, `S-APP-*`, `S-ST-*` stills: desktop/app focus, light/dark, fullscreen, auto-hide, notch/overflow, multi-display, keyboard focus.
- [ ] Capture every system-menu item, submenu, confirmation, and update badge.
- [ ] Capture app-menu item states: enabled/disabled/checked/mixed/submenu/icons/shortcuts/dynamic items.
- [ ] Capture each status item and its menu: Wi-Fi, Bluetooth, Battery, Sound, Search, Quick Settings, Notifications, Date & Time, Focus, Screen Casting, third-party.
- [ ] Capture menu open/close/submenu as 120 fps motion and dump the AX tree.

## Out of scope

- Implementing the menu bar (T230–T235).
- Third-party app-specific menus beyond the representative set.

## Design notes

Record the focused app and its menu model. The menu bar’s material is already covered by the liquid-glass set; this task captures behaviour/labels/states. For the notch/overflow and multi-display rows, use hardware if available; otherwise write `OPEN`. Capture the calendar popover and date/time formats, including seconds and 24-hour mode.

## Done when

- [ ] Every `S-MB/S-SYS/S-APP/S-ST/M-*` id has a still/motion/AX artifact or an `OPEN` row.
- [ ] Menu open/close timing is captured at 120 fps with trigger timestamps.
- [ ] A coverage table lists captured/OPEN status items and apps.
- [ ] Docs touched: the design doc(s) this task implements and the relevant `docs/design/STATUS.md` row.
- [ ] Hand-off filled in below.

## Live visual check (required)

- [ ] Open the system menu and two status menus; compare labels, order, item states, and anchoring to the captures.
