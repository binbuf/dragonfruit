## Design notes

Ids are stable and append-only. Do not rename an id after a task cites it; add a new id and mark the old one superseded. The manifest is the index, not the artifact store. Every entry needs a trigger/script and a hash. The inventory must include the parts macOS does not expose on this build (Stage Manager onboarding, Siri/Spotlight merge, HUDs that need specific hardware) as explicit `OPEN` rows.
