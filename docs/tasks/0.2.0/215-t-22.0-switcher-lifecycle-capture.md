# T215 — Capture: app switcher and app lifecycle

## Goal

Capture the app switcher, Cmd+` window cycling, app launch/quit, Force Quit, and the window lifecycle motion.

## Context (read first)

- T209/T210 inventory and harness
- Track T-06 and T-02 captures
- `docs/design/05-window-decorations.md`

## Reference UI/UX (macOS screenshots)

- Host: **macOS**. Reference inventory: `macos-liquid-glass-review/docs/SURFACE-INVENTORY.md`; capture plan: `macos-liquid-glass-review/docs/CAPTURE-PLAN.md`.
- Local macOS captures are reference only and never ship. Record the build/axes for every artifact.

## Scope

- [ ] Capture `N-SW-01..12`: app/window mode, forward/backward cycling, many apps, minimized/hidden, cancel, commit, Cmd+`, multi-display.
- [ ] Capture `N-WIN-01..16`: open/close, minimize genie/scale, restore, zoom, fullscreen, drag/resize, focus, double-click, app quit, unexpected quit, Force Quit, launch bounce, reopen.
- [ ] Capture the switcher and window lifecycle at 120 fps.
- [ ] Dump AX labels/order for the switcher and Force Quit dialog.

## Out of scope

- Implementing the switcher/lifecycle (T241/T243).
- Stage/tiling (T242).

## Design notes

Record the app list, window counts, selected index, and trigger path. Distinguish app-mode from window-mode if the build exposes both. Capture a crash/Force Quit case without losing user data. Reduced motion for every transition.

- [ ] Switcher cycling/commit/cancel and window minimize/restore are captured at 120 fps.
- [ ] Force Quit and unexpected-quit states are captured.
- [ ] Docs touched: the design doc(s) this task implements and the relevant `docs/design/STATUS.md` row.
- [ ] Hand-off filled in below.
