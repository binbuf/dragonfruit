## Design notes

One state machine owns switch/overview/reveal. The grid uses live surfaces, not screenshots. Gesture transitions are progress-based/interruptible. The strip must not clip at the readable floor. Hot corners and gestures share settingsd policy. Multi-display never mixes outputs.
