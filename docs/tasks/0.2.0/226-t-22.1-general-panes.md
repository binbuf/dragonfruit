## Scope

- [ ] About: hostname, OS, kernel, CPU, memory, GPU, disk, serial where permitted; More Info.
- [ ] Updates: PackageKit/native backend, check/install/progress/reboot, automatic policy.
- [ ] Storage: categories, volumes, usage; delegate formatting/partitioning.
- [ ] Login Items: XDG autostart + systemd user units; enable/disable.
- [ ] Language & Region: locale, formats, first day, temperature/measurement.
- [ ] Date & Time: NTP, time zone, manual set, clock format.
- [ ] Sharing: file/screen/media/printer/remote login adapters; absent states.
- [ ] Backup: backend detection (restic/Pika/Timeshift), destination, schedule, run, restore entry.
- [ ] Reset/Startup Disk: reset Dragonfruit settings; read-only boot/volume info.

## Out of scope

- Implementing the backup backend (delegate).
- A full partition editor.

## Design notes

Every sub-pane has its own owner and absence row in the map. Distro commands stay in the adapter. The About pane reads host info; it does not fake Apple hardware. Software Update must never silently enable automatic updates. The Sharing pane hides services that are not installed.
