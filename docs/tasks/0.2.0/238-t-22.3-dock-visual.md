# T238 — Dock visual/state parity: stacks, Trash, badges, hover, magnification

## Goal

Complete the Dock’s visual states: stacks, Trash, badges, hover, magnification, separators, and overflow, without regressing the measured glass.

## Context (read first)

- T213 captures; T237 motion
- `docs/design/04-shell.md` Dock materials, ADR 0091/0102/0103/0106/0109/0113
- Liquid-glass Dock tasks T198/T199

## Reference UI/UX (macOS screenshots)

- Host: **Linux**. Reference inventory: `macos-liquid-glass-review/docs/SURFACE-INVENTORY.md`; capture plan: `macos-liquid-glass-review/docs/CAPTURE-PLAN.md`.
- Local macOS captures are reference only and never ship. Record the build/axes for every artifact.

## Scope

- [ ] Folder stacks: artwork, popover, empty/missing, Open in Files, drop.
- [ ] Trash: empty/full/unavailable, empty progress/result, badge.
- [ ] App/window badges: count, attention, precedence, scale with magnification.
- [ ] Hover/press/focus/running indicators; separators; overflow cell.
- [ ] Magnification/plate/rim/gloss/shadow: check the glass tasks first; fix only gaps.
- [ ] Accessibility names/states for every visual state.

## Out of scope

- Re-implementing the measured glass (T198/T199).
- New Dock artwork not in the design system.

## Design notes

Every visual state has a semantic state and an accessible name. A badge never hides a failure; precedence is failure > app badge > window count > none. The Trash empty operation is async and visible. Folder artwork is original geometry, no Apple assets. The plate/rim material comes from the glass path.

## Done when

- [ ] Stacks/Trash/badges/overflow/hover states are implemented and tested.
- [ ] The measured Dock optics/motion are unchanged.
- [ ] A capture shows each state in light/dark.
- [ ] Docs touched: the design doc(s) this task implements and the relevant `docs/design/STATUS.md` row.
- [ ] Hand-off filled in below.

## Live visual check (required)

- [ ] Open a stack, empty the Trash, trigger a badge, hover/magnify, and open overflow; compare to captures.
