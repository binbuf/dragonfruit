## Design notes

Every click resolves through the compositor activation authority; the shell does not re-derive “which window”. A launch must never silently no-op. The window chooser rows are requests, not local mutations. The Dock never writes its own pinned/recent config; settingsd is the writer. Check the glass Dock material tasks first.
