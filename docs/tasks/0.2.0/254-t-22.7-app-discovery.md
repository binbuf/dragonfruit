# T254 — App discovery and install locations across distros

## Goal

Make app discovery correct on Fedora, Ubuntu, Debian, and Arch: XDG paths, Flatpak, Snap, AppImage, Nix, dedupe, icons, and launch.

## Context (read first)

- T221 adapters; T246 app-index
- `services/app-index/`, `shell/src/desktopentry.*`
- `docs/design/distro-compatibility.md` app discovery section

## Reference UI/UX (macOS screenshots)

- Host: **Linux**. Reference inventory: `macos-liquid-glass-review/docs/SURFACE-INVENTORY.md`; capture plan: `macos-liquid-glass-review/docs/CAPTURE-PLAN.md`.
- Local macOS captures are reference only and never ship. Record the build/axes for every artifact.

## Scope

- [ ] Search all XDG/Flatpak/Snap/AppImage/Nix paths; dedupe by desktop id with user precedence.
- [ ] Respect NoDisplay/Hidden/OnlyShowIn/NotShowIn/TryExec.
- [ ] Resolve Exec/icons correctly; launch environment and activation token.
- [ ] Record source and unavailable reason for Settings/diagnostics.
- [ ] Tests with fixture desktop files and real installs on each distro.
- [ ] Performance with a large corpus.

## Out of scope

- A new package manager.
- A second app index.

## Design notes

Do not assume `/usr/share/applications` only. Flatpak/Snap exports are real app sources. A missing TryExec marks unavailable but does not delete. The app index is the one identity source; the shell does not scan desktop files.
