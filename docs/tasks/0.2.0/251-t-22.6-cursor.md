# T251 — Cursor and pointer aesthetics

## Goal

Ship a crisp, consistent cursor system: theme, sizes, shapes, hotspots, hide-while-typing, and HiDPI.

## Context (read first)

- T217 captures; T220 assets
- `compositor/src/cursor_theme.rs`
- `docs/design/interface-naming-and-licensing.md` cursor policy

## Reference UI/UX (macOS screenshots)

- Host: **Linux**. Reference inventory: `macos-liquid-glass-review/docs/SURFACE-INVENTORY.md`; capture plan: `macos-liquid-glass-review/docs/CAPTURE-PLAN.md`.
- Local macOS captures are reference only and never ship. Record the build/axes for every artifact.

## Scope

- [ ] Choose a permissively licensed cursor theme; record license/attribution.
- [ ] Sizes 24/32/48/64 at 1×/1.5×/2×; crisp rendering.
- [ ] Shapes: arrow, text, hand, resize, move, drag copy/link, busy/wait, help, not-allowed, crosshair, cell, zoom.
- [ ] Exact hotspots; hide-while-typing; reveal on move.
- [ ] Drag feedback and cursor shape per operation.
- [ ] Tests/captures at each scale.

## Out of scope

- Apple cursor artwork.
- A second cursor renderer.

## Design notes

The compositor owns cursor rendering; the shell does not draw a fake cursor. The cursor must not appear in screenshots unless the capture path includes it. Hotspots are physical pixels; verify at fractional scale. Reduced motion does not affect the cursor.

## Done when

- [ ] All shapes/sizes/hotspots are correct at 1×/1.5×/2×.
- [ ] Hide-while-typing and drag feedback work.
- [ ] A capture/photo shows the cursor at each scale.
- [ ] Docs touched: the design doc(s) this task implements and the relevant `docs/design/STATUS.md` row.
- [ ] Hand-off filled in below.

## Live visual check (required)

- [ ] Move over text, links, window edges, and a drag; capture the cursor at 1×/1.5×/2×; compare.
