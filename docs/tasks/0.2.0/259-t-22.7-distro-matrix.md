# T259 — Cross-distro validation matrix and packaging

## Goal

Prove the desktop installs and works on Fedora, Ubuntu, Debian, and Arch, with packaging, dependencies, and absence tests.

## Context (read first)

- T221/T254–T258
- `packaging/`, `docs/design/12-packaging.md`, `docs/design/distro-compatibility.md`
- CI workflows

## Reference UI/UX (macOS screenshots)

- Host: **Linux**. Reference inventory: `macos-liquid-glass-review/docs/SURFACE-INVENTORY.md`; capture plan: `macos-liquid-glass-review/docs/CAPTURE-PLAN.md`.
- Local macOS captures are reference only and never ship. Record the build/axes for every artifact.

## Scope

- [ ] Build RPM/DEB/PKGBUILD and install in clean VMs for Tier 1/2 distros.
- [ ] Session entry, first login, shell, Dock, menu bar, Settings, Files, network, audio.
- [ ] Stop optional services and verify absence states.
- [ ] Document distro-specific gaps and commands.
- [ ] Add CI jobs and a release checklist.
- [ ] Performance smoke on each distro.

## Out of scope

- Supporting non-systemd distros.
- Bundling GPL services into MIT packages.

## Design notes

A package is not done when it builds; it is done when a clean VM installs it and reaches a usable desktop. Record the exact package versions and the VM image. Nested-only evidence does not prove the session entry. The hardware rail still owns GPU/seat-specific rows.
