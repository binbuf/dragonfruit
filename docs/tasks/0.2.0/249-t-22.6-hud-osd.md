# T249 — HUD/OSD system

## Goal

Ship the HUD/OSD system: volume, brightness, keyboard backlight, mute, charging, low battery, screen casting, Focus, and other transient feedback.

## Context (read first)

- T217/T218 captures; T232 extras
- `shell/osd/Osd.qml`, `shell/src/osdmodel.*`

## Scope

- [ ] HUD model: kind, value, icon, label, timeout, per-display, replacement.
- [ ] Volume/brightness/backlight/mute/charging/low-battery/casting/Focus.
- [ ] Real key/power triggers; no focus steal; AT-SPI announcement.
- [ ] Enter/hold/exit motion, reduced motion, light/dark, scaling.
- [ ] Persistent indicators (recording, camera/mic) if in scope.
- [ ] Tests and captures.

## Out of scope

- A second OSD for each service.
- Apple-specific HUDs that are omitted.

## Design notes

One HUD per kind; a new value updates in place. The HUD never blocks input. The timeout is measured; a new value resets it. Per-display: the active display for global keys. Reduced motion removes scale/travel but keeps the dwell. The HUD material uses the popup/overlay role.
