# T211 — Capture: System Settings pane sweep

## Goal

Capture every System Settings pane, sub-pane, popup, sheet, search state, and admin prompt so the Settings map and UI work are evidence-backed.

## Context (read first)

- T209/T210 inventory and harness
- `docs/reference/System_Preferences.md`
- `docs/design/settings-business-logic-map.md`

## Reference UI/UX (macOS screenshots)

- Host: **macOS**. Reference inventory: `macos-liquid-glass-review/docs/SURFACE-INVENTORY.md`; capture plan: `macos-liquid-glass-review/docs/CAPTURE-PLAN.md`.
- Local macOS captures are reference only and never ship. Record the build/axes for every artifact.

## Scope

- [ ] Capture every `SET-*` pane at the top, each scrolled section, and every popup/sheet/disclosure/help popover.
- [ ] Capture light/dark, reduce transparency, increase contrast, and a long-string locale where feasible.
- [ ] Capture Settings search empty/one/many/no results and the highlighted match.
- [ ] Capture admin/polkit/password prompts, cancel, wrong password, success.
- [ ] Dump AX roles/labels/values/frames and record the pane deep-link identifier.

## Out of scope

- Implementing the panes (T222–T229).
- Faking absent service states; use the real controls.

## Design notes

Use the pane URL schemes and record the exact identifier. The capture set must cover the full macOS 27 pane list, including omitted panes (for the naming/omission decision). Do not capture a user’s private data; use a scratch user or redact. Record every scroll position and window size.

## Done when

- [ ] Every `SET-*` id has a still set and an AX dump or an `OPEN` row.
- [ ] Search states and admin prompts are captured.
- [ ] A coverage table lists captured/OPEN panes and the exact deep-link ids.
- [ ] Docs touched: the design doc(s) this task implements and the relevant `docs/design/STATUS.md` row.
- [ ] Hand-off filled in below.

## Live visual check (required)

- [ ] Open three representative panes from the coverage table and compare the captured labels/order to the live UI.
