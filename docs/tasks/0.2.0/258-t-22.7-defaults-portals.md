Make default-app and portal integration correct: MIME handlers, settings portal, file chooser, screenshot, screencast, and global shortcuts.

## Scope

- [ ] Default browser/mail/media/file manager via xdg-mime/mimeapps/settings portal.
- [ ] File chooser, screenshot, screencast, global shortcuts portal paths.
- [ ] Permission store integration; absence/denial states.

## Out of scope

- A second MIME database.

## Design notes

Use the settings portal when available; edit `mimeapps.list` only as a fallback. The portal backend is selected by the session. A missing portal disables the capability with a reason; it never silently uses an unsafe path. Flatpak access must be tested.
