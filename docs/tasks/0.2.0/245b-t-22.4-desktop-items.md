# T245b — Desktop items and interaction

## Goal

Bring the desktop surface to the total-experience bar: icon grid, labels,
selection, context menu, stacks, mounted volumes, widgets placement,
drag/drop, Quick Look, Trash, multi-display, keyboard, and accessibility.

- The wallpaper provider (T-18) and wallpaper settings pane (T229a).
- A new desktop file model; files-core remains the source of truth.

## Design notes

The desktop is owned by Files, not the shell. The compositor grants the
background layer; Files owns the content. The desktop must not become a second
file manager. A missing/removed file updates the icon without a full reload.
Widgets are optional and degrade to an empty state. The desktop context menu
uses the design-system context menu and the glass popup role.
