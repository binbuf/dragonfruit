# T239 — Dock drag/drop, keyboard, accessibility, and app management

## Goal

Make the Dock fully operable without a mouse and complete drag/drop/app management.

## Context (read first)

- T236/T238
- `shell/dock/`, `shell/src/dockdrops.*`, `apppicker.*`
- `docs/design/04-shell.md` Dock drag/keyboard/app-management sections

## Reference UI/UX (macOS screenshots)

- Host: **Linux**. Reference inventory: `macos-liquid-glass-review/docs/SURFACE-INVENTORY.md`; capture plan: `macos-liquid-glass-review/docs/CAPTURE-PLAN.md`.
- Local macOS captures are reference only and never ship. Record the build/axes for every artifact.

## Scope

- [ ] Drag reorder within pinned; external file/app/folder drop; affordances; pin/unpin.
- [ ] Keyboard focus ring, arrows, Return, Escape, type-ahead, Ctrl+Shift+Arrow reorder.
- [ ] AT-SPI names/roles/states for entries, popovers, chooser, stacks, Trash, badges.
- [ ] Add Application picker search/pin; app-index absent state.
- [ ] Multi-display drag and edge cases; reduced motion.
- [ ] Tests for drag arbitration, dead taps, and focus restoration.

## Out of scope

- Touch reordering.
- A second app index.

## Design notes

A stationary click must always activate; only a real drag lifts. Pointer injection timestamps are mandatory. Reorder persists through settingsd. The picker is a management surface, not the primary launcher. Keyboard reordering is axis-aware. A11y names include state/window count.
