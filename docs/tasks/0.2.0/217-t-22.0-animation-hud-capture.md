# T217 — Capture: animations and HUDs

## Goal

Capture every remaining animation and transient HUD/OSD at high frame rate so the motion and HUD systems have measured inputs.

## Context (read first)

- T209/T210 inventory and harness
- `docs/design/motion-and-feedback.md`
- Existing T-02/T-05/T-06/T-11 motion captures

## Reference UI/UX (macOS screenshots)

- Host: **macOS**. Reference inventory: `macos-liquid-glass-review/docs/SURFACE-INVENTORY.md`; capture plan: `macos-liquid-glass-review/docs/CAPTURE-PLAN.md`.
- Local macOS captures are reference only and never ship. Record the build/axes for every artifact.

## Scope

- [ ] Capture the `A-*` transitions not covered by T212–T216: menu, Quick Settings, notifications, HUDs, lock/unlock, Preview, Stage/tiling.
- [ ] Capture `H-*`: volume 0..100/mute, brightness, keyboard backlight, charging, low battery, battery full, screen casting, Focus, Wi-Fi/Bluetooth off/on, nearby transfer, screenshot flash, recording/privacy indicators.
- [ ] Capture 120 fps enter/hold/exit for each HUD; record the trigger and timeout.
- [ ] Capture light/dark, reduce transparency/contrast, reduced motion, and multi-display where applicable.
- [ ] Record the HUD geometry, icon, bar fill, text, and position.

## Out of scope

- Implementing the HUD system (T249) and sound (T250).
- Apple service-specific HUDs that are omitted.

## Design notes

Use the real key path for volume/brightness/backlight and the real power plug for charging. A HUD that cannot be triggered on the host is `OPEN` with the missing hardware and exact key path. Do not infer a HUD timeout from a still. Capture the menu-bar indicator for persistent states (recording, camera/mic).

## Done when

- [ ] Every `A-*` and `H-*` id has a motion/still artifact or an `OPEN` row.
- [ ] HUD enter/hold/exit timings and geometry are captured.
- [ ] Persistent indicators and reduced-motion variants are captured.
- [ ] Docs touched: the design doc(s) this task implements and the relevant `docs/design/STATUS.md` row.
- [ ] Hand-off filled in below.

## Live visual check (required)

- [ ] Trigger volume, brightness, charging, and one notification; compare position, content, timeout, and fade to the captures.
