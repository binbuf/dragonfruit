# T223 — Settings IA, search, and deep-link polish

## Goal

Make Settings navigable and searchable: pane/section/row search, deep links, row anatomy, headers, and long-string behavior.

## Context (read first)

- T222 catalog/map
- `apps/settings/SettingsShell.qml`, `SettingsPanes.qml`, `PaneHeader.qml`
- `docs/reference/System_Preferences.md`, `settings-layout-measurements.md`

## Reference UI/UX (macOS screenshots)

- Host: **Linux**. Reference inventory: `macos-liquid-glass-review/docs/SURFACE-INVENTORY.md`; capture plan: `macos-liquid-glass-review/docs/CAPTURE-PLAN.md`.
- Local macOS captures are reference only and never ship. Record the build/axes for every artifact.

## Scope

- [ ] Index pane titles, section titles, row labels, synonyms, and help text; return a ranked result list.
- [ ] Deep-link a result to the pane and scroll/highlight the row.
- [ ] Unify row anatomy: label, description, control, disclosure, trailing action, help.
- [ ] Add pane headers where the reference has them; keep settings-list panes headerless.
- [ ] Test long strings/locales, keyboard navigation, empty/no-results, and back/forward history.

## Out of scope

- Implementing individual pane controls (T225–T229).
- A separate search service for Settings.

## Design notes

Search must be fast and local. A result that cannot be deep-linked is not shown. Keep the macOS section order and labels from the map. The back/forward chevrons follow pane history, not window history. The `?` help button opens the relevant doc/help, not a dead link.

## Done when

- [ ] Search returns pane/section/row results and deep-links correctly.
- [ ] Keyboard-only navigation works; long strings do not clip controls.
- [ ] A capture shows search, a deep-linked row, and a long-string pane.
- [ ] Docs touched: the design doc(s) this task implements and the relevant `docs/design/STATUS.md` row.
- [ ] Hand-off filled in below.

## Live visual check (required)

- [ ] Search for three rows across panes, deep-link each, and compare the row anatomy/highlight to the capture.
