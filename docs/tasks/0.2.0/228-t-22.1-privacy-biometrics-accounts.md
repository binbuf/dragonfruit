# T228 — Settings panes: Privacy & Security, Biometrics & Password, Online Accounts

## Goal

Ship the privacy/security, biometrics, and online-account panes with real portal/polkit/fprintd/GOA state and honest Linux differences.

## Context (read first)

- T221 adapters, T222 map, T224 apply path
- `services/privacy-adapter/`, `services/account-adapter/`, `services/lock-auth/`
- `docs/design/07-system-integration.md`

## Reference UI/UX (macOS screenshots)

- Host: **Linux**. Reference inventory: `macos-liquid-glass-review/docs/SURFACE-INVENTORY.md`; capture plan: `macos-liquid-glass-review/docs/CAPTURE-PLAN.md`.
- Local macOS captures are reference only and never ship. Record the build/axes for every artifact.

## Scope

- [ ] Privacy: map each macOS category to the closest portal/permission; show per-app state; explain differences.
- [ ] Security: software sources, LUKS status (read-only), hardening mode, extensions, advanced.
- [ ] Biometrics: password change, fingerprint enroll/delete, unlock/auth toggles (PAM detection).
- [ ] Online Accounts: GOA provider list, add/remove, sync toggles; hide if GOA absent.
- [ ] Add absence tests for portal, fprintd, GOA, LUKS, and polkit.

## Out of scope

- A new permission store or screen reader.
- Fake TCC categories that Linux does not have.

## Design notes

The portal PermissionStore is the state; the pane displays it. LUKS is read-only; do not implement disk encryption here. Fingerprint toggles are hidden unless PAM is configured. GOA is optional; the pane is hidden if absent, not a dead entry. Every row states the Linux difference where the mapping is approximate.
