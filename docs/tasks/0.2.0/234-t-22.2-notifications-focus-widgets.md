# T234 — Notifications, Focus, widgets, and banners

## Goal

Complete the notification experience: banner/stack/history/lower panel, Focus policy, widgets, actions, and per-app settings.

## Context (read first)

- T212 captures; T232 extras
- `shell/notifications/`, `services/notifications/`, `shell/src/notificationclient.*`

## Reference UI/UX (macOS screenshots)

- Local macOS captures are reference only and never ship. Record the build/axes for every artifact.

## Scope

- [ ] Banner enter/exit/stack/timeout; actions; reply where supported; keyboard/AX.
- [ ] Notification Center history, grouping, clear, lower panel, per-display.
- [ ] Focus modes: DND/Personal/Work/Sleep/custom; allowed people/apps; schedule; shared policy.
- [ ] Widgets: gallery, add/remove/size, calendar/weather/clock; live data; absence.
- [ ] Per-app notification settings from the notification service.
- [ ] Check the liquid-glass notification material tasks (T204/T205) first.

## Out of scope

- A new notification daemon.
- Apple-specific notification features.

## Design notes

The notification service is the source of truth; the shell renders. Focus is one policy shared by menu bar, Quick Settings, and the service. A banner must not steal focus. Widgets are optional and must degrade to an empty state. Per-display placement follows the active display.
