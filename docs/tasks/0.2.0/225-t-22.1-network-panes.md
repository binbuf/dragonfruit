## Scope

- [ ] Wi-Fi: toggle, current network, known/available networks, hidden join, details, ask-to-join policy, advanced.
- [ ] Network: services, service order, VPN, firewall, add/configure, advanced.
- [ ] Firewall: detect firewalld/ufw/nftables; status, enable/disable, open port/service; absent state.

- [ ] Add adapter tests, pane tests, and absence captures.

## Out of scope

- A full connection editor beyond the reference MVP.
- A second network backend (systemd-networkd).

## Design notes

NetworkManager is authoritative; the pane never caches a stale connected state. Joining a network uses the NM agent/polkit path. A firewall backend that cannot report status is `Unavailable`, not `Off`. The Wi-Fi quick sheet and pane share one model. Check the liquid-glass menu/popover material tasks before styling the quick sheet.
