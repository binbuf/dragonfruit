## Goal

Trash to the freedesktop spec via GIO/GVfs with a sanctioned fallback.

## Scope

- Trash (freedesktop spec via GIO/GVfs when available; sanctioned fallback otherwise).

## Explicitly deferred

- Folder watcher (T-10.3b).

## Test plan

- Headless: trash operations with the fallback path.

## Hand-off

- **Landed.** `services/files-core/src/trash.rs`: `TrashOps` (the seam:
  `trash`/`restore`/`empty`/`entries`/`home_trash`) and `FreedesktopTrash`, the
  sanctioned freedesktop-spec fallback. It uses the same store GVfs owns
  (`$XDG_DATA_HOME/Trash`, else `$HOME/.local/share/Trash`; `files/` +
  `info/*.trashinfo`; percent-encoded absolute `Path`; per-volume
  `.Trash/$UID`/`.Trash-$UID`). `OptimisticModel::trash_via` reuses
  `begin_delete`. Public helpers `parse_trash_info`, `format_deletion_date`,
  `default_home_trash`; marker `SANCTIONED_TRASH_FALLBACK_MARKER`.
  `OperationError` gained `MalformedTrashInfo`. `FileOps::delete` stays
  permanent. ADR 0046; `docs/design/09-files.md` T-10.3a paragraph.
- **Commands.** `CARGO_NET_OFFLINE=true cargo test -p dragonfruit-files-core`
  → 106 pass (50 unit + 17 operations + 11 optimistic + 5 sorting + 6 streaming
  + 13 new `tests/trash.rs` + 4 doctests). `make lint`, `make e2e` green.
- **Deviations.** `DeletionDate` is UTC, not the spec's preferred local time
  (display only; restore never reads it). `entries` enumerates the home trash
  only — per-volume trashes are written but not aggregated (that is GVfs's job;
  listing `trash://` is still `UnsupportedScheme`).
- **Next (T-10.3b).** Wire the folder watcher to call `confirm`/`revert` (or a
  reconcile step) instead of the operation result; each pending op must resolve
  exactly once. T-10.6a still needs a `DirectorySource` for `trash://` over
  `FreedesktopTrash::entries`/`home_trash`.
- **Live visual check.** `/tmp/opencode/t60-desktop.png` — files-core has no
  surface of its own; the nested demo renders (menu bar, Dock, Settings), same
  as T57–T59.
