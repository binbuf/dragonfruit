## Reference UI/UX (macOS screenshots)

Near-verbatim target: the macOS System Settings shell in the local captures
(`docs/reference/macos/`; never shipped, see
[14-risks.md](../design/14-risks.md)), distilled in
[System_Preferences.md](../reference/System_Preferences.md).

Sections and rows (observed order):

- **Window**: rounded with a drop shadow; translucent sidebar, opaque detail
  pane; follows the desktop light/dark appearance. Chrome: traffic lights;
  back/forward chevron pills (forward dimmed at the end of history) and the
  current pane's title.
- **Sidebar**: search field at top (`Search` placeholder, magnifier glyph);
  then the account row; then one continuous, scrollable list of icon + label
  pane rows in reference order: Wi-Fi, Bluetooth, Network, Battery, General,
  Accessibility, Appearance, Apple Intelligence & Siri, Desktop & Dock,
  Displays, Menu Bar, Spotlight, Wallpaper, Notifications, Sound, Focus,
  Screen Time, Lock Screen, Privacy & Security, Biometrics & Password,
  Users & Groups, Internet Accounts, Keyboard, Mouse, Trackpad, Printers &
  Scanners. The selected pane carries a tinted rounded highlight with
  accent-colored text; rows appear as their panes ship (no half-panes).
- **Header card**: large pane icon, pane title, one-line description.
- **Grouped inset sections**: icon + label rows; trailing chevron when the
  row pushes a deeper screen; toggles and pickers inline on their row.

Adapt or omit (Apple-only): the Apple Account row (our **Users & Groups**
pane, T-15.11, covers accounts); `Apple Intelligence & Siri` and Screen Time
(macOS-specific, not planned); Spotlight (our Search pane, deferred);
AppleCare & Warranty and AirDrop & Continuity rows; Internet Accounts
(deferred, not core).

## Hand-off

**Status: done.** The Settings app shell landed. The old single-`Window`
placeholder is now a real shell.

What landed (repo root):

- **`apps/settings/`** is a reusable QML module (`Dragonfruit.Settings`, static
  lib `dragonfruit-settings-ui` + plugin) plus the thin
  `dragonfruit-settings` executable — the design-system gallery/module split,
  so the app and the test render the same surfaces.
- **`apps/settings/SettingsPanes.qml`** (new, singleton) — the ordered pane
  catalog mirrored from `docs/reference/System_Preferences.md`:
  `{ id, title, icon, description, shipped }`. `shippedPanes`/`filter(query)`
  are the no-half-panes gate and local search. Wave-1 rows are `shipped`:
  `appearance`, `desktop-dock`, `displays`, `wallpaper`.
- **`apps/settings/SettingsShell.qml`** (new) — design-system `AppWindow` +
  `TitleBar`/traffic lights, `Sidebar` + `SearchField`, `Toolbar` back/forward
  (`canGoBack`/`canGoForward`, forward dimmed at the end), pane history,
  `PaneHeader` card, and a `SettingsGroup` note that names the pane's own step
  until a body lands. Alt+Left/Right history, Ctrl+F search focus, Escape
  clears (SearchField).
- **`apps/settings/PaneHeader.qml`**, **`SettingsWindow.qml`** (new) — header
  card; frameless Tier-1 window that maps shell intent to `Window`
  (close/minimize/zoom/`startSystemMove`).
- **Design system** — `Icon.qml` gained `chevron-left` and Canvas-painted pane
  glyphs (`appearance`, `wallpaper`, `dock`, `displays`); `Button.qml` gained
  `accessibleName` (bare-glyph buttons); `Sidebar.qml` no longer emits a header
  row for an untitled section (flat pane lists).
- **Tests** — `apps/settings/tests/tst_settings_shell.{cpp,qml}` (new): shell
  opens, search filters (case-insensitive, id/title/description), keyboard
  nav + Enter, history back/forward, AT-SPI roles, traffic-light close
  forwarding, and a pixel check that the selected row carries the accent
  highlight.
- **Docs** — ADR [0035](../design/adr/0035-settings-shell-and-pane-catalog.md);
  track doc `09-settings-app-wave-1.md` shell section.

Commands that work (all green):

- `ctest --test-dir build -R tst_settings_shell --output-on-failure` — 11/11;
  `ctest --test-dir build` — 22/22 (no regressions).
- `make lint` — fmt/clippy/qmllint/token/design/desktop-name gates green.
- `make e2e` — all Rust suites + clean `make demo --headless`.

Live visual check (`/tmp/opencode/t48-capture.sh`, captures
`/tmp/opencode/t48-settings-shell.png`): nested `make demo` with
`dragonfruit-settings` as the Qt/Wayland client; the window renders the
titlebar "Settings" + red/yellow/green lights, the "Search" field with
magnifier, the sidebar rows Appearance / Desktop & Dock / Displays / Wallpaper,
the selected row in accent (#b32a66 = 179,42,102; 5162 accent pixels in the
sidebar), and the Appearance header card (magenta icon, title, description).
Vision on a tight window crop reported all elements present, the selected row
as deep magenta, and no clipping/overlap/missing icons/stray pixels.

Deviations / notes for T-09.1b:

- **T-09.1a ships only the shell**; the four Wave-1 pane rows show a header card
  and a one-line placeholder note, replaced as T-09.2…T-09.5 land. This is the
  intended slice split, not a half-pane: the catalog's `shipped` gate is what
  later tasks flip, and unbuilt panes are not listed.
- The selected-row highlight animates in over `motion.hover` (100 ms); tests
  must wait it out before sampling pixels.
- The app's `Theme.dark` still follows the host style hint (light here) while
  the compositor defaulted dark in the nested run; the QML/scheme unification
  is the existing T-04.4b/T-08 follow-up, untouched here.
- T-09.1b replacing "the `--placeholders` Settings window" refers to the old
  shell placeholder the demo used; this shell is the replacement. The
  per-pane placeholder note is what the pane units remove.
