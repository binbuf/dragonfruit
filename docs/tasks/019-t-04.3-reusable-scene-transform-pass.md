## Goal

Build one reusable scene-transform pass (scale/translate/clip + optional blur) for T-05 to compose.

## Scope

- One pass built once, consumed by Mission Control and the app switcher later.
- One effect pass per rendered frame; instrumented.

- Per-feature variants (explicitly forbidden).

## Hand-off

**State: done.** The reusable scene-transform pass exists and is exercised.

What landed:

- **`compositor/src/window/pass.rs`** (new) — `FramePass`, the single shared
  once-per-frame/per-output guard + damage recorder. `BackdropPass`
  (T-04.2) and the new `SceneTransformPass` both wrap it; no per-effect guard.
- **`compositor/src/window/scene_transform.rs`** (new) — `SceneTransform`
  (source→target scale/translate + optional token `CornerMask` clip + optional
  token `BackdropSpec` blur; `scale`/`offset`/`map_point`/`map_rect`/
  `clip_spans`/`blur_layers`/`blur_elements`/`is_identity`), the
  `from_motion(MotionFrame, surface_size)` seam (uses `MotionFrame::scale_for`,
  the committed-surface scale — not the chrome `frame.scale`), and
  `SceneTransformPass`.
- **`compositor/src/render.rs`** — `push_motion_elements` now wraps through
  `SceneTransform::from_motion`; `window_render_elements` takes `&mut DfState`
  and opens the pass once per output with the union of the transformed window
  rects (output-local logical). No behavior change for a non-motion window.
- **`compositor/src/state.rs`** — `DfState.scene_pass`; `begin_render_frame`
  opens it; the render-stats line appends
  `scene_transforms` / `scene_transform_skipped` (append-only, ADR 0009).
- **`compositor/tests/idle_trace.rs`** — parses the new fields and asserts the
  pass is flat and the skip guard never fires while idle.
- **Docs** — ADR `0014-reusable-scene-transform-pass.md`; `02-compositor.md`
  "Reusable scene-transform pass (T-04.3)".

Next task must know:

- **T-05/T-06/T-11 consume `SceneTransform`/`SceneTransformPass`; do not add a
  second transform.** The pass guard is shared (`FramePass`).
- The lifecycle motion already renders through `SceneTransform::from_motion`
  (confirmed by `from_motion_matches_the_lifecycle_frame`); T-05's grid should
  build the same transform from its layout rects.
- **Clip is not yet applied to live client surface elements** (Smithay keys
  them for presentation feedback; T-04.1b's limitation). The transform carries
  the `CornerMask`; T-05 decides the element wrap (see `CropRenderElement`).
- The headless backend never renders pixels, so `scene_transforms=0` there;
  the counters move only on nested/DRM. The idle trace still asserts flat.
- Folding the T-04.2 chrome backdrop element generation through this pass is
  still open (`BackdropPass`/`MaterialRole` are the seam); the guard is
  already shared.
