## Reference UI/UX (macOS screenshots)

Local macOS **Tahoe 26** captures only (`docs/reference/macos/` never ships; see

Distilled in [System_Preferences.md](../reference/System_Preferences.md).

**Sections and rows (observed order):** Observed in the Tahoe capture:

- Sidebar: flat icon + label list with no trailing chevrons or badges;
  `Printers & Scanners` is the selected row (solid accent fill, on-accent
  text). A trailing third-party `macFUSE` pane follows (not part of the stock
  order).
- `Default printer` — popup, value `Last Printer Used`, trailing down chevron.
- `Default paper size` — popup, value `US Letter`, trailing down chevron.
- `Printers` — section title over the device list.
- `Canon MF230` — disclosure row: grayscale printer icon, secondary
  `Idle, Last Used` with a green state dot, trailing right chevron pushing the
  per-printer detail screen (not captured). Same treatment for scanners (none
  captured).
- `Add Printer, Scanner, or Fax...` — standard rounded button.
- `?` help — question-mark-in-circle button.
- Header/chrome: centered pane title, back/forward chevron pill (forward dimmed), sidebar `Search` field, trailing `?` help.

**Apple-only (adapt or omit):** AirPrint branding — CUPS discovers the same
printers over IPP/DNS-SD, and Bonjour is Apple's name for DNS-SD, so keep
generic IPP equivalents and drop AirPrint wording; the `?` button maps to local
help if it exists. Captured device names (`Canon MF230`) are generic and can
stay as fixture-like examples.
