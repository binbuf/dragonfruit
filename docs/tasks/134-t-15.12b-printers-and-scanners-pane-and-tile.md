**Sections and rows (observed order):** Observed in the Tahoe capture:

- Sidebar: flat icon + label list with no trailing chevrons or badges;
  `Printers & Scanners` is the selected row (solid accent fill, on-accent
  text). A trailing third-party `macFUSE` pane follows (not part of the stock
  order).
- `Default printer` — popup, value `Last Printer Used`, trailing down chevron.
- `Default paper size` — popup, value `US Letter`, trailing down chevron.
- `Printers` — section title over the device list.
- `Canon MF230` — disclosure row: grayscale printer icon, secondary
  `Idle, Last Used` with a green state dot, trailing right chevron pushing the
  per-printer detail screen (not captured). Same treatment for scanners (none
  captured).
- `Add Printer, Scanner, or Fax...` — standard rounded button.
- `?` help — question-mark-in-circle button.
- Header/chrome: centered pane title, back/forward chevron pill (forward dimmed), sidebar `Search` field, trailing `?` help.

**Apple-only (adapt or omit):** AirPrint branding — CUPS discovers the same
printers over IPP/DNS-SD, and Bonjour is Apple's name for DNS-SD, so keep
generic IPP equivalents and drop AirPrint wording; the `?` button maps to local
help if it exists. Captured device names (`Canon MF230`) are generic and can
stay as fixture-like examples.

## Hand-off

**Landed.** The Settings `Printers & Scanners` pane and the Control Center
`Printers` tile ship as one functional unit over the T-15.12a adapter, through
the `org.dragonfruit.SystemStatus1.Printers` bridge host (ADR
[0141](../design/adr/0141-printers-scanners-pane-and-tile.md)). The pane
applies live: the `Default printer` popup writes the CUPS default, the
`Default paper size` popup writes the new `printers.defaultPaperSize` settingsd
key (schema 16 → 17), and the per-printer detail dialog writes accept/reject
and Cancel plus sets the default. The tile is a read-only count summary with a
settings link. Absence is layered and documented: CUPS absent marks only the
print half absent, SANE absent only the scanner half, the view is
`unavailable` only when both are absent, and the pane shows a per-half note.

**Tests (all green, commands in PROGRESS.md > T134):**
`cargo test -p dragonfruit-system-status -p dragonfruit-printer-adapter
-p dragonfruit-settingsd`; `ctest --test-dir build --output-on-failure -j4`
(66/66); `make e2e` EXIT 0 (`/tmp/opencode/e2e-t134.log`). New suites:
`services/system-status/tests/printers.rs`,
`apps/settings/tests/tst_settings_printers.{cpp,qml}`, plus the updated absence/
shell/control-center/status-model suites.

**Deviations from the plan, recorded:** (1) `Add Printer, Scanner, or Fax…` is
not shown — the reference row cannot work until the adapter exposes a CUPS
discovery/`lpadmin -p` seam, and a disabled button would be a dead control; it
is a follow-up in `dragonfruit-printer-adapter`. (2) `Last Printer Used` is the
`Default printer` popup's value when CUPS names no default, but it is not a
selectable choice (clearing a system default is not a CUPS client-tool
operation). (3) To fit the fifteenth Control Center tile the panel's content gap
compacted from `xs` to `xxs` and the new tile's own gap is `xs`; the fixed
360×1160 surface still holds every tile.

**Next task must know:** the `Printers` interface and the three adapter writes
are the only ones; the one settingsd key is `printers.defaultPaperSize`; a 16th
Control Center tile needs a taller nested output; the Add-printer follow-up
goes in the adapter, not the pane.

**Live visual check:** `bash scripts/capture-t15-printers-pane.sh` produced
`docs/captures/t15-12b-printers-pane.png` (2088x1410) and
`docs/captures/t15-12b-printers-control-center.png` (360x1160). Vision found the
pane's sidebar selection, both popups, both printer rows with their state
labels, the scanner row, and the tile's `2 Printers, 1 Scanner` summary through
the last tile with no clipping, blanks, or stray artifacts.
