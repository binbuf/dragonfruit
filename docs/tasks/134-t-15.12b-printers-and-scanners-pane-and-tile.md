## Reference UI/UX (macOS screenshots)

Near-verbatim target: the real macOS screenshot in `docs/reference/macos/`
(never shipped; see [14-risks.md](../design/14-risks.md)), distilled in
[System_Preferences.md](../reference/System_Preferences.md). The capture
(`Screenshot 2026-09-18 at 9.21.58 PM.png`) covers the detail pane; the
Control Center tile mirrors the same state (T-15.12a), tile art not captured.

Sections and rows (observed order):

- **Default settings group** (grouped inset, no section title): `Default
  printer` popup menu (captured value `Last Printer Used`) and `Default paper
  size` popup menu (`US Letter`); map the default destination to the CUPS
  default queue, paper size provider TBD (T-15.x).
- **`Printers` section**: printer list row — grayscale printer icon, name
  (captured `Canon MF230`), secondary status text with a green state dot
  (captured `Idle, Last Used`), and a trailing chevron that pushes the
  per-printer detail screen (queue, options, jobs; not captured). Rows carry
  the same list treatment for scanners (none captured). Then the button
  `Add Printer, Scanner, or Fax...` and the circular `?` help button.
- Map the printer list, queue state text, and add flow to CUPS (`org.cups.*`;
  see [07-system-integration.md](../design/07-system-integration.md)); the
  per-printer queue/job detail rows and scanner controls (SANE) stay in the
  layout with providers TBD (T-15.x). Absence is a normal state.

Adapt or omit (Apple-only): AirPrint branding — CUPS discovers the same
printers over IPP/DNS-SD, and Bonjour is Apple's name for DNS-SD, so keep
generic IPP equivalents and drop AirPrint wording; the `?` button maps to
local help if it exists. Captured device names (`Canon MF230`) are generic
and can stay as fixture-like examples.
