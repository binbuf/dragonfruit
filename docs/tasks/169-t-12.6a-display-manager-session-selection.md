## Goal

The harness can point the next display-manager login at the Dragonfruit session
and put the previous default back, across the common DMs, without guessing or
leaving the host configured differently.

## Scope

- A `SessionSelector` seam with one adapter per supported DM: GDM
  (AccountsService `XSession`), SDDM (SDDM state file), LightDM (`~/.dmrc`).
- Read the current selection, select the Dragonfruit session entry, restore a
  saved selection; an unknown/unreadable DM degrades to `Unsupported` and the
  caller falls back to "pick it in the greeter".
- Optional autologin arm/disarm behind its own adapter, off by default, and a
  hard `disarm` on any non-round-trip exit.
- Unit tests with fixture DM state directories (no real DM needed).

## Explicitly deferred

- The round-trip command and the in-session return item (T-12.6b).
- The second-VT mode (T-12.6c).
- Real DM validation on hardware (T-12.6b on the T-159…T-161 rail).

## Acceptance (agent-completable)

- [ ] Each adapter reads, selects, and restores from fixture state.
- [ ] Unknown DM returns `Unsupported`; no write is attempted.
- [ ] Autologin arm/disarm round-trips and defaults to off.

## Test plan
