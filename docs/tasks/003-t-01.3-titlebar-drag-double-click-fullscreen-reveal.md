## Goal

Add pointer drag-to-move, double-click zoom honoring `dock.titlebarDoubleClick`, and fullscreen hover reveal.

## Scope

- Drag from the titlebar starts the existing interactive move grab.
- Double-click dispatches `zoom` or `minimize` per `dock.titlebarDoubleClick` (default `zoom`).
- Fullscreen hover reveal of the titlebar.
- All geometry changes keep flowing through `configure_window_size`.

## Explicitly deferred

- Minimize/zoom animation (T-02).
- Multi-monitor drag polish (T-16).

## Acceptance (agent-completable)

- [ ] Drag moves the window; double-click zooms when configured; fullscreen hover reveals the titlebar.
- [ ] Interactive move over the protocol is asserted (resize already asserted in `window_conformance`).

## Test plan

- Headless: synthetic seat button starts the grab and the move survives; extended `window_conformance`.

## Hand-off

**State: done.** All acceptance criteria met; `make e2e` green.

What landed:

- Drag from a floating window's titlebar starts the existing `MoveGrab`
  (`DfState::begin_titlebar_move`); the window moves and all geometry still
  flows through `move_window`/`configure_window_size`.
- Double-click dispatches `TitlebarDoubleClick` per `dock.titlebarDoubleClick`
  (default `zoom`; `minimize`/`none` supported) via
  `DfState::titlebar_double_click_action`; detection is
  `DoubleClickTracker` (400 ms, 4 px, same window).
- Fullscreen reveals an overlay titlebar when the pointer is in the top
  `TITLEBAR_HEIGHT` strip; `TitlebarElement::for_window` lays it on the
  content with `insets == NONE` while `hovered`.
- Titlebar presses now activate the window (`DfState::activate_window`),
  satisfying the T-01.2 note that activation could land in T-01.3.
  Activation focuses but does not raise the window in the `Space`.
- Tests: `window_conformance::{titlebar_drag_and_double_click_move_and_zoom,
  fullscreen_hover_reveals_the_titlebar}` plus `window::decoration` unit
  tests. Verified with `cargo test -p dragonfruit-compositor --bin
  dragonfruit-compositor` (144 pass), `--test window_conformance` (8 pass),
  `--test xwayland_conformance` (4 pass), `make e2e`, clippy and fmt clean.

Deviations / notes:

- The setting is not read from the shell yet; the compositor holds the field
  and a synthetic-input command (`set titlebar-double-click <mode>`) sets it
  for tests. ADR 0001 records that T-08 settingsd owns the live value and
  must push it through `DfState::set_titlebar_double_click`.
- Zoomed/fullscreen windows are not interactively moved (grab module's
  contract); multi-monitor drag polish stays T-16.
- `docs/design/05-window-decorations.md` updated; PROGRESS.md T03 section has
  the full details and gotchas.
