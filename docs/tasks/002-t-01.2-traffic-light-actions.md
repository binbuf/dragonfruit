## Goal

Make close/minimize/zoom clickable through the titlebar hit-test, wired to the existing window state machine.

## Scope

- Hit-test regions for the three buttons with hover/disabled states.
- close → `df_toplevel.close`; minimize → `minimize_window`; zoom → `zoom`/`unzoom`.
- Titlebar hit-testing integrated into compositor input routing without breaking popups, IME, or client input regions.
- Reduced motion: N/A (no animation) — recorded as such.

## Explicitly deferred

- Drag-to-move and double-click (T-01.3).
- Lifecycle animation (T-02).

## Acceptance (agent-completable)

- [ ] Synthetic pointer clicks drive close/minimize/zoom for a Wayland and an X11 client.
- [ ] No new window state or second owner of truth is introduced.

## Test plan

- Headless: synthetic-input harness clicks each button and asserts the state-machine transition over the protocol.

## Hand-off

Landed: hover tracking (`DfState::hovered_titlebar`, reveal on button-cluster
hover), hit-testing (`DfState::titlebar_button_at`, topmost-first), and the
action mapping in `DfState::traffic_light_action` (close/minimize/zoom+unzoom)
through the existing state machine. `DfState::close_window` is the new single
close path for Wayland and X11, also used by the window menu and
`df_toplevel.close`. The synthetic `query decorations` report now carries the
window state so minimize/zoom are assertable.

Deviations: (1) added X11 close support (`X11Surface::close`) — required by the
"X11 client" acceptance criterion, since `toplevel.send_close()` is a no-op for
X11; (2) the titlebar is only hit-tested when no chrome surface and no client
surface (toplevel/popup/input region) is under the pointer, to protect popups,
IME, and client input regions; (3) left-clicking a light does not focus the
window in this slice.

T-01.3 adds drag and double-click on the same hit-test (`button_at`/`hit`/
`cluster_rect`), and may add titlebar-click activation. Keep routing input
through `DfState::titlebar_button_at` and actions through
`DfState::traffic_light_action`/`close_window`; do not add a second close path.
