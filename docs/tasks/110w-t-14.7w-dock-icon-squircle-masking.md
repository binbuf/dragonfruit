## Goal

Make every Dock icon a real rounded-square (squircle) tile: themed artwork is
clipped to the tile shape, so square or transparent-padded theme icons read
like the reference's uniform squircles instead of an inset-and-fitted square.
Closes the deviation T-14.7j recorded (its inset+fit approximation), keeping the
reference's tile radius/inset.

## Context (read first)

- `shell/dock/DockGlyph.qml` — the themed `Image`/`VectorImage` fill, the
  placeholder tile radius, the folder/trash geometry. Artwork currently fills
  the tile with `PreserveAspectFit` and `component.dock.icon.inset` (0.06),
  with no clip.
- `design-system/tokens/tokens.json` → `component.dock.icon.radiusRatio`
  (0.24) / `.inset` (0.06); `scripts/gen-tokens.py` regenerates `Theme.qml`.
- ADR [0102](../design/adr/0102-dock-material-role-and-qml-glass-layers.md)
  and the T-14.7j Hand-off deviation: *"Arbitrary square theme artwork is inset
  and fitted, not per-pixel squircle-masked: the headless software scene graph
  has no mask pass, so a real mask would be GPU-only and invisible to the pixel
  tests. True squircle masking is deferred with liquid-glass refraction."*
- Reference measurements from `docs/reference/macos/Dock.png`: icon tiles are
  rounded squares ~49 pt with a consistent corner radius (~0.22–0.24 of the
  tile) and the artwork reaching the tile edge; there is no visible square
  letterbox.
- `shell/tests/tst_dock.qml` — glyph/tile cases; the renderer used by
  `make qml-test` is the software scene graph that must be able to observe the
  clip.

## Current behavior (shipped after T-14.7j)

- A square theme icon (or one with its own transparent padding) renders as a
  fitted square inside the tile; only the placeholder tile draws a rounded
  rectangle. Squircles are therefore inconsistent between the placeholder and
  real themed artwork.

## Scope

- [ ] Implement a real tile clip in `DockGlyph.qml`: a rounded-rect/squircle
      mask (`OpacityMask`/`MultiEffect`/`ShaderEffect` with a software
      fallback, or a `Canvas`/`Rectangle` clip where the scene graph supports
      it) applied to the themed artwork for every entry kind (app, temporary,
      recent, folder stack, placeholder). Use the token radius; do not add a
      literal.
- [ ] Choose the mechanism that the headless software scene graph used by
      `tst_dock.qml` can observe, so a pixel test can assert the corner is
      transparent/clipped (the reason T-14.7j deferred it). If a GPU-only path
      is unavoidable, add a software clip fallback and document the tier split
      in the Hand-off and ADR 0102.
- [ ] Keep the T-14.7j material/inset/rim behavior: the mask sits inside the
      existing tile inset so the plate rim is unaffected; hover/press/focus
      states keep their current geometry.
- [ ] Reconcile `icon.radiusRatio`/`.inset` with the reference tile
      measurement; regenerate `Theme.qml` if the tokens move.
- [ ] Tests: `tst_dock.qml`/`tst_design_system` pixel cases asserting the
      corner is masked for a square test icon (and unchanged for round
      artwork), plus the placeholder/real-artwork parity; keep the existing
      geometry cases green.
- [ ] Capture `docs/captures/t14-dock-icon-mask-{light,dark}.png` (a square
      theme icon, a padded icon, a rounded icon side by side) and the
      `PROGRESS.md` note.

## Explicitly deferred

- True liquid-glass refraction (a real texture sampler) — still deferred per
  ADR 0102; this unit is the tile clip only.
- Per-icon artwork (we render the user's theme icons).
- Animated squircle morphs on launch (macOS zoom) — a later motion unit.
- Folder/Trash artwork internals (their own geometry, T-14.7d/T-14.7k).

## Design notes

- Reproduce the language with our own geometry; never an Apple bitmap
  ([14-risks.md](../design/14-risks.md)).
- One mask source of truth: radius/inset from tokens; do not re-derive in each
  entry kind.
- The clip must not clip the running indicator, badge, tooltip, or focus ring
  (those are siblings of the artwork, not children).
- Degrade intentionally: if a mask tier is unavailable, fall back to the
  current inset+fit look rather than an unmasked square.
