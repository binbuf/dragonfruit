## Hand-off

**State: done.** The OSD is keyboard/AT-SPI accessible and the T-11 capture set
is committed. Contract frozen in [adr/0063](../design/adr/0063-osd-keyboard-atspi.md).

What landed:

- **`shell/osd/Osd.qml`** — the alert keeps `Accessible.role: Alert` + the
  value-derived `Accessible.name`, and gains `Accessible.description`
  ("Volume 60 percent. Press Escape to dismiss." / "Volume is muted. Press
  Escape to dismiss."), `Accessible.focusable`, `Accessible.onPressAction`,
  a `dismissed()` signal, and `Keys.onEscapePressed`.
- **`shell/src/shellcontroller.cpp`** — `onKeyEvent` hides a visible OSD on
  Escape (before the Control Center check) so a keyboard user can clear the
  unfocused alert; the OSD component's `dismissed()` connects to `hideOsd()`.
- **`design-system/components/Icon.qml`** — the `volume` glyph is now a speaker
  (body + cone + waves); the T-11.4a "drive slab" read as a battery in the
  capture. Affects the OSD and the Control Center Sound tile.
- **Tests** — `tst_osd.qml` 7 cases: role/name/description, muted wording,
  Escape -> `dismissed`. `make qml-test` 38/38; `make lint` and `make e2e`
  exit 0.
- **Captures** — `scripts/capture-osd-dnd.sh` +
  `scripts/capture-osd-dnd-driver.py` (new; `make osd-dnd-capture`) write
  `docs/captures/t11-osd.png`, `t11-osd-context.png`, `t11-dnd.png`; the
  `t11-control-center*.png` stills are refreshed with the speaker glyph.
- **Docs** — ADR 0063; `04-shell.md` T-11.4b status; `docs/captures/README.md`.

Commands that work (repo root; `make` sets the toolchain env):

- `make qml-test` 38/38; `make lint` exit 0; `make e2e` exit 0.
- `LD_LIBRARY_PATH=$HOME/.local/df-toolchain/usr/lib64 ctest --test-dir build
  -R tst_osd` — 9/9.
- `make osd-dnd-capture` — writes the three new stills (host Wayland +
  `spectacle` + Pillow).

Live visual check: `docs/captures/t11-osd.png` (centered card, speaker glyph,
accent bar, `100%`), `t11-osd-context.png` (card centered over the Settings
window, Control Center open, DND crescent in the bar), `t11-dnd.png` (accent
crescent immediately left of the clock). Vision verdict: sharp, no clipping or
artifacts, glyph now reads as a speaker, not a battery.

Deviations / gotchas for later tasks:

- **The fixture mock seeds a banner even in DND** (`MockNotificationClient`),
  so the capture driver clicks it away before the OSD drag; the real service's
  suppression is the Rust policy tested elsewhere. Do not read the fixture as
  proof of suppression.
- **The OSD is still non-interactive and never takes focus.** `Escape` is
  handled at the shell level; a real screen reader announcement depends on the
  AT-SPI tree, whose live dump/walkthrough is T-16.6a. No hardware media keys
  are wired yet (route them into `ShellController::showOsd` later).
- **`Icon.qml` `volume` is shared** by the OSD and the Control Center Sound
  tile; the design-system gallery snapshot only renders titlebar/utility
  glyphs, so `make visual-test` is unaffected.
- T-12.1a begins the session work.
