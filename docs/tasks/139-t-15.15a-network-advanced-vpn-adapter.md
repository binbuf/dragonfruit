## Hand-off

**State: done.** The VPN adapter landed in `services/networkmanager/src/vpn/`
as a second adapter inside the existing NetworkManager crate (same daemon; ADR
0146), over its own `VpnSource` seam and `AdapterId::VPN` (`"vpn"`):

- `VpnSource` / `MockVpn` (`services/networkmanager/src/vpn/source.rs`) —
  `read`/`activate`/`deactivate`; absence, failing, deny/fail-write control,
  and an accepted write mutates the simulated store so a round-trip is
  observable headlessly.
- `VpnSnapshot` / `VpnKind` / `VpnState` (`.../vpn/model.rs`) — joins settings
  connections to active connections, names the tunnel flavour, sorts connected
  first, derives glyph/label.
- `VpnAdapter` / `VpnAccess` / `VpnResult` (`.../vpn/adapter.rs`) — three-state
  reads, subscription events, and two explicit writes with the polkit
  read-only degradation (mirrors ADR 0027).
- `DbusVpn` + proxies + `vpn_connection_from_settings` (`.../dbus.rs`) — the
  live `Settings.Connection.GetSettings` / `Connection.Active` read and
  `ActivateConnection`/`DeactivateConnection` writes; `libnm` never linked.
- Tests: 7 acceptance in `tests/vpn_read_path.rs` over
  `tests/fixtures/nm-vpn.json`, plus 67 lib unit tests.
