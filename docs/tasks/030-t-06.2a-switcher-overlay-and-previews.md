Gotchas for later tasks:

- **One recency source**: `AppSwitcher` on `DfState`. The shell renders the
  `app_switcher` + `app_switcher_entry` projection and never sorts or
  re-derives.
- The entry event carries only `index`/`app_id`; T-06.2b needs the window
  handle to address a window, so append it additively rather than changing the
  signature.
- The compositor hides non-entry visible windows with `alpha = 0` while the
  switcher is active; a switcher transition (open/close animation) is not
  implemented (the overlay appears instantly; reduced motion is the same).
- The shell card row is a non-wrapping `Row`; many apps need wrapping/paging.
- The preview layout and the shell cards are separate (the compositor grid
  above `CARD_STRIP`, the shell row at the bottom); they agree on the strip
  height via the shared tokens but do not share per-card geometry. Aligning
  them (and drawing per-card labels under each preview) is a polish item.
