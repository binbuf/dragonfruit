## Goal

Click a live window in the overview and route through the existing selection round-trip.

## Scope

- Hit-test transformed surfaces in the overview; click selects and reverses the scene.

## Explicitly deferred

- Keyboard-only grid is the existing shell path (unchanged).

## Acceptance (agent-completable)

- [ ] Pointer selection on a live representation works and focuses the window.

## Test plan

- Headless hit-test transfer conformance; nested capture.

## Hand-off

**State: done.** Pointer selection on a live representation hit-tests the
interpolated Mission Control grid transform and routes through the existing
selection round-trip.

- `compositor/src/overview/grid.rs` — `GridLayout::window_at(point, progress)`
  hit-tests `GridPlacement::frame(progress).rect` (the renderer's exact rect),
  most-recently-used first. 3 new unit tests.
- `compositor/src/state.rs` — `DfState::overview_window_at(point)` (output +
  interpolated layout hit) and `DfState::select_overview_window(id)` (the one
  round-trip: `overview.select` → `activate_window_id` → `broadcast_overview`).
- `compositor/src/shell/mod.rs` — `select_overview_toplevel` now calls the same
  `select_overview_window`, so keyboard and pointer selection cannot diverge.
- `compositor/src/input.rs` — a left press while `InputOwner::Overview` hit-tests
  the grid before titlebar/menu handling; committed geometry is never consulted
  in the overview.
- `compositor/tests/window_conformance.rs` — new
  `overview_click_selects_and_focuses_the_live_representation` (27/27 green):
  settles the grid, clicks a representation whose target center is outside its
  committed rect, asserts the grid closes, the window gets the `focused` event,
  and all live surfaces stay mapped.
- Docs — `02-compositor.md` "Pointer selection on live representations
  (T-05.2)". No new ADR (extends ADR 0017; no new constraint).

Commands (repo root): `cargo test -p dragonfruit-compositor --bin
dragonfruit-compositor` (235 green), `... --test window_conformance` (27
green). Direct cargo needs `PKG_CONFIG_PATH=~/.local/df-devroot/lib64/pkgconfig`
and `RUSTFLAGS=-L ~/.local/df-devroot/lib64`.

Deviation / gotcha: selection leaves the overview immediately (no reverse
animation), matching the existing `select_overview_toplevel` round-trip; a
clicked grid window is the live surface, so it stays mapped. Nested capture was
not added (T-05.6 owns the T-05 visual capture, as in T-05.1a/b). T-05.3 adds
cross-Space drag and must reuse `GridPlacement` — do not add a second transform.
