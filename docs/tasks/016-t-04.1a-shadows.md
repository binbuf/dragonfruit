## Goal

Elevation-token-driven shadows for chrome, SSD titlebars, and floating windows, shared between compositor and QML so they cannot drift.

## Scope

- Shared elevation tokens drive compositor-drawn SSD and QML `TitleBar`.
- Shadows for chrome, titlebars, and floating windows.

## Explicitly deferred

- Rounded-corner clipping (T-04.1b), blur (T-04.2).

## Acceptance (agent-completable)

- [x] Shadows render from tokens; compositor and QML agree.

## Test plan

- Headless: shadow element present with token-derived geometry; gallery golden updated.

## Hand-off

**Landed.** Elevation-token shadows on both sides of the process boundary from
one source.

- Tokens: `component.elevation.{low,med,high,overlay}` in `tokens.json`
  (blur/offsetY/layers from `primitive.elevation.*` + `component.shadow.*`),
  regenerated into `Theme.qml` + `design_tokens.rs`.
- Compositor: `compositor/src/window/shadow.rs` (`ShadowLevel`, `ShadowSpec`,
  `shadow_layers`, `shadow_bounds`, `shadow_elements`) and
  `render::window_shadow_render_elements`, wired into nested + DRM after
  `window_render_elements`. `WindowInsets::outset` and a shared
  `motion_transform` were added to `decoration.rs`.
- QML: `Shadow.level` (default `high`) and `AppWindow.shadowLevel`; gallery
  `WindowPage` shows the four levels.
- Docs: ADR 0011; 02-compositor.md, 05-window-decorations.md,
  10-design-system.md.
- Verify: `cargo test -p dragonfruit-compositor` (190 unit + suites green),
  `make qml-test`, `make clippy`, `make fmt-check`, `make check-tokens`,
  `make check-design-tokens`, `./scripts/check-gallery-snapshots.py --strict`
  (66/66; only `window_{light,dark,dark_reduced}.png` changed).

**Deviations / for the next task (T-04.1b).** The compositor shadow is
rectangular and unblurred — rounded-corner clipping (T-04.1b) and backdrop
blur (T-04.2) are deferred as planned. T-04.1b should put the radius clip on
this same shadow/window pass and make `shadow_layers` follow
`component.window.radius`. `render::window_shadow_render_elements` still uses
the default dark scheme until T-08. The DRM wire-up follows the existing
(nested-mirroring) ordering but is untested without hardware. The committed
gallery goldens can churn on a full `make gallery-snapshot`; see the T16
PROGRESS section.
