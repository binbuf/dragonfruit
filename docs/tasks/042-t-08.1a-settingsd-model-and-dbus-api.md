## Goal

The desktop-settings provider with named, schema-documented keys and get/set/change signals.

## Scope

- Provider for Dock, workspaces, gestures, appearance dark/light/accent, animation policy, input repeat.
- `org.dragonfruit.Settings1`: named schema-documented keys; get/set; change signals (no polling); additive-only within a release.
