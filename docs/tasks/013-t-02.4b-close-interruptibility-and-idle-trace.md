## Hand-off

**Landed.** A live close ghost is now interruptible. `DfState::interrupt_close`
(and `restore_window` of a closing window) replaces the `Close` with a
`Restore` whose origin is the ghost's **current interpolated rect**
(`begin_window_motion_from`), re-maps the window into the layout/input path at
once, and returns focus; the pending removal is dropped with the replaced
motion, so no `Closed` is broadcast and (`step_window_motions` commits removal
only while the kind is still `Close`). `close_window` now releases keyboard
focus at ghost time and, because Smithay does not invoke `focus_changed` on an
unset, mirrors the change itself (`active_window = None`, `Unfocused` broadcast,
shortcut scope cleared) — no phantom focus target.

**Tests.** `window_conformance.rs::close_reverses_mid_flight_and_the_idle_trace_stays_flat`
(22/22) drives a real toplevel: focuses it, closes, asserts the ghost releases
focus and does not commit, reverses mid-flight and checks the reverse origin is
strictly between the Dock tile and the geometry (no jump), resolves back to the
window, then closes for real and asserts exactly one `Closed`; finally samples
the SIGUSR1 render counters and asserts `frames_rendered` and
`animation_frames_stepped` are flat. Unit tests: motion `is_close`/mid-flight
reverse, synthetic `interrupt-close`/`reopen` parsing. Commands: `make
cargo-test` (177 bin unit + all suites), `make clippy`, `make fmt-check`, `make
e2e` — all green.

**Deviations.** (1) The reversal is a compositor primitive driven by
`interrupt-close`/`restore`; the T-07 shell/Dock "activate a closing window"
wiring is a follow-up (the protocol seam does not exist yet). (2) A
well-behaved client destroys itself on `send_close`, so the capture cannot
show a live interrupted close; the reversal is exercised headless. (3) The
`docs/captures/t02-*` clip is assembled from settled stills (the environment
has no scriptable Wayland screen recorder); live motion is T-03.1a's trace.

**Docs.** ADR `0008-close-interruption-and-ghost-focus.md`;
`docs/design/02-compositor.md` "Window lifecycle motion";
`docs/captures/README.md` names `scripts/capture-motion.sh`.

**Capture.** `docs/captures/t02-lifecycle-motion*` stills,
`t02-lifecycle-motion.mp4`, `t02-lifecycle-motion-reduced.mp4` (regenerate with
`SETTLE=8 bash scripts/capture-motion.sh`).

**For T-03.1a.** Drive the close/reverse/close loop if useful; the idle
assertion (`frames_rendered` flat) is already in the headless suite. Keep the
single motion driver and the single `remove_window` path.
