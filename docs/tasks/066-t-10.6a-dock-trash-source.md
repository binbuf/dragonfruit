## Hand-off

**State: done.** The Dock's Trash state now comes from `files-core` over the
shared freedesktop store, and the shell's interim `TrashMonitor`
(`QFileSystemWatcher` over `$XDG_DATA_HOME/Trash`) is deleted.

What landed:

- **`services/files-core/src/trash_source.rs`** (new) — `TrashSource`, a
  `DirectorySource` over `trash://` (items are `Node`s named by stored name at
  `trash:///<name>`); `TrashMonitor` (count/available + change events on the
  T-10.3b `FolderWatcher` over the store's `info/`); `TrashState`.
- **`services/files-core/src/ffi.rs`** — the C ABI
  `df_files_trash_monitor_{new,free,state,wait,refresh,trash,empty,take_error}`
  plus `df_files_trash_state`; `df_files_begin` dispatches `trash://` to
  `TrashSource`. New test `trash_monitor_abi_reads_trashes_and_empties`.
- **`shell/src/trashbridge.{h,cpp}`** (new) — `TrashBridge` wraps the ABI; a
  worker thread blocks on `wait` and posts changes to the UI thread.
- **`shell/src/files_core_trash.h`** (new) — the mirrored C header.
- **Deleted** `shell/src/trashmonitor.{h,cpp}` and its seven
  `trashMonitor*` tests; `tst_dockcore` has four `trashBridge*` tests instead
  (they point `XDG_DATA_HOME` at a temp dir).
- **CMake** — the `dragonfruit-files-core` imported staticlib is defined once
  at the top level and linked by both Files and `dragonfruit-shell-dockcore`.
- **Docs** — ADR [0052](../design/adr/0052-dock-trash-state-from-files-core.md);
  `09-files.md` T-10.3a deferred-note and a T-10.6a status paragraph.

Not in this task (deferred as specified): the Drop-to-trash / Empty Trash UX
rework and `trash://` navigation (T-10.6b) and Show in Files / Downloads /
`.desktop` identity (T-10.6c).

Gotchas for T-10.6b:

- Drop and Empty already route through `TrashBridge::trash`/`empty` (the
  deleted class did these too), so T-10.6b owns the *UX* (confirmation,
  feedback) and `trash://` navigation rather than the routing.
- The monitor watches **only the home trash** (`$XDG_DATA_HOME/Trash`); a
  trash on another volume goes to that volume's `.Trash-$UID`. The Dock badge
  intentionally counts the home store.
- `TrashSource` nodes currently carry `trash:///<name>` URIs; Put Back/Delete
  Immediately over them is T-10.6b/c.
- The shell links the `files-core` staticlib now; keep new shell-side files on
  the small trash header rather than pulling in the listing/model ABI.
