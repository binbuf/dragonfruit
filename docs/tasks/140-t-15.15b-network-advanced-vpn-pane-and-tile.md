## Reference UI/UX (macOS screenshots)

Local macOS **Tahoe 26** captures only (`docs/reference/macos/` never ships; see
[14-risks.md](../design/14-risks.md)). The per-image inventories are
[`SystemSettings_Network.md`](../reference/macos/SystemSettings_Network.md) and
[`SystemSettings_WiFi.md`](../reference/macos/SystemSettings_WiFi.md); the
shared interface language and Linux adaptations are in
[ADR 0122](../design/adr/0122-tahoe-interface-language-across-chrome.md).
Distilled in [System_Preferences.md](../reference/System_Preferences.md).

**Sections and rows (observed order):**

- **`Network`** — selected sidebar row: blue fill, no trailing chevron; the
  list is continuous (Search field, `Wi-Fi`, `Bluetooth`, `Network` selected,
  then the other system rows).
- **`Wi-Fi`** — disclosure row: icon, label, green dot with secondary
  `Connected`, trailing chevron.
- **`Firewall`** — disclosure row: icon, label, gray dot with secondary
  `Inactive`, trailing chevron.
- **`Other Services`** — section header over `USB 10/100/1000 LAN` and
  `Thunderbolt Bridge`, each a disclosure row with red dot and secondary
  `Not connected`, trailing chevron.
- **Footer** — `...` ellipsis menu (with down chevron) and `?` help button.
- **`Wi-Fi` pane** (`SystemSettings_WiFi.md`): `Wi-Fi` header toggle (on) with
  the description "Set up Wi-Fi to wirelessly connect your Mac to the internet.
  Turn on Wi-Fi, then choose a network to join. Learn More..."; current network
  row (`Connected`, green dot, lock, signal, `Details...`); `Known Network`
  (checkmark, lock, signal, ellipsis); `Other Networks` (nearby-network list,
  each lock/signal/ellipsis, then `Other...`); `Ask to join networks` (popup,
  `Notify`) and `Ask to join hotspots` (popup, `Ask To Join`), each with its
  description. Network names are redacted to `<network>` placeholders in
  `System_Preferences.md`.
- **VPN and advanced network settings** — no VPN row and no sub-pane appear in
  either capture, so their nesting is unconfirmed; map VPN rows and the
  connections behind the chevrons to NetworkManager over the adapter's D-Bus
  seam (T-15.15a, never `libnm`).

**Apple-only (adapt or omit):** iCloud Private Relay and Apple-specific
services (none appear in these captures); the Apple Account, Apple
Intelligence & Siri, and Screen Time sidebar rows; `Thunderbolt Bridge` is
Apple-hardware-specific and maps to the host's bridge-type devices.
