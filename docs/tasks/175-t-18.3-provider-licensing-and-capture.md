### Deviations / notes for the next session

- **`make check` still fails only on `check-desktop-names`** (pre-existing
  StatusNotifier/zoo/apppicker lines; unchanged by this task). `make lint`
  otherwise passes.
- **Two robustness fixes were needed to keep e2e green in this harness
  environment, both outside T-18.3's nominal scope:**
  1. `compositor/tests/milestone_e2e.rs::xwayland_running_for` did a substring
     scan of every `/proc/*/cmdline` for `"Xwayland"` + `":1"`. The agent
     process's argument is the whole task document, which mentions both, so
     teardown falsely reported a leaked Xwayland. It now splits argv and
     requires argv[0] basename `Xwayland` and the display as a whole argument.
  2. `services/wallpaperd/tests/session_bus.rs::preload_round_trips…` read a
     zbus-cached property immediately after `Preload`; under load the method
     reply beat the `PropertiesChanged` signal and read the stale `idle`. It
     now waits (bounded) for the cache to catch up; the returned snapshot is
     the authoritative state.
- **`assets/graphics/wallpapers/Default.jpg` provenance.** The file is a real
  camera photograph (EXIF: Canon EOS 5D Mark IV, Lightroom Classic, 2024-11;
  no watermark). It was added to the repo in the early `c138043` snapshot and
  is documented as the project's original asset (ADR 0094). This session could
  not independently prove authorship from the repo alone, so the licensing
  claim rests on that prior project decision; if a provenance record exists,
  keep it with the asset. Vision described it as a twilight rice-paddy
  landscape, Southeast-Asian, no visible branding.
- The shipped default resolves with a `../../`-relative path from the crate in
  the in-tree case; harmless, but canonicalizing would make the transcript
  prettier.
- Fetching only happens with a real network; the capture's real-fetch half was
  run here and succeeded (deterministic Nature default selected).
