## Goal

Land the licensing policy for both the shipped original default and the fetched
content, prove the first-run/offline/weekly/preload matrix, hand i18n/a11y
coverage to T-16, and capture the track's demo.

## Context (read first)

- `docs/licensing.md` — MIT repo-wide; the "no copyleft dependency" and
  "original assets only" rules; the "Fetched third-party content (wallpaper)"
  section; the asset table that must list the shipped `Default.jpg`.
- `assets/graphics/wallpapers/Default.jpg` — the project's original shipped
  default; confirm provenance before it is listed as an original asset.
- `docs/design/14-risks.md` — Apple-artwork rule and the public-release gate.
- ADR [0055](../design/adr/0055-online-wallpaper-content-provider.md) /
  [0094](../design/adr/0094-bundled-default-wallpaper-and-lazy-cache.md).
- `docs/SLICING-REVIEW.md` — track-boundary sign-off.

## Scope

- [ ] Add the shipped default to the project asset table in `docs/licensing.md`

- [ ] Extend the "Fetched third-party content (wallpaper)" section: the shipped

## Design notes

- Licensing is a first-public-release blocker; do not ship a package that
  bundles any fetched image or omits attribution. Shipping our *own* original
  default is intended and licensed (ADR 0094).
- Record the manual parts (real network, real gallery) honestly rather than
  claiming them in the headless path.
