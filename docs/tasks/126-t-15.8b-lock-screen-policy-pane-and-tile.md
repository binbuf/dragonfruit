- Absence case documented.

## Explicitly deferred

## Reference UI/UX (macOS screenshots)

Local art-direction only — images in `docs/reference/macos/` (never shipped;
see [14-risks.md](../design/14-risks.md)), distilled in
[System_Preferences.md](../reference/System_Preferences.md). Target: mirror
the macOS Lock Screen pane (`Screenshot 2026-09-18 at 9.21.45 PM.png`)
nearly verbatim in style, information architecture, section order, row
labels, control types, and wording.

Sections and rows (observed order):

- Display-off timing (first, untitled group):
  - **Turn display off on battery when inactive** — popup, `For 10 minutes`;
    idle blank timer (T-12.4a); per-source provider TBD (T-15.6a).
  - **Turn display off on power adapter when inactive** — popup,
    `For 20 minutes`; warning footer (`Mac` → `system`).
  - **Require password after screen saver begins or display is turned off**
    — popup, `After 5 seconds`; lock delay (T-12.5b) + lock UI (T-12.3a),
    adapter T-15.8a.
- Lock-screen options (second, untitled group):
  - **Show user name and photo** — toggle, on; lock UI presentation
    (T-12.3a); key provider TBD (T-15.x).
  - **Show password hints** — toggle, off; PAM auth (T-12.3b), never a
    custom store; hint behavior is macOS-only, adapted below.
  - **Show message when locked** — toggle + dimmed `Set...` button; lock UI
    (T-12.3a); provider TBD (T-15.x).
- **When Switching User** (only section header):
  - **Login window shows** — radio group, `List of users` (selected) /
    `Name and password`; host display manager (T-12.2).
  - **Show the Sleep, Restart, and Shut Down buttons** — toggle, on; host
    display manager (T-12.2).
  - **Accessibility Options...** — button + `?` help; provider TBD (T-15.x).

Grouped inset lists; switch-user rows are host display-manager territory.

Adapt or omit (Apple-only):

- Touch ID / Apple Watch unlock (`Touch ID & Password` sidebar row).
- Siri on the lock screen (`Apple Intelligence & Siri` sidebar row).
- FileVault (omit); macOS-only password hint behavior: PAM hints (T-12.3b).
