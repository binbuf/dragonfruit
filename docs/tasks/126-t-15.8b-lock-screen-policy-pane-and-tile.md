**Sections and rows (observed order):** Observed in the Tahoe capture:
- First untitled group (display/password timeout):
- `Turn display off on battery when inactive` (popup, `For 10 minutes`).
- `Turn display off on power adapter when inactive` (popup, `For 20 minutes`)
  with a warning row (yellow triangle): "Energy usage may be higher when this
  Mac is inactive for longer periods of time before the display turns off."
- `Require password after screen saver begins or display is turned off`
  (popup, `After 5 seconds`).
- Second untitled group (lock-screen display options):
- `Show user name and photo` (toggle, on).
- `Show password hints` (toggle, off).
- `Show message when locked` (toggle, off; trailing `Set...` button dimmed).
- `When Switching User` (the only section header):
- `Login window shows` (radio group, `List of users` selected /
  `Name and password`).
- `Show the Sleep, Restart, and Shut Down buttons` (toggle, on).
- `Accessibility Options...` (button, bottom-right, `?` help).
- Header/chrome: centered pane title, back/forward chevron pill (forward dimmed), sidebar `Search` field, trailing `?` help.

**Apple-only (adapt or omit):**
- Touch ID / Apple Watch unlock (`Touch ID & Password` sidebar row).
- Siri on the lock screen (`Apple Intelligence & Siri` sidebar row).
- FileVault (omit); macOS-only password hint behavior: PAM hints (T-12.3b).
- Sidebar `Apple Account`, `Screen Time`, `Internet Accounts`, `Game Center`,
  `iCloud`, and `Wallet & Apple Pay` rows.

## Hand-off

**Shipped.** The Lock Screen pane (`apps/settings/LockScreenPane.qml`) and the
Control Center Lock Screen tile ship together, shell-native plus settingsd keys
(ADR 0133), the T-15.5b Mission Control precedent. Settingsd is revision 15
with a new `lock` group (`lock.showUserNameAndPhoto`, `lock.showPasswordHints`,
`lock.showMessageWhenLocked`, `lock.message`, `lock.showPowerButtons`); the two
timing rows reuse the revision-5 `idle.blank`/`idle.lock` keys the session idle
engine already applies live. The pure `lockPolicyView` in
`shell/src/controlcenterpolicy.cpp` projects the tile subtitle; the shell never
touches the compositor lock path. A new design-system `lock` glyph was added.

**Deviations from the macOS capture (recorded in ADR 0133 / the pane header):**
the battery/AC display-off pair collapses to one `Turn display off when
inactive` row (ADR 0132's Linux adaptation); `Login window shows` is omitted
(no login-window provider) and `Accessibility Options...` is omitted (the
Accessibility pane is not shipped — a link would be a dead control); the Apple
Account/sidebar row and `?` help are omitted project-wide (ADR 0122). The
energy warning is shown for any long display-off delay, not only on battery.

**Stored policy, not yet consumed.** The four `lock.*` display keys
round-trip live and the pane/tile reflect them, but `shell/lock/LockScreen.qml`
does not yet read them to hide the name/photo, hints, custom message, or power
buttons. That renderer wiring is in `docs/PROGRESS.md` under `## Follow-ups`.
The compositor lock and the session timing are untouched.

**Next (T-15.9a, Menu Bar configuration) must know:** the Control Center panel
is now 360×1120 (`kControlCenterHeight`), the tile list has 11 entries (Battery
is index 9, Lock Screen index 10), and any new tile must update
`test_panel_content_fits_the_shell_surface`, the constant, and the capture
crops together. Settingsd is revision 15; `settingsSchemaDefaults()` and
`docs/settings-keys.md` are in sync.

**Commands:** `cargo test -p dragonfruit-settingsd`; `ctest --test-dir build
--output-on-failure -j4` (62/62); `make e2e` (EXIT 0); `cargo fmt --all --
--check`; `make check-design-tokens check-tokens check-no-capture-grab`;
`./scripts/check-gallery-snapshots.py` (78 green).

**Live visual check:** `bash scripts/capture-t15-lock-pane.sh` produced
`docs/captures/t15-8b-lock-screen-pane.png` (2088×1410) and
`docs/captures/t15-8b-lock-screen-control-center.png` (360×1120). Vision found
all pane rows, the "When Switching User" note, and the Lock Screen tile
(`Password after 10 min`) rendered as intended with no clipping, overlap, or
stray artifacts. Verdict: the surface reads as designed.
