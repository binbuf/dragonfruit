## Hand-off

**State: done.** The shell and first-party apps are translatable and a locale
switch translates them; dates/numbers follow the locale. Contract in
[ADR 0156](../design/adr/0156-localization-catalogs-and-locale-formatting.md).

What landed:

- `libs/i18n/` (new static library `dragonfruit-i18n`) — `CatalogTranslator`
  reads Qt `.ts` XML at runtime (no `lupdate`/`lrelease` dependency),
  `resolveLocale()` honors `DRAGONFRUIT_LOCALE` then `QLocale::system()`,
  `catalogSearchPaths()` (env → source tree → install prefixes),
  `installTranslations()`/`installTranslationsFor()` install the catalog and
  set `QLocale::setDefault`. `libs/i18n/tests/tst_i18n.cpp` — 9 tests
  (parser, unfinished/empty skip, malformed rejection, in-tree es catalog,
  locale override, QML `qsTr()` through the installed catalog, default-locale
  number/date formatting).
- Entry points wired: `shell/src/main.cpp`, `apps/settings/main.cpp`,
  `apps/files/main.cpp` call `Dragonfruit::installTranslations(app)` before
  QML loads; the three executables link `dragonfruit-i18n`.
- `apps/files/FilesDirectoryModel.cpp` — size/modified formatting uses the
  default `QLocale()` (not `QLocale::system()`) and the Kind column strings
  ("Folder"/"File"/"Alias"/"Item") are now `QCoreApplication::translate`.
- `scripts/i18n-extract.py` + `make check-i18n` (in `make lint` and CI) — the
  string-extraction gate: 909 strings / 65 contexts, template in sync, no bare
  user-visible QML literals. `make i18n-update` regenerates the template.
- `translations/dragonfruit.ts` (template, 909 strings) and
  `translations/dragonfruit_es.ts` (458 Spanish translations across 45
  contexts: chrome, Control Center, Dock, Files, session/portal dialogs, the
  General pane).
- `scripts/capture-t16-i18n.sh` + `make t16-i18n-capture` —
  `docs/captures/t16-i18n-{en,es}.png` and the stacked `t16-i18n.png`.
- CMake install rule ships the `.ts` files under
  `${CMAKE_INSTALL_DATADIR}/dragonfruit/translations`.

Deviations / notes for T-16.8 and later:

- **No Qt Linguist tools in the toolchain.** Catalogs are parsed at runtime, so
  `.ts` files are shipped directly; there is no `.qm` build step. If
  `lupdate`/`lrelease` are ever adopted, the checked-in `.ts` files are already
  the standard format.
- **Locale is selected at process start** (`DRAGONFRUIT_LOCALE` or
  `LANG`/`LC_*`). In-place runtime switching (with `QQmlEngine::retranslate()`)
  is not implemented.
- **Spanish coverage is partial by design** (458 of 909 strings); untranslated
  strings fall back to English. RTL polish is deferred as the task states.
- The extraction gate scans `shell/`, `apps/`, and `design-system/components`,
  excluding `tests/`; a bare literal in a `text:`/`title:`/`label:`/
  `placeholderText:`/`description:`/`accessibleName:`/`Accessible.name:`
  property fails it (escape with `// df-allow-untranslated`).

- T-16.8 hardens crash recovery.
