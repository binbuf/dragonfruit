## Reference UI/UX (macOS screenshots)

Local art direction only: images in `docs/reference/macos/` (never shipped; see
[14-risks.md](../design/14-risks.md)), distilled in
[System_Preferences.md](../reference/System_Preferences.md). The captured pane
is the near-verbatim target for our Wallpaper pane.

Sections and rows (observed order):

- **Current wallpaper card**: large preview with its name (`Tahoe Evening`)
  and the **`Show on all Spaces`** toggle.
- **`Dynamic Wallpapers`**: grid of labelled tiles with info badges and a
  `Show All (34)` link.
- **`Your Photos`**: the **`Add Photo…`** button opens a file chooser; ours
  uses the portal file chooser.
- **`Landscape`**: grid of labelled tiles with video and download badges,
  ending in a `Show All (79)` link.
- **`Cityscape`**: grid of labelled tiles with video and download badges,
  ending in a `Show All (30)` link.

Ours is per-Space by design (T-05.4): `Show on all Spaces` is carried by the
per-Space model as an affordance decided at implementation, and fit is
chosen per selected wallpaper.

Adapt or omit (Apple-only): bundled Apple artwork by name (`Tahoe`,
`Sequoia`, `Macintosh`, `Sonoma`), the screensaver/clock buttons, and
iCloud-synced collections.

## Hand-off

**State: done.** Per-Space wallpaper selection + fit are live and persisted.

- **What landed**: `apps/settings/WallpaperPane.qml` (hero preview, name,
  `Show on all Spaces`, fit segmented control, two original gradient
  collections, portal `Add Photo…`); `SettingsBridge` renders the presets and
  owns the portal chooser; new settingsd keys `wallpaper.source` /
  `wallpaper.fit` / `wallpaper.showOnAllSpaces` (schema 2); the shell forwards
  them per Space (`shell/src/wallpaperpolicy.*`,
  `ShellProtocol::setWallpaper`, `ShellController::applyWallpaperPolicy`); the
  compositor's `df_workspace.set_wallpaper` now changes only source/fit and
  keeps the Space color.
- **Verification**: `ctest --test-dir build -R tst_settings_wallpaper
  --output-on-failure` (7/7), `ctest --test-dir build -R tst_wallpaperpolicy`
  (5/5), `make qml-test` 26/26, `make lint` green, `make e2e` exit 0. Live
  capture `/tmp/opencode/t51-capture.sh` + `/tmp/opencode/t51v-window.png`:
  the compositor background changed `(33,13,41)` → `(37,97,100)` when
  `wallpaper.source` was set to a preset mid-session; vision read the pane
  sections with no clipping.
- **Deviations**: built-in artwork is generated gradient PNGs (no Apple
  artwork shipped); `Add Photo…` degrades to disabled when the portal is
  absent; per-Space distinct persistence is last-selection-only (needs a
  stable Space identity — T-16).
- **Decisions**: ADR [0038](../design/adr/0038-wallpaper-pane-settingsd-and-shell-forwarder.md).
- **For T-09.4**: `SettingsRow` has no default property — use
  `controlData:` for the control (the plain-child form overlaps the label).
  Add the pane to `SettingsShell.paneComponent` + `apps/settings/CMakeLists.txt`
  (QML_FILES + `df_qml_lint`). `DF_SETTINGS_START_PANE=<id>` opens a pane for
  captures.
