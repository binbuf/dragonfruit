## Goal

Settings pane and Control Center tile for Menu Bar configuration as one functional unit.

## Scope

- Settings pane and Control Center tile shipped together (no half-panes).
- Absence case documented.

## Explicitly deferred

- None.

## Reference UI/UX (macOS screenshots)

Local art-direction only — images in `docs/reference/macos/` (never shipped;
see [14-risks.md](../design/14-risks.md)), distilled in
[System_Preferences.md](../reference/System_Preferences.md). Target: mirror
the macOS Menu Bar pane (`Screenshot 2026-09-18 at 9.21.32 PM.png`) nearly
verbatim in style, information architecture, section order, row labels,
control types, and wording.

Sections and rows (observed order):

- First an untitled behavior group, then **Menu Bar Controls** (header plus
  footer: "System and app controls can be configured to appear in both
  Control Center and the menu bar."); rows map to the shell's status items
  ([04-shell.md](../design/04-shell.md)); T-15.9a's keys are additive (T-08).
  - **Automatically hide and show the menu bar** — popup, `In Full Screen
    Only`; shell menu-bar auto-hide; provider TBD (T-15.9a).
  - **Show menu bar background** — toggle, off; shell menu-bar background;
    provider TBD (T-15.9a).
  - **Recent documents, applications, and servers** — stepper, `10`; menu
    recents count (not the Dock's `dock.showRecentApps`); provider TBD.
  - **Add Controls...** — button; menu-bar/Control Center item management;
    provider TBD (T-15.9a).
  - **Clock** — list row + trailing `Clock Options...` button; shell clock
    status item; provider TBD (T-15.9a).
  - **Spotlight** — checkbox, checked; our Search entry, the app-index
    Spotlight-equivalent; provider TBD.
  - **Wi-Fi** — checkbox, checked; NetworkManager.
  - **Bluetooth** — checkbox, checked; BlueZ.
  - **Battery** — checkbox + trailing `Battery Options...` button; UPower.
  - **AirDrop** — checkbox, checked; omitted (Apple-only).
  - **Focus** — checkbox + `Show When Active` popup; notification service
    Focus/DND (T-15.7).
  - **Screen Mirroring** — checkbox + `Show When Active` popup; omitted.
  - **Display** — checkbox + `Show When Active` popup; compositor outputs.
  - **Sound** — checkbox + `Show When Active` popup; PipeWire/WirePlumber.

Adapt or omit (Apple-only):

- AirDrop and Screen Mirroring (Continuity/AirPlay) have no Linux equivalent.
- Sidebar Apple Account, Apple Intelligence & Siri, and Screen Time rows.
- Spotlight keeps its row as our Search entry (naming substitution only).
