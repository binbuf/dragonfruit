**Deviations / decisions.** (1) CUPS exposes no stable machine-readable local
API, so the live read shells to the CUPS client tools (`lpstat -l -t`) rather
than linking libcups or reimplementing IPP; this matches the audio/input adapter
precedent and keeps the churn in one fixture-pinned parser. (2) `lpstat` does
not print `printer-make-and-model`, so `make_and_model` is empty on the live
read (the field stays for fixtures and future IPP); no value is invented. (3)
`lpstat` does not print a job title, so `PrintJob` is `{id, user, size}`. (4)
`PrinterState::Unknown` (not `Idle`) is the unrecognized-code default, to avoid
inventing a state.

**For T-15.12b.** Add the Settings pane and Control Center tile; the adapter
has no surface. `AdapterId::PRINTER` / the wire id is `"printer"`. Absence is
layered: `printers: None` (CUPS absent) disables the print half only;
`scanners: None` (SANE absent) disables the scanner half only; the adapter is
`Unavailable` only when both are absent. No settingsd keys are defined here —
`Default paper size` and any presentation preferences are T-15.12b's to declare.
Adding a printer (discovery + `lpadmin -p …`) is *not* in this adapter; decide
that flow in T-15.12b and extend this adapter rather than reimplementing CUPS.
The write surface is `set_default_printer`, `set_printer_accepting_jobs`,
`cancel_job`; add methods deliberately if the pane needs more.
