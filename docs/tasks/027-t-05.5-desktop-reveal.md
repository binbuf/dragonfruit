**Done.** Ctrl+Down routes `DesktopReveal` through the one overview state
machine and the reusable scene transform.

What landed:

- `compositor/src/overview/reveal.rs` (new): pure `escape_rect` /
  `reveal_frame` geometry (slide to the nearest horizontal edge; reduced
  motion fades in place). 4 unit tests.
- `OverviewMachine::desktop_reveal_progress` (mirrors `overview_grid_progress`)
  + `input_owner` keeps the overview owning pointer hit-testing while
  `desktop_revealed`. 2 unit tests.
- `DfState::desktop_reveal_frame`; `window_render_frame` composes
  grid → reveal → lifecycle so surface/titlebar/shadow share one mapping.
- `query reveal` headless introspection + parser test.
- `window_conformance.rs`: `desktop_reveal_translates_live_surfaces_and_respects_reduced_motion`
  (Ctrl+Down opens, second restores, reduced motion fades in place). 30/30.

Commands / results: `cargo test -p dragonfruit-compositor` — 252 bin units and
every integration suite green (window_conformance 30/30). `cargo clippy -p
dragonfruit-compositor --all-targets -- -D warnings` and `cargo fmt -p
dragonfruit-compositor -- --check` clean.

Deviation: Escape/click/timeout restore and neighbour-Space reveal are out of
scope (only the second toggle restores). Nested capture + frame trace are T-05.6
(this task verified headlessly via `query reveal`). No ADR: reuses T-04/T-05.
