thin dividers; circular icon tiles; a trailing `... Settings...` text link
into the matching pane. The Focus and dark-mode toggles keep the same
accessible roles and Escape/click-away dismissal as the captured sheets.

## Hand-off

**State: done.** The Control Center panel now has Focus/DND and Dark Mode
tiles, both applying live; every tile carries accessible roles. Contract frozen
in [adr/0061](../design/adr/0061-control-center-toggles-and-a11y.md).

What landed:

- **`shell/control-center/ControlCenter.qml`** — two new tiles (Focus,
  Dark Mode) plus a `TextLink` component for the trailing `… Settings…` links.
  Five-tile `tiles` model; signals `focusToggleRequested(bool)` /
  `focusSettingsRequested()` / `darkModeToggleRequested(bool)` /
  `appearanceSettingsRequested()`. New properties `focusPolicy` (the
  notification service view) and `dark` (effective scheme). External switch
  state is applied with `Binding` elements, not `checked:` bindings, so a
  daemon round-trip re-syncs (the `Toggle` writes its own `checked`).
- **`shell/src/controlcenterpolicy.{h,cpp}`** (new, in dockcore) —
  `focusModeForToggle` (`dnd`/`off`) and `colorSchemeForDarkToggle`
  (`dark`/`light`), unit-tested.
- **`shell/src/shellcontroller.{h,cpp}`** — `applyControlCenterData` pushes
  `focusPolicy` + the effective `dark`; the four new slots write
  `setFocusMode(...)` to the notification client and `appearance.colorScheme`
  to settingsd; `onNotificationFocusPolicy` refreshes an open panel. Panel
  surface grows to 360×520.
- **`design-system/components/Toggle.qml`** — optional `accessibleName`
  (falls back to `text`).
- **`design-system/components/Icon.qml`** — a `focus` crescent painted glyph.
- **Tests** — `tst_controlcenter.qml` 18/18 (tiles, live switch/pointer,
  accessible roles, safe defaults); `tst_dockcore` mapping tests. ctest 36/36.
- **Docs** — ADR 0061; `04-shell.md` T-11.3b status; `settings-keys.md`
  `appearance.colorScheme` note.

Commands that work (repo root; `make` sets the toolchain env):

- `make qml-test` — 36/36; `make lint` exit 0; `make e2e` exit 0.
- `cargo test -p dragonfruit-notifications` — unaffected, still green.

Live capture: `scripts/capture-control-center-focus-dark.sh` (with
`DF_STATUS_FIXTURE=1 DF_NOTIFY_FIXTURE=1 DF_FOCUS_FIXTURE=dnd`) writes
`docs/captures/t11-control-center.png` (five tiles, Focus `Do Not Disturb`),
`t11-control-center-focus-dark.png` (Focus clicked off), and
`t11-control-center-dark-toggle.png` (Dark Mode on, panel dark), plus the
context still. Vision check: all five tiles render, live switch applies, no
clipping/artifacts.

Deviation / gotchas for the next task:

- **The Focus tile is a Do Not Disturb switch, not a three-way `focus`
  selector.** On=`dnd`, off=`off`; `focus` still lights it when set elsewhere.
- **Dark Mode writes an absolute `dark`/`light`, never `auto`**; the panel
  shows the effective (`auto`-resolved) state.
- **The `Focus Settings…` / `Appearance Settings…` links log only** — T-16
  wires Settings-on-a-pane.
- **No pixel assertion in the headless suites**; the color flip was verified
  only by the live captures above.
- **The notification fixture seeds a banner at the panel's corner**; the
  capture driver dismisses it by clicking the banner before opening the panel.
