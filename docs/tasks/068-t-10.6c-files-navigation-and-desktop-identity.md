## Goal

Show in Files reveals a path, Downloads rows open through Files, and the app identity is installed.

## Scope

- Show in Files reveals the path; Downloads-stack rows open through Files.
- Install `org.dragonfruit.Files.desktop` identity and register `org.dragonfruit.Files1`.

## Hand-off

Landed:

- **Identity** — `apps/files/org.dragonfruit.Files.desktop`
  (`Exec=dragonfruit-files %U`, `DBusActivatable=true`, `MimeType=inode/directory;`)
  and `apps/files/org.dragonfruit.Files1.service`, installed by CMake to
  `${CMAKE_INSTALL_DATADIR}/applications` and `.../dbus-1/services`.
  `apps/files/main.cpp` owns `org.dragonfruit.Files1` on the session bus.
- **Reveal** — `shell/src/filestarget.cpp` (`revealExecutable`: PATH-resolves a
  bare Exec program) and `apps/files/FilesArguments.h` (`filesOpenTarget`: a
  file argument becomes its parent folder + a `revealUri`). Show in Files and
  Downloads-stack rows both route through `ShellController::launchFiles`; Files
  opens the parent and selects+scrolls to the item (`Files.revealUri`,
  `FilesShell::applyReveal`, `scrollToNode` on both views).
- **Tests** — `tst_dockcore`: 3 reveal-resolution cases; `tst_files_arguments`:
  4 `filesOpenTarget` cases; `tst_files_shell.qml`: open-target + reveal-selects-row.
- **Docs** — ADR 0054; `09-files.md` T-10.6c status paragraph.

Commands / result:

- `cargo test -p dragonfruit-files-core` — all pass (12 watcher shown).
- `make qml-test` — 33/33 ctest green (`tst_files_shell`, `tst_dockcore`,
  `tst_files_arguments` included). Requires
  `LD_LIBRARY_PATH=$HOME/.local/df-toolchain/usr/lib64` when cmake regenerates.
- `make e2e` — exit 0; `make lint` pieces (fmt, clippy, tokens, design tokens,
  no-capture-grab, check-desktop-names) green.

Live visual check: `/tmp/opencode/t68-capture.sh` (driver `/tmp/opencode/t68-still.py`;
PNG `/tmp/opencode/t68-files-reveal-window.png`). Launched Files with
`DF_FILES_START_URI=<fixture>/notes.txt`, `DF_FILES_START_VIEW=list`. Raw vision
on the crop: window title/breadcrumb `Computer > tmp > dragonfruit-t68-capture.… >
reveal`; rows `Photos`, `archive.tar.gz`, `notes.txt`, `report.pdf`; the
`notes.txt` row is highlighted. The file argument is exactly what the shell's
`launchFiles` passes, so this exercises the reveal path. Vision is a supporting
check.

Deviations: "Downloads rows open through Files" is implemented as reveal (Files
opens the containing folder and selects the file), since Files has no
open-with-yet; opening the file with its registered handler remains T-18.
`DBusActivatable=true` is declared for the installed identity, but the shell's
interim launcher still uses the `.desktop` Exec (app-index/T-18 owns D-Bus
activation). The Settings app identity is not installed here (out of this
task's scope).
