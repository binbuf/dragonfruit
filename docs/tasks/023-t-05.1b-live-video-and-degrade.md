## Hand-off

**State: done.** A committing "video" client keeps advancing at the reduced
grid scale (the transform is render-time only — the surface stays mapped and
keeps its frame callbacks), and the T-04.4a material degrade tier is selectable
and genuinely applied to the Mission Control grid through one new
`overview_grid_material` accessor. No new ADR: this extends ADR 0015/0017.

What landed:

- `compositor/src/overview/grid.rs` — `GridMaterial { tier, shadow, blur }`
  and `GridMaterial::resolve(tier, scheme)`: the high-elevation token shadow and
  the material blur mapped through the active degrade tier, so the grid never
  invents material values. 2 unit tests (tier ladder, scheme tones).
- `compositor/src/state.rs` — `DfState::overview_grid_material()` (the one
  accessor; `None` when the grid is closed).
- `compositor/src/render.rs` — `window_shadow_render_elements` resolves its
  shadow through `overview_grid_material` while the overview is open, else the
  global tier (identical values outside the grid; the grid is now the explicit
  source).
- `compositor/src/input/synthetic.rs` — `query grid` gained a
  `grid material tier=<name> blur=<0|1> shadow_layers=<n> shadow_radius=<r>
  shadow_opacity=<o>` line (wire format documented). At `minimal` `blur=0`;
  `reduced`/`full` `blur=1`.
- `compositor/tests/window_conformance.rs` — new
  `overview_grid_keeps_live_video_advancing_and_applies_degrade_tier`: with the
  grid settled, three fresh buffer commits advance `frames_rendered` (the video
  keeps playing), the grid still lists the one live surface at its committed
  geometry, and `set degrade-tier reduced|minimal|full` moves the reported grid
  material (blur flag, shadow layers/radius) with the surface staying mapped.
  `parse_grid` now parses the material line.
- Docs — `02-compositor.md` "Live video at scale and the grid material
  (T-05.1b)".

Gotchas for later tasks:

- **The grid material is the degrade seam.** Read it via
  `DfState::overview_grid_material`; do not resolve a second grid shadow/blur
  from `state.degrade` in a T-05 slice. `blur` is the tier's blur state (the
  overview chrome backdrop also reads it), not a per-window texture blur.
- **T-05.2 hit-testing** should use `overview_grid_layout`'s transformed rects
  and must not unmap surfaces: the live-video test asserts the surface stays in
  `query decorations` across commits/tier changes (a thumbnail substitution
  would break it).
- The reusable `SceneTransform`'s `clip`/`blur` attachments are still **not**
  composed onto third-party client surface elements (the renderer has no clip
  element); the grid material stays in the solid-fill pass. The T-04.3 clip
  follow-up remains open.
- Headless never renders, so the tier's effect on the grid is asserted through
  `query grid` (`grid material …`) and `frames_rendered`; the pixel capture is
  T-05.6.

- T-05.2 adds hit-testing.
