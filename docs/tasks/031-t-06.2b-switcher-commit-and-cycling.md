## Goal

Commit the selected app, cycle windows with Cmd+`, and stay interruptible while held.

## Scope

- Commit activates via `activate_app` (cross-Space, restore-if-minimized).
- Cmd+` cycles windows; interruptible while held; cancel on Escape.
- Commit `docs/captures/t06-*`.
