## Live visual check (required)

Before reporting done, run the app and **look at it**:

- Launch the nested session (`make demo`), open the surface this task changed,
  and capture it (e.g. `spectacle -b -n -f -o /tmp/<task>.png`).
- Inspect the image: all UI/UX must be present and read as intended in the
  compositor window — layout, materials, text, and no stray artifacts.
- A green `make e2e` is necessary but **not sufficient**: the headless suites
  render no pixels, so they miss exactly this class of bug. If the task has no
  surface of its own, still launch the demo and confirm the desktop renders.
- Note the capture path and your verdict in the Hand-off.
