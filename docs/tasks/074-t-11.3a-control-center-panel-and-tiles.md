## Goal

The Control Center panel with Wi-Fi, volume, and brightness tiles.

## Scope

- Panel chrome, keyboard shortcut, Escape/click-away dismissal.
- Tiles: Wi-Fi, volume, brightness (compositor-owned), live apply.

## Explicitly deferred

## Reference UI/UX (macOS screenshots)

Near-verbatim target: the real macOS quick-settings sheets — local images in
`docs/reference/macos/` (never shipped; see
[14-risks.md](../design/14-risks.md)); distilled in
[macos-ui-inventory.md](../reference/macos-ui-inventory.md). Only the Wi-Fi
and Bluetooth sheets were captured (`Screenshot 2026-09-18 at 9.23.53 PM.png`,
`Screenshot 2026-09-18 at 9.23.47 PM.png`); the full Control Center panel and
the Focus/dark-mode tiles were not captured — these two sheets are the only
tile references.

Sheet anatomy (both captures): modal sheet, rounded, no title bar; bold title
top-left with an on/off toggle aligned top-right; flat rows separated by thin
dividers; circular icon tiles; a trailing `... Settings...` text link; the
Bluetooth sheet adds frosted-glass vibrancy.

- **Wi-Fi** — `Wi-Fi` toggle (on); `Known Network`: `<network>`, connected
  (blue icon) and secured (lock icon); `Other Networks` (expanded): network
  rows with gray icons and lock icons; `Other...` and `Wi-Fi Settings...`.
- **Bluetooth** — `Bluetooth` toggle (on); connected device rows
  (`WF-1000XM6`, `WH-1000XM6`) with headphone icon tiles, informational only;
  `Bluetooth Settings...`.

The Wi-Fi tile maps to the NetworkManager adapter (T-07) and the Bluetooth
tile to the BlueZ adapter (T-15.1a); each `... Settings...` link opens the
matching pane, and the panel keeps the keyboard shortcut and Escape/click-away
dismissal.

Control-Option-C shortcut, renders Wi-Fi / Sound / Display tiles, and applies

  with a normalized `tiles` model (test seam) and `volumeSetRequested` /
  `brightnessSetRequested` / `muteToggleRequested` / `wifiToggleRequested` /

Capture: `scripts/capture-control-center.sh` (`DF_STATUS_FIXTURE=1`, opens via
Control-Option-C) writes `docs/captures/t11-control-center.png` and

with toggle and `Wi-Fi Settings…`, Sound tile at 60% with Mute, Display tile
with the brightness slider; rounded tiles, no clipping or artifacts.

Deviations / what the next task must know:

- **Wi-Fi radio writes are deferred.** The T-07 NetworkManager adapter exposes
  join but no radio write, so the tile's toggle reflects `radioEnabled` and is
  inert (`wifiWritable=false`; the tile model already carries `enabled`).
  T-15 adds the adapter method and flips the property. This is the one
  non-live core tile.
- **Brightness is compositor-owned but applied best-effort.** The compositor
  stores/clamps the level per output and reports it back; headless/nested do
  not touch hardware and DRM is a later task.
- **`df_output` is v2; the event is `fixed` (24.8)** — compare with
  fixed-point tolerance (~1/256), as the conformance test does.
- **T-11.3b** adds Focus/DND and dark-mode tiles to the same QML module and
  surface; keep the `ON_DEMAND` keyboard and the deferred-dismissal rule (a
  one-turn delay on `keyboardFocused(false)` so bar→panel focus movement is
  not mistaken for a click-away).
- **`Wi-Fi Settings…` logs only** — launching Settings on a pane is T-16.
