## Reference UI/UX (macOS screenshots)

Target: mirror the macOS Privacy & Security pane (`Screenshot 2026-09-18 at
9.21.47 PM.png`) nearly verbatim in style, information architecture, section
order, row labels, control types, and wording. Local art direction only —
images in `docs/reference/macos/` (never shipped; see
[14-risks.md](../design/14-risks.md)); distilled in
[System_Preferences.md](../reference/System_Preferences.md).

Sections and rows (observed order):

- **Privacy**: blue hand icon, title `Privacy`, footer naming data, location,
  camera, and microphone; `Learn more...` link.
- **Location Services** — badge `1`; provider TBD (T-15.x).
- **Calendars** (`1 full access`) — provider TBD (T-15.x).
- **Contacts** (`None`) — provider TBD (T-15.x).
- **Files & Folders** (`18 apps`) — FileChooser portal (T-13.2a/b),
  portal-mediated access with no blanket disk grant.
- **Full Disk Access** (`1 full access`) — provider TBD (T-15.x).
- **Home** (`None`) — provider TBD (T-15.x).
- **Media & Apple Music** (`3 apps`) — provider TBD (T-15.x).
- **Passkeys Access for Web Browsers** (`1 full access`) — host Secret
  Service (reuse-only).
- **Photos** (`3 full access`) — provider TBD (T-15.x).
- **Reminders** (`None`) — provider TBD (T-15.x).
- **Accessibility** — badge `2`; provider TBD (T-15.14 owns the pane).
- **App Management** — badge `3`; provider TBD (T-15.x).
- **Camera** / **Microphone** — named only in the Privacy footer in this
  capture; keep the labels, provider TBD (T-15.x).

Every row is a disclosure row with trailing chevron pushing a per-category
screen of per-app toggles/rows (those screens are not captured). Rows without
a provider stay in the layout as the target UI. Privileged operations go
through polkit with the shell's authentication agent (T-13.6); the pane and
tile report absence as a normal state (T-15.13a).

Adapt or omit (Apple-only): Apple Advertising; Analytics sharing to Apple;
Find My; FileVault; Lockdown Mode (capture ends before the Security section).
