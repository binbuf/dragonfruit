## Hand-off

Landed:

- **Drop-to-trash / Empty Trash through files-core.** Already routed by
  T-10.6a's `TrashBridge`; this task adds Files' own Empty Trash and the
  `trash://` open path.
- **`services/files-core`** — `OptimisticModel::begin_empty_trash` /
  `empty_trash_via` (bulk remove with item-for-item revert) and the C ABI
  `df_files_begin_empty_trash(session)`, valid only on a `trash://` session
  with rows. Mirrored in `apps/files/ffi/files_core.h`.
- **`apps/files`** — `FilesDirectoryModel::emptyTrash()`; FilesShell owns an
  Empty Trash confirmation `Dialog` (background menu + `Shift+Cmd+Delete`).
  `main.cpp` now maps a positional location argument (`trash://`,
  `file:///…`) onto `DF_FILES_START_URI` via the header-only
  `FilesArguments.h`, so the Dock's `openTrashInFiles` launch opens the Trash.
- **Tests** — Rust: `empty_trash_clears_every_row_and_reverts_them_in_order`,
  `confirm_empty_trash_keeps_the_cleared_model`,
  `empty_trash_abi_rejects_a_non_trash_session`. QML: `tst_files_shell`
  `test_trash_location_lists_and_empty_clears_the_model` (trashes real files
  into the temp `XDG_DATA_HOME`, opens `trash://`, empties, asserts the model
  clears). C++: `tst_files_arguments` for the CLI parser.
- **Docs** — `09-files.md` T-10.6b status paragraph.

Deviations / notes:

- T-10.6a had already routed the Dock's drop and Empty Trash through
  `files-core`, so the remaining T-10.6b work was Files' Empty Trash and the
  `trash://` open path; the Dock side needed no change.
- Empty Trash uses one optimistic op (`PendingKind::Empty`) rather than a batch
  of per-node deletes so the pending count and the worker outcome stay paired.
- Files accepts the location as the first URI/absolute-path argument; Qt
  consumes its own `-option value` pairs before `app.arguments()`.

For T-10.6c:

- Skip installing `.desktop`/`Files1` activation here (explicitly deferred);
  `openTrashInFiles` already passes `trash://` and Files now honors it.
- `TrashSource` lists the home store only; per-volume `.Trash-$UID` and
  Put Back remain later work.
