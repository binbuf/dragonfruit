# T179 — T-20.1 Offscreen scene texture + GPU backdrop blur pass

## Goal
The compositor renders the scene into an offscreen GPU texture once per frame and
draws a real, sampled, token-driven blur under each chrome panel, so the menu bar
and the Applications drawer read as frosted glass over live content instead of a
flat feather approximation. This is the first slice of the T-20 material track.

## Scope
- [ ] New `compositor/src/window/blur.rs`: the compiled custom texture shader
      (downsample + Kawase or separable Gaussian), a `BlurSpec`, and a
      `BackdropBlur` value/element type. Keep the spec/geometry pure so it is
      unit-testable headless.
- [ ] `nested.rs` and `drm.rs`: render the scene elements (wallpaper, desktop,
      windows, shadows) into an output-sized offscreen `GlesTexture` once per
      frame, then compose the output from the scene texture + per-panel blurred
      elements + chrome Wayland surfaces.
- [ ] `render::chrome_backdrop_render_elements` resolves each `MaterialRole` to a
      blur spec from the generated material tokens and emits the sampled blur;
      `DegradeTier::Minimal` still emits the existing feather stack (no blur).
- [ ] Preserve the `BackdropPass` contract: one application per `(frame,
      output)`, `backdrop_passes`/`backdrop_skipped` counters, and zero idle
      wakeups (no pass when no chrome is mapped).
- [ ] Menu bar (persistent `Chrome`) and the Applications drawer get the sampled
      blur; the drawer declares its card with a new
      `df_layer_surface.set_panel_rect` call (`ShellProtocol::setAppsDrawerPanelRect`,
      mirroring `setDockPanelRect`).
- [ ] Blur radius comes from the existing `material.{chrome,popup,dock}Blur`
      tokens; no new literal.

## Design notes
- The blur samples the **live** scene texture inside the render pass — never a
  screenshot or screencopy (the no-screencopy gate must stay green).
- Composite the blurred panel with `TextureRenderElement` (or a small custom
  element) and clip it with the shared `CornerMask`, so the rounded edge matches
  the titlebar/shadow/backdrop geometry.
- Downsample the scene region per panel (e.g. half res, token-driven) and
  upsample on compose; map the token blur radius to the Kawase iteration count.
- The scene texture keeps client alpha; the chrome surface's own alpha composites
  over the blurred panel (FR-3 of the track).
- Keep the headless/software path on the deterministic `Minimal` path (no GPU
  readback) so headless tests stay reproducible.
