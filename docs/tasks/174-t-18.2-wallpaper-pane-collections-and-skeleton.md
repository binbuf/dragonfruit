## Goal

The Wallpaper pane shows Featured / Built-in / Custom sources, includes the
shipped original default, fills Featured with fetched pictures, shimmers while
they download, shows attribution and empty/offline/error states, and requests an
eager provider preload while the pane is open.

## Context (read first)

- `apps/settings/WallpaperPane.qml` — the current pane (hero card, two gradient
  collections, portal `Add Photo…`); restructure it into three rows.
- `apps/settings/SettingsBridge.*` — where the provider's `Items`/`Status`/
  `DefaultSource`/`BuiltinDefaultSource` and the `Preload` request reach QML
  (added by T-18.1b, mirroring the existing `wallpaperPresets` /
  `wallpaperChooserAvailable` pattern).
- `assets/graphics/wallpapers/Default.jpg` — the shipped original default; it
  appears in the Built-in row and is the out-of-box background (ADR 0094).
- `design-system/components/` + `design-system/gallery/` + `design-system/tokens/`
  — new UI consumes components/tokens; gallery goldens enforce the visual floor.
- `docs/reference/System_Preferences.md` § Wallpaper — row order and the
  Apple-only rows to adapt or omit.
- ADR [0055](../design/adr/0055-online-wallpaper-content-provider.md) — states
  and attribution; ADR 0094 — the shipped default and the cache policy.

## Scope

- [ ] **Design-system skeleton**: add a `Skeleton` component — a grey slow
      animated gradient (shimmer) with tokens (`skeleton.base`,
      `skeleton.highlight`, duration/easing), a **reduced-motion static
      variant**, and a gallery golden.
- [ ] Restructure the pane into three groups:
      **Featured** (the six Dragonfruit categories from the provider),
      **Built-in** (the shipped `Default.jpg` "Default" tile plus the existing
      original gradients), **Custom** (`Add Photo…` portal; degrade to disabled
      when absent, as today).
- [ ] Featured tiles bind to the provider catalogue via `SettingsBridge`;
      while `Status=fetching` and no items exist, render `Skeleton` rectangles
      (accessible name: "Downloading wallpapers").
- [ ] **Open-pane preload**: when the pane becomes visible/active, ask the
      provider to `Preload` (foreground load). When it is not open, the provider
      stays lazy/background; leaving the pane returns it to idle. The desktop is
      already showing the shipped default, so this never blocks the session.
- [ ] Offline/empty/error states with translated copy: pictures "will be
      available soon"; a cold cache keeps the shipped default and the
      solid-color fallback.
- [ ] Attribution for the current fetched wallpaper: artist, license short
      name linked to `licenseUrl`, and the file page; sanitize the HTML
      `Artist` value (never render raw markup). The shipped/Built-in tiles have
      no third-party attribution.
- [ ] Selecting a tile keeps the existing per-Space / `Show on all Spaces`
      behavior and writes `wallpaper.source`.
- [ ] Accessibility: accessible names include category + title + license;
      keyboard navigation and focus rings on tiles; reduced motion stops the
      shimmer.

## Explicitly deferred

- Video/dynamic wallpapers (post-gate).

## Design notes

- Do not fetch from QML: the pane reads the provider's D-Bus catalogue only.
- Keep `wallpaperChooserAvailable` degradation for the Custom row.
- Skeleton must not animate under `accessibility.reduceMotion`.
- New strings are translatable (`qsTr`) for T-16.7.

## Hand-off

**Landed.** The Wallpaper pane has three rows (Featured / Built-in / Custom).
Featured binds `Settings.providerItems`; while `Status=fetching` with no items it
renders six design-system `Skeleton` rectangles (accessible name "Downloading
wallpapers", static under `Theme.reducedMotion`); a non-empty catalogue renders
tiles whose accessible names carry category + title + license; every other empty
state (absent provider, cold cache, offline, error) shows the translated
"Featured pictures will be available soon." note. Built-in is the shipped
`Default.jpg` "Default" tile plus the six original gradients. Custom is the
unchanged portal row. The pane calls `Settings.preloadWallpapers()` in
`Component.onCompleted` (once per open). The current fetched picture shows
artist (HTML stripped in `SettingsBridge::sanitizeHtmlText`, rendered
`Text.PlainText`), the license short name linked to `licenseUrl`, and the file
page; built-in/user photos show none.

**Test seam.** `DF_WALLPAPER_FIXTURE` (mirrors `DF_SETTINGS_FIXTURE`) makes
`SettingsBridge` serve a deterministic in-process catalogue and exposes
`providerPreloadCount`; `Settings.setWallpaperFixture(status)` seeds
ready/fetching/offline/error. Inert without the env var.

**Tests (all green).**
- `ctest --test-dir build -R "tst_design_system|tst_settings_wallpaper|tst_settings_absence|tst_settings_live" --output-on-failure` — 4/4.
- `make qml-test` — 53/53.
- `./scripts/check-gallery-snapshots.py --strict`; `./scripts/gen-tokens.py --check`;
  `./scripts/check-design-tokens.sh`; `./scripts/check-no-capture-grab.sh` — green.
- `cargo fmt --all -- --check` — green.

**Live visual check (required).** `make t18-wallpaper-capture`
(`scripts/capture-t18-wallpaper.sh`) writes
`docs/captures/t18-wallpaper-fetching.png` and
`docs/captures/t18-wallpaper-filled.png` (both 1920x1200). The fetching still
runs the provider behind a hanging CONNECT proxy so it stays `Status=fetching`.
Verdict: the Featured row renders uniform placeholder rectangles in the fetching
still (pixel probe of the tile band (820,430)-(1280,560): 9 unique colours,
uniform `#f8f6fa`, i.e. the skeleton highlight) and photos in the filled still
(same probe: 1639 unique colours); the filled still additionally selects a cached
picture so the attribution panel is populated. **Caveat:** the environment's
image-analysis tool returned HTTP 429 on every attempt (same as T173), so the
"three headings / no clipping" judgement is from the deterministic pixel probes
and the headless tests, not from a model description; no clipping or stray
artifacts were observed in either still.

**Deviations.** (1) `Selected tile writes wallpaper.source`, per-Space behavior,
and the Custom degradation are unchanged. (2) The provider has no explicit
"return to idle" call, so leaving the pane just stops requesting; the service is
already lazy. (3) Built-in tiles get no attribution by design (ADR 0094).

**Next (T-18.3).** Owns the licensing/absence matrix sign-off and the track
capture/ADR set. Keep `Skeleton`'s plateau gradient (the strict gallery
invariant checks the exact highlight colour) and the `DF_WALLPAPER_FIXTURE`
seam test-only. ADR 0116 records the decisions.
