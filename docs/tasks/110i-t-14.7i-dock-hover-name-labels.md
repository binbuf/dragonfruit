## Goal

Hovering a Dock entry for a moment shows its name (and state), like macOS:
a small glass capsule above the icon. This is both a discoverability feature
and the fix for folder names looking bad inside the artwork.

## Context (read first)

- No `Tooltip` component exists today (`design-system/components/`; the
  gallery lists the component set in `GalleryContent.qml`). `Popover.qml` is
  the closest surface but is focus-taking and arrowed.
- `shell/dock/DockEntry.qml` — `HoverHandler` (`~328-330`) already tracks
  `hovered`; the entry exposes `name`, `kind`, `windowList`, `badge`, and
  `stateLabel` (accessible text, ~104-120).
- `shell/dock/Dock.qml` — the hover handler for magnification
  (`~1671-1705`), popover rect/headroom plumbing (`popoverRect` ~1241-1256;
  `renderDock` computes headroom/gutters), spring-load dwell token
  `springLoadDelay` (500 ms).
- `design-system/tokens/tokens.json` — add a `controls.tooltip` group
  (delay, offset, radius, padding, maxWidth) or reuse `popover`/`contextMenu`
  values; `scripts/gen-tokens.py` regenerates `Theme.qml`.
- Reference: macOS Tahoe's Dock name label (local captures under
  `docs/reference/macos/`, never shipped).
- ADR [0093](../design/adr/0093-tooltip-joins-the-design-system.md).

## Current behavior (investigated, T101 era)

- Hovering a Dock entry only magnifies it; no name appears. A user cannot
  identify an unlabeled icon or distinguish folder entries.
- The folder name is instead drawn inside the folder artwork (T-14.7h removes
  that); the app picker/stack rows have names, the Dock itself does not.

## Scope

- [ ] New `design-system/components/Tooltip.qml`: a pointer-anchored, non-focus
      capsule with a single elided text, an optional arrow-less Tahoe look
      (rounded translucent surface + hairline), `open`, `anchorItem`, `text`,
      `placement` (above/below), `dwell` delay, and open/close motion from the
      tokens. It never takes active focus and never accepts keys.
- [ ] Tokens: a `controls.tooltip` group (dwell ~600 ms, offset, radius,
      padding, maxWidth, font size) in `tokens.json`; no literals in the
      component.
- [ ] Gallery + tests: add a Tooltip page to `GalleryContent.qml`, a
      `tst_design_system.qml` case (open/close, text elision, reduced motion),
      and a golden snapshot pair (light/dark, reduced) so the component is held
      to the same gate as the rest of the library; update the component list
      in `10-design-system.md`.
- [ ] Dock integration: `DockEntry` (or `Dock.qml`) starts a dwell timer on
      hover and shows the Tooltip anchored above the entry (beside it for
      left/right positions), text = name plus state ("3 windows",
      "Trash — empty", folder item counts). Hide on click, drag, popover open,
      and pointer leave; keep visible during magnification; reduced motion
      opens/closes instantly.
- [ ] Placement/rendering: the label is committed through the existing Dock
      overlay/headroom path (`popoverRect` union) so a bottom Dock's label is
      not clipped; clamp to the output; no new surface unless the headroom
      proves insufficient.
- [ ] A11y: the Tooltip is presentational; the entry's accessible name keeps
      carrying the state (already does). Verify no focus change and no key
      capture.
- [ ] Tests: `tst_dock.qml` dwell-appear/leave-hide, state text, popover
      suppression, the folder entry showing its name, reduced motion.
- [ ] Capture `docs/captures/t14-dock-tooltip.png` and the `PROGRESS.md` note.

## Explicitly deferred

- Tooltips on other chrome (menu-bar status items, Control Center tiles):
  the component is reusable; adopting it there is a later sweep (T-16.6).
- Rich/multi-line tooltips; hover previews of window contents.
- Tahoe material/icon language → T-14.7j.

## Design notes

- The component lives in the design system so the gallery gate and tokens
  apply; the Dock consumes it, never rolls its own.
- Dwell uses the motion/token layer; the existing `springLoadDelay` is a
  different interaction (drag spring-load) — use a distinct tooltip delay.
- Never show a tooltip at the same time as a context menu/chooser/stack.
- The label is the folder/app name source approved by ADR 0092; do not
  reintroduce text inside the artwork.
