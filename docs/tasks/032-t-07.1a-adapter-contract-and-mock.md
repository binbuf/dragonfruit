An adapter interface with available/unavailable/error states and a mock implementation for tests.

## Hand-off

**State: done.** The adapter contract and mock landed in a new,
dependency-free library crate, `services/system-adapters`
(`dragonfruit-system-adapters`), which T-07.2–T-07.4 implement and T-07.1b
extends. It defines `Adapter`, `AdapterState<T>` (`Available(T)` /
`Unavailable` / `Error`), `AdapterId` (ids match the shell status-item ids:
`wifi`, `bluetooth`, `volume`, `battery`), `StatusSlot`, and `MockAdapter`.
`AdapterState::slot` / `status_slots` are the consumer projection: unavailable
hides, error shows inert with a message, available shows live. No polling seam
exists on the trait (subscription is T-07.1b). See ADR 0024 and
`docs/design/07-system-integration.md` "The adapter contract (T-07.1a)".

Commands (repo root; `make` sets the toolchain env):

- `cargo test -p dragonfruit-system-adapters` — 8 lib + 2 integration tests
  green (all three states, slot projection, mock transitions).
- `make e2e` — pass (exit 0); `make e2e` now runs
  `cargo test -p dragonfruit-system-adapters` before `make demo`.
- `cargo fmt --all -- --check` and
  `cargo clippy -p dragonfruit-system-adapters --all-targets -- -D warnings`
  clean.
