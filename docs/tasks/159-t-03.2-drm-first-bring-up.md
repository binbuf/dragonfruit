### What landed

- **`compositor/src/drm_bringup.rs`** (new) — the pure
  `DrmBringup::{Ready, Open}` / `DrmBringupBlocker::{NoSeat, NoGpu, NoOutput}`
  classification plus `classify(session, device, outputs)` and a single-line
  `marker()`. Re-exported from `compositor/src/lib.rs`; 5 bin unit tests.
- **`compositor/tests/drm_bringup.rs`** (new, in `make e2e`) — 5 tests pinning
  the open/ready decision and the greppable marker. This is the
  agent-completable half of the acceptance: with no seat the unit is marked
  open.
- **`compositor/src/backend/drm.rs`** — `init` now classifies at three
  checkpoints and prints `DRM bring-up: READY device=<node> outputs=<n>` or
  `DRM bring-up: OPEN (<reason>)`. **Fix:** the backend previously could enter
  the event loop with **zero outputs** (every connector fails when a foreign
  process owns the master) and hang with no display and no diagnosis; it now
  fails with `DRM bring-up failed: no connected output`.
- **`scripts/drm-bringup.sh`** + **`make drm-bringup`** (new) — probes
  `/dev/dri/card*` with `libdrm` (`scripts/drm-seat-probe.py`, new), starts the
  real DRM backend when a card accepts master, and otherwise writes
  `docs/captures/t03-drm-loop.open.txt`. Always exits 0.
- **`docs/captures/t03-drm-loop.open.txt`** (new) — the open record: the
  master probe (`/dev/dri/card0: busy (Permission denied)`), the backend's own
  no-op-seat self-report (`OPEN (no connected output: master busy or all
  connectors disconnected)`), the seat evidence, and the reproduction command.
- **Docs** — ADR
  `docs/design/adr/0170-drm-first-bringup-open-marker-and-no-output-guard.md`
  (new), `docs/design/02-compositor.md` "DRM first bring-up (T-03.2)",
  `docs/captures/README.md` T-03.2 entry.

### Deviations

- The required DRM capture + frame trace (`docs/captures/t03-drm-loop.*`) is
  **not** committed; only the open record is. This is the task's explicit
  no-seat branch, not a silent skip.
- I did **not** run the logind/libseat path: `libseat`'s logind backend calls
  `TakeControl`, which would steal control of the live host session. The
  backend was exercised through `LIBSEAT_BACKEND=noop`, which opens the card
  directly and never acquires master, so the host session is untouched. This
  is how the self-report in the open artifact was produced.
- The interactive T-01 loop capture on DRM (shell + clients + still) is left to
  the T-03.4 runbook, which owns the dedicated-user second-VT/VM workflow.
