**Sections and rows (observed order):** Observed in the Tahoe capture:

- Sidebar: flat icon + label list with no trailing chevrons or badges;
  `Users & Groups` is the selected row (solid accent fill, on-accent text).
- `<user>` (avatar, `Admin`) — grouped-inset user-list row with a circular
  initial avatar and a trailing info (i) button; captured as `Dan` (`Admin`).
  Map to accountsservice.
- `Guest User` (`Off`) — user-list row with a gray silhouette avatar and a
  trailing info (i) button.
- `Add Group...` and `Add User...` — standard rounded buttons below the list.
- `Automatically log in as` — popup, value `Off`, **disabled** (trailing down
  arrow grayed), with the helper text `Automatic login can’t be turned on
  because FileVault is enabled.` (substitute Linux disk encryption).
- `Network account server` — section title with a trailing `Edit...` rounded
  button.
- `?` help — question-mark-in-circle button, bottom-right of the detail pane.
- Header/chrome: centered pane title, back/forward chevron pill (forward dimmed), sidebar `Search` field, trailing `?` help.

**Apple-only (adapt or omit):** Apple Account/iCloud sign-in and Apple ID
buttons (the sidebar account row reads `Apple Account`; the sidebar
`iCloud`/`Internet Accounts` rows also go), FileVault in the auto-login helper
text (map to Linux disk encryption), and Touch ID & Password (sidebar row).

## Hand-off

Landed: the Settings `Users & Groups` pane and the Control Center `Users` tile
as one unit over the T-15.11a adapter, via a new
`org.dragonfruit.SystemStatus1.Accounts` bridge interface
(`services/system-status/src/accounts.rs`) — see ADR
[0139](../design/adr/0139-users-groups-pane-and-tile.md) and the
`docs/PROGRESS.md` "## T132" section for paths and commands.

Deviation from the reference: `Network account server` (and its `Edit…`) is
omitted because there is no enterprise directory provider; the FileVault helper
text is omitted because the adapter reads no disk-encryption state. Both are
recorded in the pane header and the ADR. No settingsd keys; the tile is
read-only.

The Control Center panel now has 14 tiles; every tile's vertical padding moved
from `spacing.xs` to `spacing.xxs` to fit. A 15th tile needs a taller nested
output — a scrolling panel would be unreachable because
`ShellProtocol::onPointerAxis` is a no-op.

Verification: `cargo test -p dragonfruit-system-status`,
`ctest --test-dir build` 65/65, `make e2e` EXIT 0,
`./scripts/check-gallery-snapshots.py` 78 green. Live visual check:
`scripts/capture-t15-users-pane.sh` →
`docs/captures/t15-11b-users-pane.png` and
`docs/captures/t15-11b-users-control-center.png`; vision confirmed both render
correctly with no clipping. Remaining for T-15.12a: none — this task is
complete.
