## Reference UI/UX (macOS screenshots)

Target: mirror the macOS Users & Groups pane (`Screenshot 2026-09-18 at
9.21.51 PM.png`) nearly verbatim in style, information architecture, section
order, row labels, control types, and wording. Local art direction only —
images in `docs/reference/macos/` (never shipped; see
[14-risks.md](../design/14-risks.md)); distilled in
[System_Preferences.md](../reference/System_Preferences.md).

Sections and rows (observed order):

- **User list card** (grouped inset list): each row has a circular avatar, a
  primary name, and a secondary account type, with a trailing info (i) button
  opening the account-detail screen. Captured rows: `<user>` (`Admin`, initial
  avatar) and `Guest User` (`Off`, silhouette avatar). Map the user list,
  avatars, and account type to accountsservice
  ([07-system-integration.md](../design/07-system-integration.md)).
- **Buttons below the list**: `Add Group...` then `Add User...`; standard
  rounded buttons. Account/group management provider TBD (T-15.x).
- **`Automatically log in as`**: popup menu row with trailing chevron, current
  value `Off`, disabled, with helper text (`Automatic login can’t be turned on
  because FileVault is enabled.` — use a Linux disk-encryption substitution).
  Provider TBD (T-15.x).
- **`Network account server`**: section title with right-aligned `Edit...`
  button that likely opens a configuration sheet. Provider TBD (T-15.x).
- **Help**: question-mark-in-circle help button, bottom-right of the detail
  pane.
- **Pane chrome**: title `Users & Groups`, back/forward pill buttons, `Search`
  field; sidebar (~25%) plus detail pane (~75%).

Adapt or omit (Apple-only): Apple Account/iCloud sign-in and Apple ID buttons
(not captured here; sidebar `iCloud`/`Internet Accounts` rows also go), and
Touch ID & Password (sidebar row).
