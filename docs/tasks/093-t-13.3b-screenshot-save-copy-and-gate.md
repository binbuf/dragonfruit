## Hand-off

**Landed.** Capture is now produced by the compositor on the private protocol
and saved/copied by the shell; no client-facing grab path exists and
`make check-no-capture-grab` is green.

- `protocols/dragonfruit-toplevel.xml` — `df_toplevel_manager` v6 adds
  `capture_screenshot(x, y, width, height, mode, path)` and the
  `screenshot_saved(path)` / `screenshot_failed(reason)` events. The manager
  global version (`MANAGER_INTERFACE_VERSION` in `compositor/src/shell/mod.rs`)
  is 6.
- `compositor/src/state.rs` — `PendingCapture` + `DfState::request_capture` /
  `take_capture`; `window_capture_rect` resolves `window` mode under the point.
- `compositor/src/backend/nested.rs` — `capture_frame`/`resolve_capture` render
  the frame's element list into a `GlesTexture`, read it back, crop, and write
  a PNG to the shell's path. It runs *before* the window render so the winit EGL
  surface is restored for the submit. Headless and DRM answer
  `screenshot_failed` explicitly.
- `shell/src/screenshotwriter.{h,cpp}` (new, dockcore) — writes PNGs to
  `Pictures/Screenshots` (`DF_SCREENSHOT_DIR` override) and copies the image +
  saved `file://` URI to the clipboard.
- `shell/src/shellprotocol.{h,cpp}` — `captureScreenshot(...)` request and the
  `screenshotSaved`/`screenshotFailed` signals.
- `shell/src/shellcontroller.{h,cpp}` — `onScreenshotCaptureRequested` unmaps
  the overlay, requests a temp capture, and `onScreenshotSaved` saves, copies,
  and completes a waiting portal request.
- Contract: ADR [0079](../design/adr/0079-screenshot-capture-delivery-and-save-copy.md).

**Deviations / gotchas for T-13.4a:**

- Capture is nested-backend-only. DRM/headless return `screenshot_failed`.
  Coordinates are output-local pixels at scale 1 (no fractional-scale crop).
- The compositor writes a temp PNG the shell loads then removes; the final save
  is the shell's `ScreenshotWriter`.
- The `mode` option (`fullscreen`/`region`/`window`) is a Dragonfruit extension
  carried on the capture request; the portal itself is unchanged.
- The clipboard copy is Qt's (`QGuiApplication`), not yet the Wayland
  data-device; T-13.5 owns the real round-trip and can reuse the writer's copy.
- T-13.4a adds screen casting (ScreenCast portal + source picker) and reuses the
  same shell overlay module.
