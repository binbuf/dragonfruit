## Hand-off

**State: done.** Compositor-death behavior and the restart policy are now one
documented contract with a headless matrix that enforces it. Contract frozen in
[ADR 0158](../design/adr/0158-compositor-death-ends-the-session.md).

What landed:

- `services/session/tests/restart_policy_matrix.rs` (new; 3 tests) — the
  restart-policy matrix. `restart_policy_matrix_matches_the_documented_decisions`
  crosses `always`/`on-failure`/`never` with `exit 0`/non-zero/signal (9 cells);
  `the_compositor_exit_ends_the_session_for_every_exit_kind` crosses compositor
  death with the same three exits and asserts the session ends, survivors stop,
  and the anchor is never restarted;
  `the_shipped_anchor_is_the_compositor_and_is_never_restartable` ties it to
  `SessionPlan::default_session()` and the `validate()` rejection.
- `docs/design/adr/0158-compositor-death-ends-the-session.md` (new) — the
  compositor is the anchor (`Never` + `ends_session`; `Restart=no`), its death
  ends the session for any exit, recovery is a fresh login via the T-12.2
  entry, no live handoff, nested ends only the nested session, lock stays
  fail-secure, and Xwayland subprocess restarts are not session restarts.
- `docs/design/11-session-and-dev-workflow.md` — new
  "Compositor death ends the session (T-16.8b)" subsection with the policy
  table and the verification pointer.
- `docs/captures/t16-kill-matrix.md` — restart-policy matrix section + the
  compositor row now points at the new test and ADR 0158.
- `scripts/t16-kill-matrix.sh` — new section "1b. The restart-policy matrix"
  row; `docs/captures/t16-kill-matrix.txt` regenerated.
- `docs/captures/README.md` updated to list the new row and ADR 0158.
