**Sections and rows (observed order):** Observed in the Tahoe capture:

- Header card — `Accessibility`, person-in-circle icon, and the description
  "Personalize Mac in ways that work best for you with accessibility features
  for vision, hearing, motor, speech, and cognition."; `Learn more...` link.
- Sidebar: flat icon + label list with no trailing chevrons or badges;
  `Accessibility` is the selected row (solid accent fill, on-accent text).
- `Vision` — grouped inset card; every row is a disclosure row with a trailing
  chevron:
  - `VoiceOver` — eye-and-cursor icon.
  - `Zoom` — magnifier icon.
  - `Hover Text` — `i`-and-cursor icon.
  - `Display` — monitor icon.
  - `Motion` — circular-motion icon.
  - `Read & Speak` — speech-bubble icon.
  - `Audio Descriptions` — speech bubble with `A`/`D`.
- `Hearing` — grouped inset card; every row is a disclosure row with a trailing
  chevron:
  - `Hearing Devices` — ear icon.
  - `Audio` — speaker-with-waves icon.
  - `Captions` — speech bubble with `CC`.
  - `Live Captions` — speech bubble with `LIVE`.
  - `Name Recognition` — person-with-sound-waves icon.
- `Motor`, `Speech`, `Cognition` — named only in the header copy; not captured
  (may sit below the fold).
- Header/chrome: centered pane title, back/forward chevron pill (forward dimmed), sidebar `Search` field, trailing `?` help.

**Apple-only (adapt or omit):** VoiceOver maps to the host screen reader over
AT-SPI (drop the Apple brand name); Siri-tied assistive items and the sidebar
`Apple Intelligence & Siri` category are omitted; `Live Captions` and
`Name Recognition` are Apple-only features. The sidebar `Apple Account` account
row (avatar + name + `Apple Account`, captured name `Daniel Gillespie`) maps to
our account row (TBD).

## Hand-off

Landed: the Settings `Accessibility` pane and the Control Center `Accessibility`
tile as one functional unit over the T-15.14a AT-SPI adapter, through the bridge
host (`org.dragonfruit.SystemStatus1.Accessibility`, `State`/`Refresh` only) —
not by linking the Rust crate. ADR [0145](../design/adr/0145-accessibility-pane-and-tile.md).
The pane has a `Vision` card with read-only `Screen Reader` / `Accessibility`
status rows and a `Motion` card with the `Reduce Motion` toggle (the existing
`accessibility.reduceMotion` settingsd key). The tile is a compact read-only
summary (`Screen Reader On` / `On` / `Off`) that opens the pane.

Verification:

- `cargo test -p dragonfruit-system-status -p dragonfruit-accessibility-adapter`
  — green.
- `ctest --test-dir build -j4` — 68/68 (a one-off `tst_dock` flake under `-j4`
  passed on rerun and in `make lint`).
- `make e2e` — EXIT 0 (`/tmp/opencode/e2e-t138.log`); `make lint` fails only on
  the pre-existing `check-desktop-names` lines.
- Live visual check: `bash scripts/capture-t15-accessibility-pane.sh` produced
  `docs/captures/t15-14b-accessibility-pane.png` (2088x1410) and
  `docs/captures/t15-14b-accessibility-control-center.png` (360x1160); vision
  confirmed the pane rows/toggle and the tile with no clipping or artifacts.

Deviations / deferred (recorded so they are not re-litigated): no new settingsd
key (the adapter is read-only; `accessibility.reduceMotion` is the one durable
preference); the Apple-only `Hearing` and `Vision` sub-rows (`Zoom`, `Hover
Text`, `Display`, `Read & Speak`, `Audio Descriptions`, `Live Captions`, `Name
Recognition`) are omitted (ADR 0122); a compositor magnifier and a
display-contrast preference are a follow-up. The menu-bar `accessibility` status
item remains inert — wiring it is a separate surface. The Control Center now
holds 17 tiles (internal gap compacted to `xxs`; content height 1130/1160), so
an 18th tile needs another compaction or a taller nested output.

Next subsystem: T-15.15a Network advanced (VPN) adapter.
