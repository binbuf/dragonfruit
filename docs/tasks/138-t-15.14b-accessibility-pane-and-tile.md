## Reference UI/UX (macOS screenshots)

The reference macOS Accessibility pane is the near-verbatim target: a header
card over grouped inset sections (Vision, Hearing); every row is a disclosure
row — right chevron pushing a detail screen. Local images in
`docs/reference/macos/` (never shipped — see
[14-risks.md](../design/14-risks.md)); distilled in
[System_Preferences.md](../reference/System_Preferences.md). The sidebar is
one continuous category list, no group breaks; Accessibility selected in blue.

**Sections and rows (observed order):**

- Header card — "Accessibility": "Personalize Mac in ways that work best for
  you with accessibility features for vision, hearing, motor, speech, and
  cognition. Learn more..."; person-in-circle icon.
- Vision — inset section card; each row pushes its own detail screen:
  - VoiceOver — screen reader; adapt, see below.
  - Zoom — magnifier: `settingsd` → compositor magnification (T-16.6b).
  - Hover Text — magnified text under the pointer; provider TBD (T-15.x).
  - Display — display-level accessibility; provider TBD (T-15.x).
  - Motion — reduced motion: shell/compositor variants (T-16.6b).
  - Read & Speak — spoken selection; provider TBD (T-15.x).
  - Audio Descriptions — described audio; provider TBD (T-15.x).
- Hearing — inset section card; each row pushes its own detail screen:
  - Hearing Devices — hearing-device pairing; provider TBD (T-15.x).
  - Audio — audio accessibility; provider TBD (T-15.x).
  - Captions — caption preferences; provider TBD (T-15.x).
  - Live Captions — live captioning; provider TBD (T-15.x).
  - Name Recognition — speaker naming; provider TBD (T-15.x).
- Motor, Speech, Cognition — named in the header copy but not captured (may
  sit below the fold): keep the reference IA, providers TBD (T-15.x); our
  pane also carries toolkit/AT-SPI keyboard/assistive settings (T-16.6a),
  which have no captured reference row. The capture shows no toggle rows, so
  subpage toggle anatomy is unconfirmed.

**Adapt or omit (Apple-only):**

- VoiceOver — drop the Apple brand name; adapt to the host screen reader
  over AT-SPI (T-16.6a); provider TBD (T-15.x).
- Siri — no Siri row is captured in this pane; Siri-tied assistive items and
  the sidebar's "Apple Intelligence & Siri" category are omitted.
