## Goal

A subscription API so consumers stop polling.

## Scope

- Subscription for identity/recency/icon changes.

## Explicitly deferred

- None.

## Acceptance (agent-completable)

- [x] Subscribers receive coalesced change signals; no polling remains in consumers.

## Test plan

- Headless: subscribe, mutate, assert a single coalesced signal.

## Hand-off

Landed: the subscription API on `org.dragonfruit.AppIndex1`.

- `services/app-index/src/subscription.rs` (new) — pure `Subscriptions`
  (subscriber table by unique bus name, `Interests` = `identity`/`recency`/
  `icons`, `note`/`due`/`next_deadline_ms`/`flush`, `COALESCE_WINDOW_MS` 100).
- `services/app-index/src/dbus.rs` — `Subscribe`/`Unsubscribe`/`Flush`/
  `SubscriberCount`, the directed coalesced `Changed(interests)` signal, and
  `spawn_coalescer` (condvar-woken; wakes only to its deadline — no polling).
  Every mutation path notes its kind (`Refresh` + watcher → identity/icons;
  window open/close/focus → recency).
- Headless tests (`services/app-index/tests/session_bus.rs`):
  `a_subscriber_receives_one_coalesced_signal_per_burst` (subscribe, install +
  two window opens + focus, `Flush` → exactly one `Changed` carrying
  `identity,recency,icons`, and none after `Unsubscribe`) and
  `the_coalescer_thread_delivers_without_a_flush` (the production thread wakes
  to the deadline and delivers).

Deviations: none from the scope. The shell does **not** subscribe yet;
`AppIndexClient`/`ShellController` still load the index once at startup. That
consumer wiring (plus the still-unwired T-14.1b window-activity forwarder) is
recorded under PROGRESS "Follow-ups". The service-side API already lets the
shell drop its startup `Enumerate` when wired.

Next task: T-14.2 builds on the index (menu-broker). A menu consumer can
`Subscribe("identity")` to stay live; the signal carries the changed kinds, not
a snapshot, so re-read `Enumerate`/`Resolve` as needed.

Capture: the change has no surface of its own (a bus API). Live visual check
performed anyway: `make demo` nested session launched, `/tmp/opencode/t102.png`
captured with `spectacle -b -n -f`; vision verdict — menu bar and Dock render,
no blank screen or stray artifacts. See ADR
[0088](../../design/adr/0088-app-index-subscription-coalescing.md).
