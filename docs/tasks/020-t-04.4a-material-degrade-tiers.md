## Goal

Budget-pressure degrade tiers (smaller radius, then blur off) with instrumentation.

## Scope

- Degrade tiers under budget pressure, instrumented and selectable.
- T-02 transitions render correctly through the degraded pass.

## Explicitly deferred

- Light/dark and reduced-motion variants and the sign-off package (T-04.4b).

## Acceptance (agent-completable)

- [ ] Tiers select under load; transitions stay correct at each tier.

## Test plan

- Headless: forcing a tier changes the pass and keeps frames correct.

## Hand-off

**Landed.** `compositor/src/window/degrade.rs` is the one material-quality
ladder and budget selector: `DegradeTier::{Full,Reduced,Minimal}` maps a
token-resolved `BackdropSpec`/`ShadowSpec` through pure geometry scaling
(`Minimal` = backdrop blur off), and `DegradeController` selects the tier from
rendered-frame durations against a 16 ms budget (env
`DRAGONFRUIT_FRAME_BUDGET_US`) with EMA + hysteresis, and can be pinned. The
render pass applies it in `render.rs`; `session.rs` feeds each frame duration;
`state.rs` exposes `set_degrade_tier`/`set_degrade_budget_us` and prints a
`degrade stats` line; the synthetic harness gained `query degrade`,
`set degrade-tier`, `set degrade-budget`. ADR 0015 is the contract.

**Verification.** `cargo test -p dragonfruit-compositor` green (223 bin unit
tests, window_conformance 23/23); `make e2e`, `make lint`, `make fmt-check`,
`make clippy` green.

**Deviations.** None material. The shadow also degrades (fewer layers / smaller
radius) even though the goal names only "blur off"; this follows the track's
"T-04.4a degrade tiers" requirement and the existing T-04.1a follow-up note.

**For T-04.4b.** Wire the light/dark `ColorScheme` into the degraded passes
(the render still uses `ColorScheme::default()`), and capture schemes +
reduced-motion. `DegradeTier::backdrop`/`shadow` already preserve the spec's
tone, so passing a real scheme through needs no shape change. The reduced-motion
variants are a T-04.4b concern; the degrade tier is orthogonal.

**For T-05.1b/T-05.6.** Read `DfState::degrade.tier()` and route the scene's
material spec through `DegradeTier`; do not add a second ladder.
