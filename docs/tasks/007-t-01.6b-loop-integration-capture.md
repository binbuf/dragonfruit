  is `dock_entry_lifecycle_focus_running_minimize_restore_close` in

- **Code change (capture instrument).** The nested backend now installs the
  T-03 synthetic-input harness when `DRAGONFRUIT_SYNTHETIC_INPUT` is set,
  exactly as the headless backend already did
  (`compositor/src/backend/nested.rs`). Unset in a real session; it exists so
  later track captures can drive the live UI. Documented in
  `docs/design/11-session-and-dev-workflow.md` ("Capturing the walkthrough").

  launches an SSD Wayland app and an X11 app. The CSD case is covered by the
  headless `decoration_tier_matrix…` test in `window_conformance`, not by a
  live still — a CSD client is not in the demo. Also, this slice has no
  motion (T-02), so `t01-loop-v0.mp4` is the ordered walkthrough states, not
  a continuous recording.
- **Run it:** `bash scripts/capture-demo.sh` (needs a host Wayland session,
  Spectacle, ffmpeg, Pillow; not part of `make e2e`).
