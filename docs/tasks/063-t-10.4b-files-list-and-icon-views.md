## Reference UI/UX (macOS screenshots)

From the Finder references (`docs/reference/macos/`, distilled in
[macos-ui-inventory.md](../reference/macos-ui-inventory.md)); the design doc
owns the semantics ([09-files.md](../design/09-files.md#views)):

- **Icon view**: a centered grid of icon tiles (glyph over an up-to-two-line
  label), accent-tinted selection, rubber-band selection, per-folder icon
  size and spacing.
- **List view**: `Name` first, then optional Date Modified / Size / Kind
  columns with sortable headers, inline disclosure triangles for folders,
  full-row selection highlight, inline rename.
- The toolbar's segmented view control is the single switch between the
  shipped views, and the choice persists per location.
