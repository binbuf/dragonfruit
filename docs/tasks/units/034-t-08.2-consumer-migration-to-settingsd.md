## Goal

Move shell, compositor, and design-system consumers onto the daemon and delete the interim file watcher.

## Scope

- Shell drops `DockSettings`/`DockPins`; adopts the existing file shape without migration.
- `Theme.dark`/`Theme.reducedMotion` bound to the daemon; compositor consumes motion policy and input settings.
- Remove the shell's `QFileSystemWatcher` in the same change that lands the daemon (no two writers).

## Explicitly deferred

- Files preferences (owned by Files, T-10).

## Acceptance (agent-completable)

- [ ] A change made anywhere reaches every consumer within one interaction beat; no two writers remain.

## Test plan

- Integration: D-Bus signal fan-out to shell/compositor.
