## Goal

Draw a functional SSD titlebar for Tier-2 windows from design tokens, with no interaction yet, so the decoration exists and its geometry/insets are assertable.

## Scope

- New compositor render element for the SSD titlebar sized from design-system tokens (height, padding, traffic-light size).
- Flat token fill; square corners (materials are T-04).
- Traffic-light close/minimize/zoom glyphs with hover and disabled *drawing*; left-side placement.
- Titlebar sits above the window surface in the element list; client input regions untouched (no behaviour yet).
- Titlebar insets offset the client area through the existing `configure_window_size` path only.

## Explicitly deferred

- Shadows/blur/rounded corners (T-04).
- All titlebar interaction (T-01.2).
- Third-party themes (T-14).

## Acceptance (agent-completable)

- [ ] A mapped Wayland toplevel carries a titlebar element with the expected insets; a CSD client does not.
- [ ] An X11 Tier-2 window carries the same titlebar.
- [ ] Client area is configured below the titlebar.

## Test plan

- Headless: map a Wayland toplevel, assert the titlebar element and insets; assert a CSD client has none.
- Regression: `window_conformance` stays green.

## Hand-off

- T-01.2 wires input into the element.
- T-04 replaces the flat fill with the material pass.
