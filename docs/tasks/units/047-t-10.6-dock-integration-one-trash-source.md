## Goal

Make Dock Trash/Show-in-Files/Downloads share files-core as the single source of truth.

## Scope

- Dock reads Trash state from files-core/GVfs; drop-to-trash and Empty Trash go through it.
- Click opens `trash://`; Show in Files reveals the path; Downloads-stack rows open through Files.
- Delete the Dock's interim home-trash watcher in the same change.
- Install `org.dragonfruit.Files.desktop` identity and register `org.dragonfruit.Files1`.
