## Goal

Make close/minimize/zoom clickable through the titlebar hit-test, wired to the existing window state machine.

## Scope

- Hit-test regions for the three buttons with hover/disabled states.
- close → `df_toplevel.close`; minimize → `minimize_window`; zoom → `zoom`/`unzoom`.
- Titlebar hit-testing integrated into compositor input routing without breaking popups, IME, or client input regions.
- Reduced motion: N/A (no animation) — recorded as such.

## Explicitly deferred

- Drag-to-move and double-click (T-01.3).
- Lifecycle animation (T-02).

## Acceptance (agent-completable)

- [ ] Synthetic pointer clicks drive close/minimize/zoom for a Wayland and an X11 client.
- [ ] No new window state or second owner of truth is introduced.

## Test plan

- Headless: synthetic-input harness clicks each button and asserts the state-machine transition over the protocol.

## Hand-off
