## Goal

A shared animation clock that renders exactly one compositor frame per animation frame and zero damage when idle.

## Scope

- Frame-scheduled clock driven by the calloop loop; one render pass per animation frame.
- Idle assertion: no animation means zero damage and zero client wakeups.
- Reduced-motion flag short-circuits to a single step through the same commit path.

## Explicitly deferred

- The appear transition itself (T-02.1b).

## Acceptance (agent-completable)

- [ ] Instrumented counters show one frame per animation frame and zero idle damage.

## Test plan

- Headless: idle trace stays flat; a dummy animation produces exactly one frame per tick.

## Hand-off

- T-02.1b and all later transitions run on this clock.
