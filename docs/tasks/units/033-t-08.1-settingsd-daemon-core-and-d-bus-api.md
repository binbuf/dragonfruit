## Goal

Land the one owner for desktop settings: configuration model, documented D-Bus API, and durable persistence.

## Scope

- Desktop-settings provider: Dock, workspaces, gestures, appearance dark/light/accent, animation policy, input repeat.
- `org.dragonfruit.Settings1`: named schema-documented keys; get/set; change signals (no polling); additive-only within a release.
- Persistence under `$XDG_CONFIG_HOME/dragonfruit/`: documented format, atomic writes, startup migrations.

## Explicitly deferred

- Host-service provider proxying (T-15/T-16).
- Settings UI (T-09).
