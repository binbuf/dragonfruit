## Goal

Open the window menu (Move to Space, Minimize, Zoom, Close) from a right/Control-click on the titlebar, routed through the existing state machine.

## Scope

- Right/Control-click the titlebar opens the window menu using design-system menu components.
- Move to Space, Minimize, Zoom, Close route through existing state-machine primitives (no new state).
- Escape / click-away / focus-loss dismissal; keyboard operable.

## Explicitly deferred

- Decoration themes (T-14).
- Window-menu animation (T-02).

## Acceptance (agent-completable)

- [ ] All four commands work through the UI on a Wayland and an X11 window.
- [ ] Dismissal matches the design-system menu rules.

## Test plan

- Headless: drive each menu command and assert the transition; nested walkthrough for the visual.
