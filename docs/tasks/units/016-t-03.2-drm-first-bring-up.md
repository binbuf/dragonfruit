## Goal

Run the never-executed DRM backend for the first time and fix what falls out.

## Scope

- LibSeat session, udev hotplug, per-crtc `DrmOutput`, vblank scheduling.
- Direct scanout, hardware cursor plane, single-GPU first.
- Capture `docs/captures/t03-drm-loop.*` and the frame trace.

## Explicitly deferred

- Multi-GPU (T-03.4).
- Suspend/multi-monitor (T-16).
- NVIDIA (post-gate).
