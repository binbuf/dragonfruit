## Goal

Land the adapter contract that all status items use, with a mock and re-subscribe semantics.

## Scope

- available / unavailable / error states; event subscription (no polling above the adapter).
- A mock implementation for tests; re-subscribe on service restart.
- Absent daemon → hidden or explicit 'unavailable', never an error, never a startup blocker.

## Explicitly deferred

- Control Center tiles (T-11).
- Remaining adapters (T-15).

## Acceptance (agent-completable)

- [ ] The contract is unit-tested against a mock; an absent service degrades without blocking session start.
