## Goal

Enforce session lock with a first-party lock UI and host PAM auth — the hard safety gate.

## Scope

- `ext-session-lock-v1` (or the sanctioned path) + first-party lock UI.
- Authentication via PAM through a small helper; never a custom credential store.
- Input capture while locked; kill-resistance: killing the lock UI does not unlock.

## Explicitly deferred

- Fingerprint/other auth methods (T-15).

## Acceptance (agent-completable)

- [ ] Input cannot reach clients while locked; killing the lock UI does not unlock; unlock works.

## Test plan

- Kill tests for the lock UI; nested lock/unlock; DRM repeated on the T-03 rail.
