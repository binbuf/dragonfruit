## Goal

Establish the shared compositor animation clock and the per-window transform, and animate window appear from the owning Dock tile.

## Scope

- One frame of compositor work per animation frame; no animation → zero damage.
- Appear scale/fade from the Dock tile geometry (additive shell→compositor request) or a centered origin when absent.
- Coordinated with the existing launch bounce and xdg-activation.
- Reduced motion: a single step through the same commit path.

## Explicitly deferred

- Blur/shadow (T-04).
- Genie minimize (post-gate).

## Acceptance (agent-completable)

- [ ] Headless clock asserts one frame per animation frame and zero when idle.
- [ ] Appear animation runs; reduced motion is instant but legible.

## Test plan

- Headless: frame-count assertion + idle trace.
- Nested capture.

## Hand-off

- T-02.2 reuses the clock for minimize/restore.
- T-04/T-05 reuse the transform.
