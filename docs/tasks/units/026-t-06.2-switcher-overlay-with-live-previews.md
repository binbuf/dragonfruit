## Goal

Render the switcher overlay with live, scaled app surfaces and commit the selection.

## Scope

- Centered overlay chrome surface with one card per app in recency order, live surfaces scaled via T-04 (never thumbnails).
- App icon/name accessible fallback; keyboard-only, single-hand operation.
- Commit activates via `activate_app` (cross-Space, restore-if-minimized); Cmd+` cycles windows.
- Reduced-motion variant; interruptible while held.

## Explicitly deferred

- Richer app identity from app-index (T-14).
- Multi-monitor edge cases (T-16).

## Acceptance (agent-completable)

- [ ] Cross-Space activation works: activates the Space, restores a minimized window, focuses it.
- [ ] Reduced motion passes; captures committed.

## Test plan
