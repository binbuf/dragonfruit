## Hand-off

**State: done.** Mission Control now transforms the live window surfaces into
the documented grid through the T-04 pass — never a thumbnail.

What landed:

- `compositor/src/overview/grid.rs` (new) — `grid_layout` (ordering by active
  Space/strip/recency, near-square columns, one uniform scale from the largest
  window fitting its cell minus the token margin, centered, non-overlapping),
  `GridCandidate`/`GridPlacement`/`GridLayout`, and `GridPlacement::frame`
  (the `MotionFrame` lerp from committed geometry to cell). 7 unit tests.
- `compositor/src/state.rs` — `overview_grid_progress` (`0` normal → `1` grid,
  reversed while closing), `grid_candidates`, `overview_grid_layout`,
  `overview_grid_frame`, and `window_render_frame` (grid while shown, else the
  lifecycle motion). `compositor/src/render.rs` now draws the client surface,
  SSD titlebar, and shadow through `window_render_frame`, so all three share
  the grid mapping. `compositor/src/window/mod.rs` — `window_by_id`.
- `compositor/src/input/synthetic.rs` — `query grid` (progress + one line per
  placed live surface: source/target/cell). Documented in the wire format.
- `compositor/tests/window_conformance.rs` — new
  `overview_grid_transforms_live_surfaces_into_the_grid`: 3 live surfaces, mid
  gesture the transform interpolates, settled it is one uniform scale in
  centered non-overlapping cells from each committed 200x150 rect, the surfaces
  stay mapped, and a second toggle reverses to no grid.
- Docs — ADR `0017-overview-grid-render-transform.md`;
  `02-compositor.md` "Mission Control live-surface grid (T-05.1a)".

Commands that work (repo root; `make` sets the toolchain env):

- `cargo test -p dragonfruit-compositor` — 231 bin unit tests + all suites
  green (`window_conformance` now 25/25). Direct cargo needs
  `PKG_CONFIG_PATH=~/.local/df-devroot/lib64/pkgconfig` and
  `RUSTFLAGS=-L ~/.local/df-devroot/lib64`.

What the next task must know:

- T-05.1b (live video + degrade): the grid renders through the reusable
  `SceneTransform`/`MotionFrame`, so a client committing fresh buffers keeps
  playing at the scaled target; degrade scales the material geometry only, not
  the grid mapping. Do **not** add a second grid/transform.
- T-05.2 hit-testing: use `DfState::overview_grid_layout` for the transformed
  on-screen rects; the committed geometry is deliberately unchanged by this
  slice.
- Deferred here (belong to later T-05 slices): neighbour-Space reveal
  (`grid_layout` already models `GridCandidate::space_index` but the render
  path only draws `Space`-mapped surfaces), per-output chrome insets, paging at
  the readable floor (`MIN_GRID_SCALE` is exposed but not enforced), and
  attaching the `CornerMask` clip to the live client element wrap (ADR 0014's
  deferred renderer work).
