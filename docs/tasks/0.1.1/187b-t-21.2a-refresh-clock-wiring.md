## Goal

Drive the animation timer and degrade budget from the fastest active output, with a test override and a visible refresh value.

## Context (read first)

- Parent spec: `docs/tasks/0.1.1/reference/187-t-21.2a-per-output-refresh-clock.md`.
- T187a model.
- `compositor/src/animation.rs`, `compositor/src/state.rs`, degrade controller.

## Scope

- [ ] Make `AnimationClock` own the current tick interval from `RefreshSchedule::fastest_period()`; `schedule_animation_timer()` and `poll_animations()` re-arm with it.
- [ ] Recompute on output add/remove, mode change, scale/transform change, hotplug, and resume; cancel/re-arm when the fastest period changes while an animation is live.
- [ ] Set `DegradeController`’s budget from the current deadline; keep `DRAGONFRUIT_FRAME_BUDGET_US` as a diagnostic override and record when active.
- [ ] Add `refresh_hz`/`source=mode|fallback|override` to `presentation stats`; add `DRAGONFRUIT_REFRESH_HZ` for 60/120/144/240 tests.
- [ ] Commit a nested simulated-144 Hz trace under `docs/captures/`.

## Out of scope

- Per-output deadlines and mixed-refresh rendering (T188).
- Per-role/per-output material floors (T189).

## Design notes

- The override must be absent from normal sessions.
- Keep the existing animation durations and design tokens.
- Do not busy-loop a settled output.
