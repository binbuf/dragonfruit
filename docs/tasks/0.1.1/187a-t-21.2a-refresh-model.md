## Goal

Add the pure `OutputRefresh`/`RefreshSchedule` model with fallbacks and tests. No timer or renderer wiring yet.

## Context (read first)

- Parent spec: `docs/tasks/0.1.1/reference/187-t-21.2a-per-output-refresh-clock.md`.
- Compositor state/output mode handling: `compositor/src/state.rs`.
- Animation clock: `compositor/src/animation.rs` (or the current clock module).

## Scope

- [ ] Add `OutputRefresh { refresh_mhz, period, deadline, source, vrr }` and `RefreshSchedule` with `update(output, mode)`, `remove(output)`, `fastest_period()`, `for_output(name)`.
- [ ] Handle no mode/zero/invalid refresh with a 60 Hz fallback and clamp to a sane range (24–500 Hz); keep the exact mode period when valid.
- [ ] Add the `Unknown`/`Off`/`On` VRR state field; no VRR behavior yet.
- [ ] Unit-test 60/120/144/240, add/remove, hotplug, invalid mode, and fastest selection.

## Out of scope

- Clock/timer wiring and degrade budget (T187b).
- Mixed-refresh scheduling (T188).
- Per-role material floors (T189).

## Design notes

- Pure module; no renderer dependency.
- Keep animation progress on monotonic elapsed time.
- Do not replace 16 ms with a global 8 ms constant.
