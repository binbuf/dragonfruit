## Goal

## Context (read first)

## Scope

- [x] Handle no mode/zero/invalid refresh with a 60 Hz fallback and clamp to a sane range (24–500 Hz); keep the exact mode period when valid.

## Hand-off

### Landed

- New pure library module `compositor/src/refresh.rs`, exported as
  `dragonfruit_compositor::refresh` from `compositor/src/lib.rs`.
- `OutputRefresh { refresh_mhz, period, deadline, source, vrr }` and
  `RefreshSchedule` with `update(output, Option<ModeRefresh>)`, `remove`,
  `clear`, `fastest_period`, `for_output`, `iter`, `len`, `is_empty`.
- Supporting types: `ModeRefresh`, `RefreshSource` (`Mode`/`Fallback`/
  `Override`, with stable `as_str()` stats tokens), and `VrrState`
  (`Unknown`/`Off`/`On`).
- Policy: no mode or `refresh_mhz <= 0` → 60 Hz `source=fallback`; positive
  modes clamp to 24–500 Hz and otherwise keep the exact millihertz period
  (`source=mode`). `deadline == period` today. VRR is stored only.
- Nine unit tests: 60/120/144/240 table, real 143.999 Hz panel, invalid/zero/
  negative fallback, low/high clamp, mode replacement, add/remove/hotplug,
  fastest selection, VRR carriage, and source tokens.
- ADR 0198 and an animation-clock note in `docs/design/02-compositor.md`.
- Progress notes in `docs/v0.1.1/progress/T187a.md`.

### Refresh table

| Mode | Period | Deadline |
|---|---:|---:|
| 60,000 mHz | 16,666,666 ns (16.667 ms) | same |
| 120,000 mHz | 8,333,333 ns (8.333 ms) | same |
| 144,000 mHz | 6,944,444 ns (6.944 ms) | same |
| 240,000 mHz | 4,166,666 ns (4.167 ms) | same |
| 143,999 mHz (real panel) | 6,944,492 ns (6.944 ms) | same |

An empty schedule and any output with no mode report the 60 Hz fallback
(16,666,666 ns). `fastest_period()` is the minimum active period, or that
fallback when empty.

### Deviations

- The parent reference says `1e9 / refresh_mhz` nanoseconds. With Smithay's
  millihertz unit that is a factor-of-1000 typo; the model uses
  `1e12 / refresh_mhz` ns (equivalently `1_000.0 / refresh_mhz` seconds).
  The 60/120/144/240 table above is the cross-check.
- Clock/timer wiring, `DRAGONFRUIT_REFRESH_HZ`, degrade-budget updates, and
  `presentation stats` are deliberately left to T187b (out of scope here).
- No VRR behavior was added; the field exists for T188.
