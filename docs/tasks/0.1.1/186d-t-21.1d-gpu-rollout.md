# T186d — T-21.1d GPU transport: rollout, stats, and docs

## Goal

Move every chrome surface to the GPU producer behind the flag, make the stats/docs honest, and keep the SHM path as the fallback contract.

## Context (read first)

- Parent spec: `docs/tasks/0.1.1/reference/186-t-21.1d-gpu-backed-chrome-transport.md`.
- T186b Dock dmabuf path.
- T185 `ChromeFrameProducer` and `chrome stats`.

## Scope

- [ ] Roll the GPU producer out to the menu bar, popovers, overlays, lock surface, and remaining chrome; name any surface that cannot move and keep it on SHM.
- [ ] Report `path=dmabuf|shm`, buffer counts, copies, and failure reasons in `chrome stats`; a GPU frame must have no CPU readback/copy.
- [ ] Update the transport ADR, `docs/rendering.md` R2.3, `04-shell.md` known limits, and `docs/captures/README.md`.
- [ ] Capture nested GL stills/stats for Dock, menu bar, popover, and lock, plus a forced-SHM fallback run; keep the default off until T192/T193 accept it.

## Out of scope

- Native material acceptance (T191).
- Benchmark/soak (T192).
- Default-on switch.

## Design notes

- One producer abstraction, one fallback contract.
- Never silently double-render a surface that cannot use the GPU path.
- Do not change chrome visuals or layout.

## Done when

- [ ] `make e2e` and `make qml-test` pass.
- [ ] Every surface is covered or named as a measured exception.
- [ ] GPU/fallback captures and stats are committed; docs updated.
- [ ] Hand-off filled in.
