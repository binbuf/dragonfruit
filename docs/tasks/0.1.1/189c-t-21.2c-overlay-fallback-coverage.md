## Goal

Extend the per-role material application to the popup-family surfaces and prove every blur-assuming surface has a deliberate fallback.

## Context (read first)

- Parent spec: `docs/tasks/0.1.1/reference/189-t-21.2c-persistent-chrome-material-floor.md`.

## Scope

- [ ] Apply the role-keyed state to Dock/menu popovers, Control Center, notifications, OSD, and Applications drawer; transient roles may reach `Minimal`.
- [ ] Give every blur-assuming popup/overlay a deliberate milky fallback and a recorded fallback reason; do not leave a flat translucent slab.
- [ ] Add/extend QML tests for the overlay family and commit forced Full/Reduced/Minimal captures in light and dark.

- The software path stays deterministic.
