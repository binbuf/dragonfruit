## Goal

Replace the global `needs_redraw` animation gate with per-output requests and earliest-deadline timer arming.

## Context (read first)

- Parent spec: `docs/tasks/0.1.1/reference/188-t-21.2b-presentation-paced-mixed-refresh.md`.
- T188a presentation clock.
- Compositor event loop/render gate.

## Scope

- [ ] Separate urgent requests (input, client/chrome commit, resize) from animation requests; render an output when its own deadline is due.
- [ ] A global scene change may mark all outputs urgent, but a 144 Hz tick must not force a 60 Hz output to present every 6.94 ms.
- [ ] Arm the animation timer from the earliest due deadline; update the output clock after presentation and re-arm; never render a settled output.
- [ ] In `frame_finish()`, update the clock and count a missed deadline at 1.5× the output period; include `refresh_hz` in the summary.
- [ ] Add a pure scheduler test and a nested single-output trace.

## Out of scope

- VRR, chrome callbacks, and mixed 60+144 evidence (T188c).
- Material floor (T189).

## Design notes

- Urgent work must not wait for a deadline.
- Keep the existing missed-deadline rule.
- No busy-loop and no 16 ms global fallback.
