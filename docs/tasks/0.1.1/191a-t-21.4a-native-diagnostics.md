### Deviation and why

- The rollback's native fallback **render** is OPEN: the compositor is the
  session anchor, so applying `DRAGONFRUIT_DRM_MATERIAL=0` for real requires
  ending the live session and logging back in. The agent cannot complete the
  password login, and ending the session would destroy the native capture.
  This is the same boundary T183/T188c recorded for native-only scenario runs.
  The config apply/restore half was exercised and the default is restored.
- `chrome stats` reports the default SHM path, not dmabuf; that is expected
  (T186d keeps the GPU transport opt-in).
