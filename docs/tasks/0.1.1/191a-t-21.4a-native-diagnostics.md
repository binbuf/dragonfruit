## Goal

Rebuild/install the release profile, capture the native material diagnostics, and record the rollback. This is the functional evidence half of the native acceptance.

## Context (read first)

- Parent spec: `docs/tasks/0.1.1/reference/191-t-21.4a-native-material-acceptance.md`.
- `make native-rebuild`, `make native-capture`, `docs/runbook-drm-session.md`.
- T183/T185/T186 chrome stats and T187/T188 presentation stats.

## Scope

- [ ] `make native-rebuild` with no material env flags; confirm the installed/running binaries are release, not debug.
- [ ] `make native-capture`; record `material stats` (path=gpu, blur_passes>0, blur_panels>=1, blur_draws>0, backdrop_skipped=0), `degrade stats` (full/reduced at idle), `presentation stats` (output/mode/refresh_hz/budget/missed), and `chrome stats` (path/copies/callbacks).
- [ ] Run the rollback once: `DRAGONFRUIT_DRM_MATERIAL=0 make native-rebuild`; record it and restore the default.
- [ ] Commit the diagnostics under `docs/captures/t21-native-material.*`; update docs/STATUS G-03/G-08.

## Out of scope

- The native visual sweep and evidence boundary (T191b).
- Benchmark/soak (T192).
- New material design.

## Design notes

- Never label a nested screenshot as native proof.
- Record exactly which values are diagnostics vs visual evidence.
- The rollback must leave the default restored.

## Done when

- [ ] `make e2e` passes on the build tree.
- [ ] The native capture is committed and the required lines are present.
- [ ] The rollback is recorded and the default restored.
- [ ] Hand-off filled in.
