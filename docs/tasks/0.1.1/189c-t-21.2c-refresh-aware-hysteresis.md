## Goal

Make the 12/180 hysteresis refresh-aware so it does not flap or recover too quickly at 120/144 Hz.

## Context (read first)

- Parent spec: `docs/tasks/0.1.1/reference/189-t-21.2c-persistent-chrome-material-floor.md`.
- T189b per-role shell application.
- Degrade controller hysteresis.

## Scope

- [ ] Replace fixed frame counts with time windows or period-scaled counts; keep 12/180 at 60 Hz as the reference.
- [ ] Prevent Full↔Reduced oscillation during a steady pointer sweep.
- [ ] Add forced-tier/load tests that pin Full, Reduced, and Minimal and verify the effective per-role state and shell properties.
- [ ] Commit a load trace and docs/ADR updates.

## Out of scope

- Panel-region material cost (T190).
- New material design or tokens.

## Design notes

- Refresh-aware, not refresh-locked: the same wall-clock behavior at every rate.
- Do not change the fallback ladder.
- Keep change-only emission.
