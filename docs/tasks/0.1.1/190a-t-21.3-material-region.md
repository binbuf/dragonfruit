## Goal

Add the pure union/padding/clamp helper for the material panel region, with tests. No renderer changes.

## Context (read first)

- Parent spec: `docs/tasks/0.1.1/reference/190-t-21.3-panel-region-material-and-scanout.md`.
- Blur panel spec and output geometry in the compositor renderer.

## Scope

- [x] Compute the union of every `BlurPanel.panel` on an output, expand by the blur spec’s padding (radius/iteration-derived), clamp to the output rect, and return the region rect and texture size.
- [x] Unit-test empty, single-panel, multi-panel, clipped-at-edge, and scale/rounding cases.

## Out of scope

- Region-sized rendering and stable IDs (T190b).
- Direct scanout and counters (T190c).

## Design notes

- No literal padding constants; derive from the blur spec.
- Keep output coordinates explicit.
- Pure helper, no renderer dependency.

## Done when

## Hand-off

### What landed

- `compositor/src/window/material_region.rs` (new, pure geometry):
  `MaterialRegion { rect, physical, texture_size }` and
  `MaterialRegion::from_panels(&[BlurPanel], output_local_rect, scale)`.
  Each panel is expanded by **its own** `BlurSpec::padding_px()` before the
  union; the union is clamped to the output. `physical` is
  `rect.to_physical_precise_round(scale)` clamped again to the physical output
  rect (independent location/size rounding can overflow one pixel at
  fractional scales), and `texture_size` is `physical.size`. Empty,
  degenerate, fully-outside, zero-output, and invalid-scale inputs return
  `None`.
- `compositor/src/window/blur.rs`: `BlurSpec::padding()` is
  `max(token radius, 2^iterations)` — the requested blur reach and the Kawase
  chain footprint, with no literal padding constant. `padding_px()` rounds up
  to whole logical pixels. Exported as `crate::window::MaterialRegion`.
- Tests cover empty/degenerate, single panel, multi-panel with different
  per-panel paddings (and order independence), every output edge plus a
  fully-outside panel, and 1x/1.5x/2x physical rounding including the
  right/bottom clamp. A `BlurSpec` test pins the padding formula and the
  fractional round-up.
- Docs: ADR `0207-material-region-padded-union.md`, `rendering.md` R1.1,
  `02-compositor.md` material note, `docs/v0.1.1/progress/T190a.md`.

### Deviations

- No renderer change, as scoped: `chrome_blur_panels()` still uses the old
  full-output scene path and its unpadded union for the material pass. T190b
  wires `MaterialRegion` into the nested/DRM scene render and translates panel
  `src` by `physical.loc`.
- The formula is `max(radius, 2^iterations)`, not `radius + padding`. It covers
  both the token soft reach and the chain's discrete footprint without
  over-padding by a whole extra radius; the current tokens therefore pad by
  their token radius (24 chrome/dock, 12 popup).
- The helper is normal-transform only, matching the current material pass;
  rotated-output material remains the T193 fallback.

`space.output_geometry()` origin is global; use its size or subtract the
