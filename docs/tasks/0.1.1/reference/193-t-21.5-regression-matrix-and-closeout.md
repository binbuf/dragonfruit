## Design notes

- The matrix is an evidence index, not a prose summary. Each row links to the
  test name, capture path, or native artifact that proves it.
- Distinguish **agent-verified**, **hardware-verified**, and **human-signed-
  off** rows. A green `make e2e` is not hardware or product sign-off.
- If a row is open, say why and what command would close it. "Not tested" is
  not an acceptable final state; "OPEN: no 240 Hz panel" is.
- Documentation is part of the release: if a design doc still says the shell
  uses `grabWindow()`/`wl_shm` without qualification after T185/T186, fix it
  in this task.
- Keep the no-screencopy rule intact. Native evidence must come from the
  trusted capture path or external photographs, not a new client grab.
