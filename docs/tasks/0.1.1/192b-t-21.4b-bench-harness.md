**Deviation/follow-up.** The default full GPU rail
(`CHROME_GPU_SURFACES=all`) segfaults the shell during Mission Control:
`QQuickRenderTarget::operator=` -> `QQuickWindow::setRenderTarget` ->
`GpuChromeFrameProducer::destroySlotResources` during `releaseGpu`, preceded
by null `Shadow.qml` overview material warnings. This is a real
shell/GPU-overview regression, not a benchmark-script bug; T192b does not fix
regressions. The benchmark excludes the `overview` surface from the GPU rail
so the rest of the set completes, which is why the overview row is shm. File
it for T193; reproduce with `CHROME_GPU_SURFACES=all make
t21-presentation-bench`.
