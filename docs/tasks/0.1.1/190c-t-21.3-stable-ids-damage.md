## Hand-off

### Landed

- Stable panel identity and cache lifetime:
  - `compositor/src/window/material_cache.rs` adds `PanelKey` (hash of the
    chrome surface namespace, layer, and Wayland object id; geometry
    excluded). `PanelTextureSlots` is keyed by it, and each
    `PanelTextureSlot` owns one stable `Id` plus the panel's Kawase textures.
    `trim_to(&keys)` drops a disappeared panel's slot, id, and `GlesTexture`
    handles; a move, reorder, or popover opening keeps them.
  - `compositor/src/render.rs` carries the key on `BlurPanel`;
    `chrome_blur_panels` builds it from the `ChromeSurface`.
- Stable scene identity and damage:
  - `SceneTextureCache` owns one scene `Id` per output and a `CommitCounter`
    advanced only when the offscreen scene's persistent `OutputDamageTracker`
    reports damage. `install` resets the tracker; the tracker is reused while
    the region key (size/output/scale) is unchanged and reset on a change.
  - `render_scene_offscreen` now calls the tracker with age 1: first frame /
    reallocation / region change renders the whole region, an unchanged scene
    renders nothing and leaves the scene commit flat.
  - `BackdropBlurElement::with_id`/`with_commit` and
    `SceneTextureElement::with_identity` carry the cached identity into the
    draw list. Panel commits stay at the default; the full-output diagnostic
    scene base uses the scene commit.
- Capture/evidence:
  - `scripts/t21-live-capture.sh` gained a `settled` state (no synthetic
    pointer motion).
  - `scripts/t21-stable-damage.sh` / `make t21-stable-damage` runs the damage
    unit test, `make t21-doctor`, and one settled 1x capture.
  - Committed artifacts: `docs/captures/t21-stable-dock-1x.png` (1920x1200),
    `docs/captures/t21-stable-damage.txt`, and the manual full-output
    diagnostic still `docs/captures/t21-stable-full-1x.png` (same `settled`
    state with `DRAGONFRUIT_MATERIAL_FULL_OUTPUT=1`).
- Docs: ADR `0209-stable-panel-keys-and-scene-commits.md`,
  `docs/rendering.md` R1.2/R1.3, `docs/design/02-compositor.md`,
  `docs/captures/README.md`.

### Deviations / notes

- The damage unit test drives a real Smithay `OutputDamageTracker` with a
  `TestElement` that uses the panel cache's actual id. It pins: first frame
  damages, settled frame returns no damage, a wallpaper commit damages the
  full output, and a Dock move damages only the old/new panel rects. The
  actual `BackdropBlurElement` cannot be constructed headless because it owns
  a `GlesTexture`; the id/commit fields it uses are the same ones tested.
- Panel element commits intentionally remain `CommitCounter::default()`. The
  live scene elements carry scene damage; bumping a panel commit on every
  scene change would repaint the panel even when its pixels did not change.
- The scene tracker relies on the full-output wallpaper element to turn an
  origin-only region move into full-region damage. The current scene always
  has that base; revisit if the base shape changes.
- The committed settled capture reports `material_allocations=10` (scene 2,
  panel 8) flat across the two snapshots and `material_region=1920x1200`.
  The region is full output because the menu bar and Dock both blur; that is
  the T190b single-union shape, not a regression in this task.
- The nested host can report `buffer_age=0` when it has no damage tracking;
  Smithay then forces full damage for correctness regardless of stable ids.
  The host used for the capture reports damage ages.
- `make gates` was run once on the final code tree. Only docs/hand-off edits
  followed.
