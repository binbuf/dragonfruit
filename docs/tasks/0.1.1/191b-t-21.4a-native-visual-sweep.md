## Hand-off

**Landed.** 23 native stills in `docs/captures/t21-native-*.png`, read from the
real DP-1 KMS scanout buffer (3840x2160 @ 143.999 Hz, scale 2 → 2560x1440
logical, amdgpu Lucienne) with a development-only `pidfd_getfd` + dma-buf/EGL
readback. The set covers light/dark desktop, Dock/menu bar over live content,
menu dropdown, Applications drawer, Control Center, OSD, notification banner,
Dock window chooser, Dock magnification, Mission Control (12-window grid plus
the 09:xx two-window re-entry), lock, fullscreen, and the minimized Dock.

**Live sampling.** An override-redirect white X11 panel was moved behind the
chrome while the wallpaper/scheme stayed fixed. Mean chrome luminance changed
as follows: light menu bar 226.3 → 245.5 (the light glass is already bright);
light Dock 68.7 → 183.5; dark menu bar 55.0 → 113.2; dark Dock 45.4 → 161.6.
A managed window is clamped below the reserved menu-bar zone by the XWM, so
the probe has to be override-redirect; the panel is a real client surface in
the compositor scene.

**Deviations / limits.** The readback is primary-plane only: the hardware
cursor and overlay planes are not in the stills, and `direct_scanouts=0`
(47 candidates) means the fullscreen still is not direct-scanout proof. The
rollback render stays the T191a OPEN artifact (needs a session cycle). HiDPI
is evidenced at 2x only; 1x/1.5x native modes remain T193. The Mission Control
grid still was captured at 07:56 during the same native session, before the
provider interruption; the later sweep re-entered Mission Control with two
windows. `DF_MISSION_CONTROL_FIXTURE` was added as a test-only capture seam
(inert unless set).

**Numbers (fresh `make native-capture`, SIGUSR1-23).** `material stats`
`path=gpu blur_passes=433308 blur_panels=875071 blur_draws=433308
backdrop_skipped=0 material_region=3840x2160`; `degrade stats` current
`tier=reduced` (not minimal), `forced=0`, `budget_us=6944`; `chrome stats`
`chrome_shm_imports=4028 chrome_dmabuf_imports=0
chrome_frame_callbacks=3532`; `scanout stats` `direct_scanouts=0
