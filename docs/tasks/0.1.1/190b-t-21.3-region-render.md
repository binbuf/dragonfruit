## Goal

Render the scene into a region-sized or damaged cached texture and reallocate only on region/mode/scale change. Stable IDs and damage are T190c.

## Context (read first)

- Parent spec: `docs/tasks/0.1.1/reference/190-t-21.3-panel-region-material-and-scanout.md`.
- T190a region helper.
- `blur_panel_texture()`, `SceneTextureElement`, and the scene/panel caches.

## Scope

- [x] Render into a region-sized texture or update a cached full scene only in damaged regions; keep output-coordinate `src` mapping and translate the region origin correctly.
- [x] Reallocate only on region size or output mode/scale change; one cache per output (and per GPU where required).
- [x] Check `MultiFrame` synchronization and `GlesTexture` lifetimes under panel add/remove; commit a nested 1x/1.5x/2x capture and region/caching unit tests.

## Out of scope

- Stable IDs and damage (T190c).
- Direct scanout policy and counters (T190d).
- New material design.
- Refresh scheduling.

## Design notes

- Capture preflight: run `make t21-doctor` before a host/nested run; reuse `scripts/t21-capture-lib.sh` and the existing capture script. Record the exact command and artifact path.
- Keep the full-output path available as a diagnostic/rollback switch.
- Do not change the visual result at the panel.
- No per-frame allocation.

## Done when

## Hand-off

### Landed

- Region-sized scene render in both backends:
  - `MaterialRegion::full_output`, `for_material`, and `panel_source` in
    `compositor/src/window/material_region.rs`.
  - `compositor/src/window/material_cache.rs` with the grow-only
    `SceneTextureCache` (keyed by allocated size/output mode/scale, not the
    region origin) and `PanelTextureSlots` (trimmed when a panel disappears).
  - Nested and DRM allocate at `region.texture_size`, relocate elements by
    `-region.physical.loc`, and translate each panel's `src` via
    `MaterialRegion::panel_source`.
  - `BackdropBlurElement::with_texture_panel` clips a region-clipped panel
    without inventing a rounded corner.
- Composition shape: the live scene elements are the output base and the
  region texture is only the blur source, so the output is not empty and the
  windows are not painted twice. `DRAGONFRUIT_MATERIAL_FULL_OUTPUT=1` restores
  the old full-output scene-texture base as the diagnostic/rollback path.
- Visual equivalence: the Kawase chain's first destination stays the full
  output's physical size, so the panel blur is unchanged from the pre-region
  path.
- Counters: `material stats` reports `material_allocations`,
  `material_scene_allocations`, `material_panel_allocations`,
  `material_region_px`, and `material_region=WxH`.
- Capture/evidence:
  - `scripts/t21-region-render.sh` / `make t21-region-render` (reuses
    `scripts/t21-live-capture.sh`; the latter gained `SCALE`, `FULL_SESSION`,
    `FORCE_TIER`, `OUT`, and `DUMP_COMPOSITOR_STATS`).
  - `docs/captures/t21-region-motion-{1x,1_5x,2x}.png`,
    `t21-region-menu-1_5x.png`, `t21-region-motion-1x-full.png`, and
    `t21-region-render.txt`.
- Docs: ADR `0208-region-scene-texture-and-grow-only-cache.md`,
  `docs/rendering.md` R1.1/R1.3, `docs/design/02-compositor.md`,
  `docs/captures/README.md`.

### Deviations / notes

- The single padded-union rectangle can equal the full output when the top
  menu bar and bottom Dock both blur. The region path is still active and
  cached; a Dock-only frame is smaller (a transient smoke frame reported
  672x120 = 80640 px). Multi-rect/tiled regions are a follow-up for T190c/T192,
  not a correctness issue.
- The nested window size follows the host (1920x1200, 1280x800, and 1281x801
  were observed), so the transcript records the actual `material_region`
  rather than assuming a fixed output size.
- The 1.5x motion run allocated three panel-slot textures between the two
  snapshots; the scene allocation count stayed flat. Panel add/remove is the
  remaining allocation source until T190c gives panels stable identities.
- The capture reuses the existing `scripts/t21-live-capture.sh` (which owns the
  `make demo`/`make dev-full` lifecycle and cleanup); `scripts/t21-capture-lib.sh`
  was not sourced because it is for scripts that start the compositor/shell
  directly.
- `make gates` was run once on the final code tree. Only docs/hand-off edits
  followed.
