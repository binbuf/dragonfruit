## Hand-off

Landed the T192a counters; the benchmark script and scenario run remain T192b.

- **GPU timing.** `compositor/src/gpu_timer.rs` adds opt-in
  `DRAGONFRUIT_GPU_TIMING=1` asynchronous `GL_TIME_ELAPSED` queries around the
  offscreen scene, each panel's blur chain, and the final composite. `gpu stats`
  reports `enabled/available/gpu_time/reason` and per-pass
  `samples/total/p50_us/p95_us/p99_us/max_us`. Glass runs inside the composite
  pass, so it has no separate category. Unsupported, disabled, or headless
  reports `gpu_time=unavailable` with the reason; nothing is derived from CPU
  time.
- **Nested surface restore.** Timer queries call `eglMakeCurrent(NO_SURFACE)`;
  the winit backend expects its window surface to stay current. `with_gl`
  captures the live `eglGetCurrentSurface(EGL_DRAW)` before the query and
  restores it afterwards. Without that restore the next submit failed with a
  lost context during this task's development. Reading the live surface each
  time also survives a resize that recreates the winit surface.
- **Chrome counters.** `path`, `commit_us`, `frame_callback_us`, `shm_bytes`,
  `dmabuf_buffers`, `dmabuf_fallbacks`, and `dmabuf_sync_timeouts` were already
  present from T183–T186. Added an explicit `copies` count (commits with
  `copy_bytes > 0`) to the global and per-surface lines; `summaryLines()` makes
  the contract testable.
- **Tests.** Four `gpu_timer` unit tests plus `tst_chromestats` cover the
  unavailable/available paths, percentiles, the bounded window, and every
  chrome transport field.
- **Commands/results.** `make t21-doctor` PASS (0 warnings);
  `cargo test -p dragonfruit-compositor` PASS (bin 375);
  `cargo clippy -p dragonfruit-compositor --all-targets -- -D warnings` PASS;
  `make qml-test` PASS 83/83; `make e2e` PASS. A short nested 144 Hz run with
  `DRAGONFRUIT_GPU_TIMING=1` produced `gpu_time=available`,
  `composite_samples=163`, p50/p95/p99 = 0/201/277 us and a clean exit. No
  mapped chrome panel meant scene/blur samples stayed 0 in that run.
- **Next.** T192b should warm up before recording and parse these fields. The
  DRM timer path is wired but still needs a free native seat in T192c; the
  headless e2e line correctly reports `gpu_time=unavailable reason=disabled`.
