## Hand-off

Landed: the service-owned Focus/DND policy. Frozen semantics in
[adr/0058](../../design/adr/0058-focus-dnd-policy-semantics.md); the rules are
`off` = all banner, `focus` = allow-list + `critical`, `dnd` = allow-list only
(everything else, including `critical`, batched). A suppressed notification is
recorded in history with `suppressed: true` and counted in the policy batch,
which clears when the mode returns to `off`.

Files:

- `services/notifications/src/policy.rs` (new) — `FocusMode`, `FocusPolicy`
  (`admits`, `set_allow_list`, `note_batched`, `batched_count`), 6 unit tests.
- `services/notifications/src/model.rs` — `Queue` owns a `FocusPolicy` (the
  old `do_not_disturb` bool is gone); `HistoryEntry.suppressed`;
  `focus_policy`/`focus_mode`/`set_focus_mode`/`set_focus_allow_list` plus the
  compat `do_not_disturb`/`set_do_not_disturb` pair.
- `services/notifications/src/view.rs` — `history_json` gains `suppressed`;
  new `focus_policy_json` (`mode`, `allowList`, `batchedCount`).
- `services/notifications/src/dbus.rs` — `org.dragonfruit.Notifications1`
  adds `FocusPolicy()`, `SetFocusMode(name) -> bool` (unknown rejected),
  `SetFocusAllowList(apps)`; both setters emit `Changed`. `DoNotDisturb` /
  `SetDoNotDisturb` remain as the T-11.1a compat mapping.
- `services/notifications/src/main.rs` — `--print-capabilities` now lists
  `actions` (it had drifted from `CAPABILITIES`).
- Tests: `services/notifications/tests/session_bus.rs` gains
  `focus_mode_suppresses_batches_and_lets_critical_and_allowed_apps_through`,
  `dnd_silences_critical_but_honors_the_per_app_override`, and
  `an_unknown_focus_mode_is_rejected_and_the_compat_dnd_pair_maps`.

Deviations: none from the task scope. The task's "Area" mentions `shell/`, but
the bar reflection is explicitly T-11.2b; no shell source changed (the existing
`setDoNotDisturb` client call still hits the compat method). Scheduling Focus
windows and per-app *silencing* were not built (not required; the policy is
additive).

Next (T-11.2b): read `FocusPolicy()` from the shell to reflect mode +
`batchedCount` in the menu bar; the `Changed` signal drives the re-read. The
D-Bus method names and the JSON keys above are the frozen contract.
