Deviations / decisions:

- There is **no stable D-Bus volume API** and the pinned toolchain lacks
  `libpipewire` dev headers, so the live source is the WirePlumber control CLI
  (`pw-dump` read, `wpctl` write), isolated behind `AudioSource` and pinned in
  one parser. Documented in ADR 0028; a native client can replace it later.
- Volume/mute reads are for the default sink; `sinks` is the per-sink list
  (read-only). Routing and device switching stay deferred to T-15.

Next task (T-07.5a) must know:

- Render the slider from `AudioSnapshot::level()`/`volume_percent()` (linear,
  already un-cubed) and use `glyph()` (`volume`/`volume-muted`).
- Own the event bridge: call `AudioAdapter::refresh()` on a WirePlumber change
  (`pw-mon`/`pactl subscribe`), never poll. Writes return `SetOutcome`; a
  successful write is reflected by the next `refresh()` (one `Changed` event).
