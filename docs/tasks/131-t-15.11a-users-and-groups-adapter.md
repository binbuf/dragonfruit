## Goal

Backend adapter for Users and Groups over the host stack (AccountsService), with state, events, and absent-daemon behavior.

## Scope

- Adapter over the host stack (reuse, never reimplement).
- State + events + absent-daemon behavior, unit-tested.

## Explicitly deferred

- Settings pane and Control Center tile (T-15.11b).

## Acceptance (agent-completable)

- [ ] Adapter reports state and events against a mock; absence is a normal state.

## Test plan

- Headless: adapter mock drives the states.

## Hand-off

Landed: a new workspace crate `dragonfruit-account-adapter`
(`services/account-adapter`) — a Users and Groups adapter over the host stack,
plus `AdapterId::ACCOUNTS` and the crate's tests, docs, and capture script. See
`docs/PROGRESS.md` "## T131" for paths, commands, and decisions, and ADR
[0138](../design/adr/0138-users-and-groups-adapter.md).

- **Read**: AccountsService users (`ListCachedUsers` +
  `Properties.GetAll("org.freedesktop.Accounts.User")`) into `AccountData`, plus
  an optional `GroupData` list from the `GroupProvider` seam. The live
  `HostAccounts::new()` attaches no provider yet, so groups report absent in a
  session until packaging supplies one — the honest state, matching T-15.10a's
  update provider.
- **Writes**: `create_user`, `delete_user`, `set_account_type`, `set_locked`,
  `set_automatic_login` (AccountsService, polkit-authorized), and `create_group`,
  `delete_group`, `set_group_members` (group provider). Each is one explicit
  call answering `Applied`/`Denied`/`Absent`/`Failed`; a write never changes the
  adapter state.
- **Events**: the shared subscription lifecycle plus a pure
  `AccountsSnapshot::changes` diff drained through `drain_changes`.
- **Absence is layered**: `Unavailable` only when neither AccountsService nor
  the provider is reachable; no users is `Available` with `present()` false; no
  provider is `Available` with `groups: None`.

T-15.11b adds the Settings pane and Control Center tile over this adapter. It
must not add a second account or group implementation, and it should note the
Control Center panel is at the nested-output height ceiling (T-15.10b).
