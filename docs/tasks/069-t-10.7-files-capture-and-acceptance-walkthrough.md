Gotchas for later tasks:

- **`make files-capture` leaves `HOME` alone** (only `XDG_*` are scratch):
  overriding `HOME` makes cargo/pnpm/pkg-config lose the toolchain (`PKG_CONFIG_PATH`
  is derived from `$(HOME)/.local/df-devroot`).
- **The stills are full nested output (1920x1200).** Watch the active-window
  capture (`spectacle -b -n -a`); if the KWin raise races, a still can catch the
  host window instead — re-run that scene with `ONLY=<name>`.
- **The nested synthetic pointer axis cannot scroll a Qt client surface**
  (known T-10.4 limitation), so the "scrolled" still looks similar to the top
  one; the QML `test_large_list_scroll_sweep` is the real scroll evidence.
- **Unrelated working-tree changes exist** (`docs/design/02-compositor.md`,
  `08-settings.md`, `licensing.md`, ADR 0055 / track 18 / tasks 172–175) from
  another session; left untouched.

- T-17's loop uses Files as the second first-party app.
