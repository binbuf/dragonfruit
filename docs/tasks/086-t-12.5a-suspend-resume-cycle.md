## Hand-off

**Landed.** The suspend/resume round trip is implemented on both sides and
frozen in [ADR 0072](../design/adr/0072-suspend-resume-cycle.md):

- `services/session/src/suspend.rs` — pure `SuspendCycle` (`Awake` /
  `Requested` / `Asleep`) driven from `IdleEvent::Enter(Suspend)` /
  `Restore(Suspend)` and logind `PrepareForSleep`, plus
  `SuspendController<B: SuspendBackend>` and a `MockSuspend`. The request side
  is idempotent; an external suspend confirms straight from `Awake`; a wake
  counts exactly one cycle; activity before sleep lands cancels the request.
- `compositor/src/suspend.rs` + `DfState` — `SuspendModel` and
  `suspend_session`/`resume_session`: quiesce (no frames, input dropped,
  animation timer disarmed) and recover (repaint every output, re-arm
  animations), keeping every output, client, and scene object.
- The headless synthetic harness gained `suspend`, `resume`, and
  `query session`; the DRM session pause/activate path drives the same model.

**Tests that pass** (repo root):

- `cargo test -p dragonfruit-session` — 29 unit + 3 `suspend`.
- `cargo test -p dragonfruit-compositor --bin dragonfruit-compositor` —
  280/280.
- `cargo test -p dragonfruit-compositor --test suspend_resume_conformance` —
  1/1 (`make e2e` now runs it).
- `make e2e`, `make lint` — exit 0.

**Deviation / deferred.** The concrete logind D-Bus backend and
`PrepareForSleep` forwarding to the compositor are not wired; `SuspendBackend`
ships with only the mock, and the trigger is the synthetic harness (plus the
DRM VT pause/activate path). That is the real-session/hardware step. The
`query latency` report also gained a `received=` input counter to make the
drop/restore observable headlessly.

**Live check.** Nested demo driven over its synthetic socket: `query session`
`suspended=0 cycles=0` → `suspended=1 cycles=0` → `suspended=0 cycles=1` →
`cycles=2`, always `outputs=1 windows=1`; captures
`/tmp/opencode/t86/t86-suspend-{awake,suspended,resumed}.png` are
byte-identical across the cycle (suspend freezes, resume restores — no visual
change intended) and the dev tool reported a clean teardown. The `symphony
vision` tool returned HTTP 429, so the stills were verified with PIL
(3840x2160, not black, ~46k distinct colors, matching the known-good
`t84/t85-idle.png` distribution).

**T-12.5b** adds the settingsd policy keys (`IdlePolicy::from_keys`), the kill
matrix, and the T-12 capture; it can construct `SuspendController` with a real
logind backend and forward `PrepareForSleep`.
