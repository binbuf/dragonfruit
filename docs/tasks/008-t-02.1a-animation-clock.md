## Goal

A shared animation clock that renders exactly one compositor frame per animation frame and zero damage when idle.

## Scope

- Frame-scheduled clock driven by the calloop loop; one render pass per animation frame.
- Idle assertion: no animation means zero damage and zero client wakeups.
- Reduced-motion flag short-circuits to a single step through the same commit path.

## Explicitly deferred

- The appear transition itself (T-02.1b).

## Acceptance (agent-completable)

- [x] Instrumented counters show one frame per animation frame and zero idle damage.

## Test plan

- Headless: idle trace stays flat; a dummy animation produces exactly one frame per tick.

Gotchas for later tasks:

- Start every transition with `DfState::start_animation(...)` (it arms the
  clock); never arm a second timer. `animations_active()` is the single
  liveness predicate.
- The `Animation` trait takes `&mut DfState` and the clock is stepped via
  `DfState::step_animations` (the clock is swapped out mid-step, so an
  animation may mutate state). An animation started *from inside another
  animation's `advance`* is absorbed, but avoid it.
- `Tween::from_motion(start, motion, reduced_motion)` is the way to honour
  `accessibility.reduceMotion`; the reduced token durations are 0 today, so
  the transition completes on its first step.
- `frames_rendered` and `animation_frames_stepped` are on the same
  `SIGUSR1`/exit line for T-03.1a's trace; the extra token does not change
  the existing three-field parse.
- T-02.1b should store its per-window appear tween in the window/scene state
  and register an `Animation<DfState>`; the Dock tile origin hand-off is
  additive and optional (centered origin in headless).
