## Hand-off

**State: done.**

What landed:

- **Live index, diff-based.** `AppIndex` remembers its `applications`
  directories; `refresh()` re-scans and diffs: new id = `installed`, changed
  record = `updated`, vanished id = `uninstalled`. Events are returned and
  retained (bounded, `IndexEvents` drains). `resolve_activity` resolves a window
  without touching the audit counters or miss set. `src/index.rs`.
- **Recursive inotify watcher.** `DirectoryWatcher` (`src/watch.rs`) watches
  every directory under the corpus, debounces 150 ms, and re-scans on a monitor
  event; `dbus::run` starts it and emits `IndexChanged` per diff. No idle
  polling. Watches are established synchronously in `new()` so a write cannot
  race the first `add_watch`.
- **Launch registry + recency.** `LaunchRegistry` (`src/registry.rs`) tracks
  running apps and window counts, and a most-recent-first recency ring (32)
  ordered by insertion (same-ms safe) rather than timestamps. Exited apps leave
  the running set but stay recent; focus reorders without changing the running
  set. Key is the resolved desktop id, else the canonical raw identity.
- **Additive bus surface** (`src/dbus.rs`): `WindowOpened`, `WindowClosed`,
  `NoteActivity`, `Running`, `Recent`, `Refresh`, `IndexEvents`,
  `ActivityEvents`; signals `AppRunning`, `AppExited`, `IndexChanged`. Flat JSON
  as before. `main.rs` gained `--refresh`.
- ADR [0087](../design/adr/0087-app-index-events-launch-registry-recency.md);
  `docs/design/02-compositor.md` "Application identity" updated.

Deviations / what remains:

- **The shell does not yet forward window activity.** This task's area is
  `services/app-index`; the service exposes `WindowOpened`/`WindowClosed`/
  `NoteActivity`, but nothing calls them live (the Dock still takes its running
  projection from the compositor). Wiring the forwarder is a later-task item;
  the headless bus tests drive the methods directly.
- Recency is in-memory per session; persistence and the coalesced subscription
  API are T-14.1c.
- The watcher is Linux/inotify only (non-Linux is a no-op), matching the
  shipping target.

Next: T-14.1c adds subscriptions (the signals are already emitted).
