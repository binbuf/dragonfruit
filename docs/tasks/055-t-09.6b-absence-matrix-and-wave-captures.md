**State: done.** The T-09 wave has its absent-provider matrix and its committed

What landed:

- **Absence matrix doc** — new section "The absent-provider matrix (T-09.6b)"
  in `docs/design/08-settings.md`: the no-half-panes rule (catalog `shipped`
  flag gates both the sidebar row and `SettingsShell.paneComponent`), the
  provider-absence table for the four Wave-1 panes, and the deliberate
  absence of a settingsd "unavailable" banner.
- **Headless test** — `apps/settings/tests/tst_settings_absence.{cpp,qml}`
  (9 cases), run under a private `dbus-run-session` with **no** settingsd and
  **no** portal and **no** `DF_SETTINGS_FIXTURE`, so `Settings.available` and
  `Settings.wallpaperChooserAvailable` are both honestly false. It asserts
  every shipped pane has a body and every unshipped id does not; each pane
  stays live and writes in memory; and the Wallpaper portal row is the only
  disabled control ("No file chooser is available.").
- **Visual-check correction (in scope).** The required live check caught the
  documented T-09.3 follow-up (a): `AppearancePane.qml` placed its
  `SegmentedControl` and accent `Row` as plain `SettingsRow` children, so they
  fell to `Item.data` and overlapped the labels. Both are now wrapped in
  `controlData:` (the form the other panes use), with a right-alignment
  regression case added to `tst_settings_appearance.qml`.
- **Captures** — `docs/captures/t09-settings-wave-1.{png,light,dark,reduced}.png`,
  one `t09-settings-wave-1-<pane>.png` per shipped pane, and
  `t09-settings-wave-1.mp4`; produced by `scripts/capture-settings-wave-1.sh`
  (`make settings-wave-1-capture`) and documented in `docs/captures/README.md`.

Gotchas for later tasks:

- **Run the absence test under `dbus-run-session`.** Without the private bus
  the host's settingsd/portal leak in and the absence assertions are
  meaningless; the CMake target wires this automatically.
- **`WallpaperPane.photoRow` is a test-surface alias** added here; no
  behaviour change.
- **Do not show a "settings unavailable" state.** Panes use the schema
  defaults; a banner would be a half-pane (see the matrix doc). The T-15.16
  breadth matrix should follow the same shape.
- **The appearance `controlData:` fix closes T-09.3 follow-up (a).** Other
  panes already used `controlData:`; keep that form for new rows.
