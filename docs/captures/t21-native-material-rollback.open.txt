## What was exercised (config only, no logout)

The documented rollback command is:

```bash
DRAGONFRUIT_DRM_MATERIAL=0 make native-rebuild
```

Running it as-is rebuilds, installs, and then ends the current login session
(`loginctl terminate-session`), so the agent session and this native capture
would end before the fallback could be read. To test the persistence/restore
half safely, the same script was run with `--no-build --no-install
--no-logout`:

```bash
# apply the rollback environment
DRAGONFRUIT_DRM_MATERIAL=0 bash scripts/native-session.sh rebuild \
    --no-build --no-install --no-logout

# restore the default environment
bash scripts/native-session.sh rebuild --no-build --no-install --no-logout
```

The apply run wrote the flag into the session environment and every unit
drop-in:

```text
~/.config/dragonfruit/native.env:
  DRAGONFRUIT_DRM_MATERIAL="0"

~/.config/systemd/user/dragonfruit-compositor.service.d/10-dragonfruit-native-env.conf:
  Environment="DRAGONFRUIT_DRM_MATERIAL=0"
```

The restore run removed it:

```text
grep DRAGONFRUIT_DRM_MATERIAL ~/.config/dragonfruit/native.env \
    ~/.config/systemd/user/dragonfruit-compositor.service.d/10-dragonfruit-native-env.conf
# (no matches)
```

The pre-run files were then copied back byte-for-byte and
`systemctl --user daemon-reload` was run, so the only diff from the original
is none. The running compositor was never restarted: its live `material stats`
still report `path=gpu`, `blur_passes>0`, `blur_draws>0`, and
`backdrop_skipped=0` (see `t21-native-material.txt`).

## Why the native fallback render is OPEN

`dragonfruit-compositor.service` is the session anchor: stopping or restarting
it makes `dragonfruit-session-entry` tear down the target and the display
manager returns to the greeter. The agent cannot complete the re-login (the
account has a password), and ending the session would destroy the live
diagnostics this task just captured. This is the same boundary recorded by
T183 and T188c for native-only scenario runs; it is an operational/session
boundary, not a missing GPU or panel.
