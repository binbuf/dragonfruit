# T187a — T-21.2a per-output refresh model (pure)

## Landed

- New pure library module `compositor/src/refresh.rs`, exported as
  `dragonfruit_compositor::refresh` from `compositor/src/lib.rs`.
- `OutputRefresh { refresh_mhz, period, deadline, source, vrr }`,
  `ModeRefresh { refresh_mhz, vrr }`, `RefreshSource`
  (`Mode`/`Fallback`/`Override`), and `VrrState`
  (`Unknown`/`Off`/`On`).
- `RefreshSchedule` keyed by output name with `update(output, Option<ModeRefresh>)`,
  `remove`, `clear`, `fastest_period`, `for_output`, `iter`, `len`, `is_empty`.
- Fallback/clamp policy: no mode or `refresh_mhz <= 0` → 60 Hz
  (`source=fallback`); positive modes clamp to 24–500 Hz and otherwise keep
  their exact millihertz period (`source=mode`). `deadline == period` today.
- Nine unit tests cover the 60/120/144/240 table, a real 143.999 Hz panel,
  invalid/zero/negative fallback, low/high clamp, mode replacement,
  add/remove/hotplug, fastest selection, VRR carriage, and source tokens.
- ADR 0198 and the animation-clock note in `docs/design/02-compositor.md`.

## Reusable facts / gotchas

- **Smithay `Mode.refresh` is millihertz.** The period is
  `1_000_000_000_000 / refresh_mhz` **nanoseconds**. The parent reference's
  `1e9 / refresh_mhz` line is a factor-of-1000 typo; `1_000.0 / refresh_mhz`
  seconds is the correct cross-check. Do not use `1e9` with millihertz.
- 60 Hz = 16,666,666 ns, 120 Hz = 8,333,333 ns, 144 Hz = 6,944,444 ns,
  240 Hz = 4,166,666 ns. A 143,999 mHz mode keeps 6,944,492 ns.
- `RefreshSchedule::fastest_period()` returns `Duration`, not `Option`, and
  falls back to `FALLBACK_PERIOD` (60 Hz) for an empty schedule. This is the
  interval T187b should feed the clock before the first output exists.
- `update` returns the resolved `OutputRefresh` by value, so a caller can
  inspect the chosen source/period without borrowing the map.
- `BTreeMap` gives deterministic name ordering and tie-breaking. `fastest`
  is simply the minimum period; ties do not need a separate rule.
- VRR is stored only; it never changes `period` in this task.
