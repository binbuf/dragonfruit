# T190a — T-21.3 pure MaterialRegion helper

## Landed

- `compositor/src/window/material_region.rs` (new, pure geometry):
  - `MaterialRegion { rect, physical, texture_size }`;
  - `MaterialRegion::from_panels(&[BlurPanel], output_local_rect, scale)`.
  - Each panel is expanded by **its own** `BlurSpec::padding_px()` before the
    union; the union is clamped to the logical output rect.
  - `physical` is `rect.to_physical_precise_round(scale)` clamped again to the
    physical output rect (independent location/size rounding can overflow one
    pixel at fractional scales); `texture_size` is `physical.size`.
  - `None` for empty input, degenerate panels, panels fully outside, a
    zero-sized output, or a non-positive/non-finite scale.
- `BlurSpec::padding()` / `padding_px()` in `compositor/src/window/blur.rs`:
  - `padding = max(radius, downsample)`, `downsample = 2^iterations`;
  - no literal padding constant; `padding_px` rounds up.
- Re-exported as `crate::window::MaterialRegion` from `window/mod.rs`.
- Tests:

## Reusable facts / gotchas

- `MaterialRegion.rect` is output-local **logical**; `physical` is
  output-local **physical** and is the scene texture geometry. Translate a
  panel's physical `src` by subtracting `physical.loc`; do not reuse a
  full-output `src`.
- The output rect passed to `from_panels` must be output-local. `DfState`'s
  `space.output_geometry(output)` carries the global output origin, so T190b
  must pass `Rectangle::from_size(output_geometry.size)` (or subtract the
  origin first).
- Padding formula is `max(token radius, 2^iterations)`. For the current
  material tokens that is the token radius (24 chrome/dock, 12 popup); a tiny
  radius still gets the minimum one-iteration footprint of 2 px.
- The helper is not wired into `chrome_blur_panels` yet: T190b still sees the
  old full-output scene path and the unpadded `material_pass.apply` region.
- The physical clamp matters at 1.5x: e.g. logical (1187,747,93,53) rounds to
  (1781,1121,140,80), whose right/bottom would be 1921x1201, so the helper
  clamps it to (1781,1121,139,79).
