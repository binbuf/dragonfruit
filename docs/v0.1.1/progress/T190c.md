## Reusable facts / gotchas

- `PanelKey` is `hash(namespace, layer, surface.protocol_id())`; it is
  allocation-free on the per-frame path. A surface restart gets a new key, so
  the old slot is trimmed and the new panel damages once on appearance.
- `PanelTextureSlots::trim_to(&keys)` is the only lifetime boundary. It uses
  key equality, not list position: a popover opening, a panel reorder, or a
  Dock magnification never inherits another panel's textures/id.
- Panel element commits stay at `CommitCounter::default()` on purpose. The
  live scene elements (windows/wallpaper/chrome) carry scene damage; bumping a
  panel commit on every scene change would repaint the panel needlessly.
- `SceneTextureCache` uses the offscreen tracker with age 1. First frame, a
  reallocation, or a region-size/scale change renders the whole region; an
  unchanged scene skips rendering entirely and leaves the scene commit flat.
- `SceneTextureKey` still excludes the region origin. An origin-only move
  relies on the relocated element geometry changing, which the full-output
  wallpaper element turns into full-region damage. If a future scene base
  stops covering the whole region, revisit this.
- The scene commit advances only when `render_output` returns
  `damage.is_some()`. In the default region shape the scene texture is only
  the blur source; the full-output diagnostic base is the element that
  consumes the scene commit.
- The nested host's `buffer_age` can be 0 when the host has no damage
  tracking; Smithay then forces full output damage regardless of ids. Stable
  ids help the damage-tracking host path; record the host if a target lacks
  it.
- `material stats` in the committed settled capture is flat between the two
  snapshots: `material_allocations=10` (scene 2, panel 8), region
  `1920x1200`. The region is full output because the menu bar and Dock both
  blur; that is the single-union shape, not a stable-ID regression.
- `make t21-stable-damage` writes the transcript with the unit-test result,
  doctor output, capture command, and both material snapshots. The capture
  itself is the compositor's own screenshot path (`DF_SCREENSHOT_CAPTURE_FIXTURE`).

## Follow-ups

- T190d: direct-scanout policy and counters. The settled-damage behavior is
  the transition baseline: a no-damage frame should not force composition.
- T192: benchmark the settled frame against the old per-frame panel repaint
  and the full-output path; include the single-union full-output case.
- Multi-rect/tiled material regions remain open from T190b. The current
  single padded union is full output when both the menu bar and Dock blur.
- `PanelKey` is a 64-bit hash. If the shell grows many layer surfaces or a
  collision-free key is required, store the namespace/layer/object-id triple
  instead; the cache API only needs `Eq + Hash`.
- Revisit the origin-move assumption if the scene base stops being a
  full-output wallpaper element.
- Record a host without `buffer_age` damage tracking if one is targeted; the
  nested fallback forces full damage for correctness.
